# Backlog

Collect concrete ideas for the product, code, architecture and development environment. Entries retain context without authorizing implementation or changing Plan priority. An empty Backlog is valid.

Use [edit-backlog](../.agents/skills/edit-backlog/SKILL.md) proactively when work reveals a useful improvement outside the current task. Check existing ideas and Plan first; update an existing entry when it describes the same improvement. Resume the task after saving the note.

Rows link stable BNNN IDs to Backlog/NNN.md. Each card contains Context, Proposal and Expected benefit. Keep ideas concise; observations and hypotheses remain distinguishable. When planning is authorized, preserve the card and link the resulting Plan feature from it. Required work for the current task remains in that task.
