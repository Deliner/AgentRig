# P091 — rust-expansion: анализатор зависимостей Rust разбирает include!, macro_rules! и атрибуты

## Feature

[B083](../Backlog/083.md): анализатор зависимостей Rust учитывает `include!` со строковым путём, `include!` кода
`OUT_DIR`, тела `macro_rules!`, экспортные атрибуты и атрибут-макросы внешних крейтов без кодогенерации. Источник —
карточка B083, сохранённая первым VAC ветки `feature/rust-expansion`; выбор и авторизация — пользователь 2026-11-07.
Порядок и границы VAC — за исполнителем.

## User capability

Rust-проект с генерацией кода, FFI-экспортом и wasm проходит проверку архитектуры по реальным зависимостям.

## Acceptance

Карточка **B083 (AC1–AC5, границы)** — критерии и формулировки там; идентификаторы те же.
