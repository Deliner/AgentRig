# P003

## Feature

P003: Discoverable lint and managed delegation.

## User capability

Configure a portable worker environment, discover and explain the actual linter capabilities, monitor owned commands, and delegate bounded tasks through MCP with recoverable results.

## Acceptance

- One typed rule registry drives discovery, details, valid examples and configuration validation; language support reflects real handlers. Explain reports selection reasons and effective overrides. Embedded and standalone lint share behavior and preserve strict existing rules.
- Managed commands have durable run and owner identities, live status, logs, resource information where supported, cancellation and recovery based on OS evidence. Cleanup preserves other owners and shared services, including after merge; setup reports actual containment capabilities.
- Project configuration and existing setup prepare selected executor profiles, models, skills and restricted MCP capabilities. Start/status/result/cancel work across reconnects with validated results for read-only snapshots and separate artifact outputs.
- Delegated code changes use isolated Git copies at fixed revisions and return inspectable commits or patches with verification. Failures and concurrent runs preserve the primary checkout and each other's data. Integration remains subject to the calling workflow's checks.
- An independent consumer demonstrates setup, lint discovery/explain/validation, all three delegation modes, cancellation, recovery and owner-aware cleanup. Schemas, guidance and documentation agree with behavior; mandatory gates and branch integration pass.
