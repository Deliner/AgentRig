# P001 — Isolated review MCP

## Feature

Provide a configurable MCP service that evaluates an exact project revision with multiple independent reviewer roles.

## User capability

The user can select the project revision, review boundary, visible project files, reviewer models, and reviewer instructions, then receive one report containing every role's verdict and evidence.

## Acceptance

Reviewers cannot modify the reviewed project or read project data outside the configured visibility boundary. Malformed or incomplete reviewer responses cannot produce a passing result. Repeated review of the same inputs records the exact revision and review configuration used. Temporary reviewer outputs do not survive after their contents are preserved in the final report.
