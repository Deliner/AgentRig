# P056 — silent-error для Rust: обход `read_dir` и рукав `Err → Ok(bool)`

## Feature

[B049](../Backlog/049.md): Rust-половина правила `silent-error` — проглоченные пер-элементные
ошибки обхода каталога (`read_dir(..).flatten()`/`.filter_map(Result::ok)`/`.map_while(Result::ok)`,
AC1) и рукав `Err(_) => [return] Ok(false|true)` в функции с литеральным типом возврата
`Result<bool, …>` (AC2, дополнение 2026-11-04). Источники — межпроектный обзор
(`wf_f2a6f63a-7ff`) и исследовательская дуга (`coverage-map.md` «silent-err-arm (b)»);
реализация авторизована пользователем 2026-11-04 (/goal). Механизм — расширение существующего
вида `silent-error` на расширение `.rs` либо новый вид, за исполнителем. Исходный контракт —
ревизия карточки B049 в Git. Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки: нечитаемый каталог не превращается молча в пустой список, а
ошибка проверки не становится молча ответом «нет»/«да»; безопасные формы (`entry?`, проброс
`Err(e)`) находкой не являются. Наш код: единственный сайт AC2 — `change_delivery/git/mod.rs:146`
(`merged_reference`) — становится fail-closed (нерезолвимый tip не разрешает удаление ветки), что
закрывает [B062](../Backlog/062.md) AC1 здесь.

## Acceptance

Карточка **B049 (AC1–AC2, границы)**.
- **AC1** — цепочка от `read_dir(` со сворачиванием `Result<DirEntry>` → находка; форма с `entry?`
  — нет.
- **AC2** — рукав `Err(_)`/`Err(..)` с телом `Ok(false)`/`return Ok(false)`/`Ok(true)`/
  `return Ok(true)` при литеральном `Result<bool, …>` без обоснования прямо выше → находка; иное
  тело или иной тип возврата — нет; тестовый код исключён.
- **Догфуд** — `merged_reference` пробрасывает ошибку Git вместо `Ok(false)`; поведенческий тест в
  `change_delivery/git/tests` фиксирует «ошибка проверки не разрешает удаление» (кандидат
  инварианта I021 оценивается по norm-or-choice при доставке).

Расширение `silent-error` на `.rs` (или новый `kind:`) должно приниматься stable-бинарём из
`lint.yaml` → двухфазная доставка с мид-бранч пином ([D051](../Decisions/051.md)); затем
`just candidate lint` → 0 находок и живая проба обоих паттернов. Пороги не ослабляются.
