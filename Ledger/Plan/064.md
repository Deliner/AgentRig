# P064 — disallowed-path и владелец `shared/fs`

## Feature

[B057](../Backlog/057.md): политика запрещённых путей `disallowed: [{path, reason, replacement,
allow}]` в настройках правила `directory-architecture`, проверяемая через существующий резолвер
ссылок (AC1); владелец файловой системы `Project/shared/fs` с обёртками, несущими путь (AC2);
догфуд нашего `lint.yaml` записями `std::fs`/`std::os::unix::fs` (AC3). Источник —
исследовательская дуга (`coverage-map.md` шаг 6 «fs-context»/`disallowed-path`, критика r0:
главный кандидат Tier 1; ремонты 1 и 5); реализация авторизована пользователем 2026-11-04 (/goal).
Исходный контракт — ревизия карточки B057 в Git. Порядок и границы VAC — за исполнителем.

## User capability

Потребитель объявляет в `lint.yaml`, какие пути запрещены вне каталогов-владельцев, и гейт держит
это с сообщением, называющим причину и замену; `lint-config-check` отвергает плохую запись. Наш
код: продакшн-файлы вне `shared/fs` не трогают `std::fs`/`std::os::unix::fs`, а ошибки файловой
системы AgentRig называют путь и действие.

## Acceptance

Карточка **B057 (AC1–AC3, границы)**.
- **AC1** — ссылка, разрешённая в запрещённый путь или подпуть по сегментам, в файле вне `allow`
  → находка в строке ссылки «`<путь>` is disallowed here: <reason>; use <replacement>»;
  неразрешимая/локальная ссылка — нет; валидация записей; описание поля в `lint-rules`.
- **AC2** — лист `Project/shared/fs` владеет всеми операциями ФС, ошибки несут путь и действие,
  типы реэкспортируются; тесты могут обращаться к `std::fs`.
- **AC3** — записи в нашем `lint.yaml` с `allow: [Project/shared/fs/**, '**/tests/**',
  '**/tests.rs']`; `just candidate lint` → 0 находок; поведение продукта не меняется (существующие
  тесты зелёные).

Новое поле настроек должно приниматься stable-бинарём (`deny_unknown_fields`) → двухфазная
доставка с мид-бранч пином ([D051](../Decisions/051.md)): источник → пин → проводка + миграция
сайтов (ожидаемо несколько VAC) → догфуд → живая проба. Поставляемый потребителям `lint.yaml`
получает пустой список. Пороги не ослабляются.
