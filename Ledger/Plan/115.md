# P115 — rust-tests: тесты рига на Rust

## Feature

[B108](../Backlog/108.md): тесты рига на Rust. Источник — карточка B108 в первом VAC ветки `feature/rust-tests`;
выбор и авторизация — пользователь 2026-11-11. Порядок и границы VAC — за исполнителем.

## User capability

Тесты рига идут быстрее, проверяют поведение через публичную поверхность фичи и лежат рядом с кодом, который
проверяют.

## Acceptance

Карточка **B108 (AC1–AC6, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

`05c2e39`. Поддержка `Project/shared/testing/tests/` запускает кандидат и Git процессами с чистым окружением.

установленный проект запускает свои новые лаунчер и хуки. Жёсткая ссылка на кандидат вместо копии рантайма дала 16–19
