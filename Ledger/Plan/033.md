# P033 — Размещение теста по реально исполняемому коду

## Feature

[B024](../Backlog/024.md): проверять TC1 (тест лежит рядом с тем, что проверяет) по
реально исполняемому коду — собирать per-test покрытие (Rust `llvm-cov`, Python
`coverage.py`) и помечать тест, чья масса покрытия лежит вне поддерева владельца.
Исходный контракт — ревизия карточки B024 в Git (568c683); согласовано и выбрано на
исполнение пользователем 2026-10-28.

## User capability

Место теста выводится из того, что он реально трогает, а не из текстовых импортов;
«тест судится по коду, который он трогает» становится проверяемым, если покрытие
окупается.

## Acceptance

Карточка **B024 (K1–K2)**, включая её границы и неизвестное. Сначала спайк
осуществимости; по итогам — проверка либо фиксация, что покрытие не окупается/нестабильно,
и TC1 остаётся нормой с записью причины (norm-or-choice), без «притворного» инварианта —
прецедент [P031](../Archive/Plan/031.md)/[D055](../Decisions/055.md). Уровень реализации
и границы VAC выбирает исполнитель.
