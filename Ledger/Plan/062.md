# P062 — unsafe-site-justification: `unsafe impl`/`unsafe trait`, `static mut`, тела макросов

## Feature

[B046](../Backlog/046.md): расширение правила `unsafe-justification` ([D065](../Decisions/065.md))
на остальные формы `unsafe`-поверхности: `unsafe impl`/`unsafe trait` (AC1), `static mut` (AC2),
`unsafe` внутри тел макросов (AC3). Источники — межпроектный обзор (`wf_f2a6f63a-7ff`) и
исследовательская дуга (`coverage-map.md` шаг 2 «unsafe-confinement»); реализация авторизована
пользователем 2026-11-04 (/goal). Исходный контракт — ревизия карточки B046 в Git. Порядок и
границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки: любая форма `unsafe` без ссылки-обоснования на строке прямо выше
— находка, как сегодня для `unsafe` блоков и функций; граница смежности строки сохраняется.

## Acceptance

Карточка **B046 (AC1–AC3, граница смежности)**.
- **AC1** — `unsafe impl`/`unsafe trait` без обоснования → находка.
- **AC2** — `static mut` без обоснования → находка.
- **AC3** — `unsafe` в теле макроса → тот же обзор ([D094](../Decisions/094.md)).

Изменение существующего детектора без изменения `lint.yaml` → ожидается только финальный пин
([D051](../Decisions/051.md)); decision, расширяющий D065, при доставке; догфуд
`just candidate lint` → 0 находок (форм в нашем коде нет: 13 сайтов `unsafe` — блоки/функции с
обоснованиями D066/D095); живая проба каждой формы. Пороги не ослабляются.
