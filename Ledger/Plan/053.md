# P053 — Tier B: unchecked-index, disabled-RAII, sibling-cycle (+ оценка TOCTOU / lossy-int-cast)

## Feature

[B044](../Backlog/044.md): пять пунктов Tier B из того же отчёта воркфлоу-ревью, расширяющих охват
панических / ресурсных / файловых / приведения-типов смеллов плюс внутрикаталожные циклы. Исходный
контракт — ревизия карточки B044 в Git; согласовано пользователем 2026-11-01 в составе Tier A+B.
Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки дополнительные переносимые проверки: (1) `unchecked-index` — индексация
или слайсинг (`x[0]`, `x[1..]`, `map[key]`) вне тестов без обоснования становится находкой (панический
путь, аналог `panic-path`); (2) `disabled-RAII` — отключение RAII (`tempfile …keep()`/`.into_path()`,
`mem::forget`, `ManuallyDrop::new`, `Box::leak`) вне тестов без обоснования становится находкой;
(3) `sibling-cycle` — взаимные зависимости соседних файлов одного каталога (встречный `pub use`)
становятся находкой расширением `directory-architecture`. Для каждого правила — эскейп `// DECISION:`/
`// INVARIANT:`. TOCTOU (`.exists()`/`.is_file()` перед действием) и lossy-int-cast (`as` в более узкий
или знаковый тип) оцениваются как правило или норма при реализации.

## Acceptance

Карточка **B044 (AC1–AC5 + границы)**. AC1 `unchecked-index`: индексация/слайсинг вне тестов без
обоснования — находка; AC2 `disabled-RAII`: перечисленные отключения RAII вне тестов без обоснования —
находка; AC5 `sibling-cycle`: встречные sibling-зависимости в одном каталоге — находка (расширение
`directory-architecture` D070/D079, без нового вида/навыка). AC3 TOCTOU/path-exists и AC4 lossy-int-cast
оцениваются правило-vs-норма при реализации; где вскроется высокий FP (поток/типы, семейство D059) —
честно норма (бар D035, norm-or-choice), а не ослабление порога, притворных инвариантов нет. Новые виды
правил идут двухфазной доставкой с мид-веткой бутстрапом; I020 растёт согласованно (вид правила + навык
на каждое новое правило). Наш код приводится к зелёному (догфуд).
