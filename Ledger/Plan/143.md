# P143 — dogfood-setup: риг устроен так же, как проект после `init`

## User capability

Любой проект после `init` получает ровно настройку рига, а каждый агент видит навыки по абсолютному пути из своего
каталога.

Карточка **B145 (AC1–AC5, границы)** — критерии и формулировки там; идентификаторы те же.
