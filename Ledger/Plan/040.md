# P040 — Линты именования

## Feature

[B031](../Backlog/031.md): имена отражают смысл, а не прячут свалку — запрет имён-помоек (6.1),
осмысленные идентификаторы (6.2), запрет магических чисел (6.3) — и привести наш код к зелёному
(догфуд). Исходный контракт — ревизия карточки B031 в Git (7253a89); согласовано и выбрано на
исполнение пользователем 2026-10-29 в составе набора кластеров 1–8.

## User capability

Каталог-свалка (`utils`/`helpers`/`misc`/`common`) ловится гейтом до коммита, а не в ревью;
`shared` остаётся легитимным домом для кросс-фичевых листьев. Имена каталогов отражают
ответственность, а не служат мусорным ведром.

## Acceptance

Карточка **B031 (6.1–6.3)**, включая её границы. Чисто-синтаксическая, высокосигнальная часть
уезжает в поставку `init` ([D053](../Decisions/053.md)/[I020](../Invariants/020.md)); шумящее
остаётся нормой с записанной причиной (norm-or-choice), а не ослабленным правилом с ложными
срабатываниями ([D035](../Decisions/035.md)). Наш код приводится к зелёному; пороги и селекторы
не ослабляются ради проходимости. Уровень реализации каждого под-правила и границы VAC выбирает
исполнитель (гейт держится зелёным).
