# P005

## Feature

Stable development and public distribution.

## User capability

Develop AgentRig while its installed development runtime remains usable independently of candidate source changes. Obtain AgentRig and its standalone linter from a public MIT-licensed GitHub repository and prepare independent consumer projects.

## Acceptance

- Working commands and hooks use an explicitly pinned installed runtime; candidate build failures do not replace or disable it.
- Product tests exercise the candidate. Development runtime upgrades are explicit and follow verified acceptance.
- A fresh clone has documented bootstrap, prerequisites and the existing full development gate.
- The public GitHub repository includes MIT, consumer quickstart, configuration/example links and CI. Linux release artifacts include AgentRig, the standalone linter, checksums and release/upgrade notes.
- Publication includes only intended source and documentation; private runtime data, credentials and temporary evidence remain local.
