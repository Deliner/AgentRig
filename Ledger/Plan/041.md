# P041 — Линты тестов

## Feature

[B032](../Backlog/032.md): тесты детерминированы и явно обоснованы, а не тихо выключены — запрет
тихо выключенных тестов (7.1), запрет недетерминизма в тестах (7.2), конвенции имён/размещения
(7.3) — и привести наш код к зелёному (догфуд). Исходный контракт — ревизия карточки B032 в Git
(7253a89); согласовано и выбрано на исполнение пользователем 2026-10-29 в составе набора кластеров
1–8.

## User capability

Тихо выключенный тест (Rust `#[ignore]`, Python `@pytest.mark.skip`/`skipif`) без записанного
обоснования ловится гейтом до коммита, а не теряется незаметно; потерянное покрытие либо
восстановлено, либо явно обосновано ссылкой `DECISION:`/`INVARIANT:`. Новый проект получает это из
коробки.

## Acceptance

Карточка **B032 (7.1–7.3)**, включая её границы. Чисто-синтаксическая, высокосигнальная часть
уезжает в поставку `init` ([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md));
шумящее остаётся нормой с записанной причиной (norm-or-choice), а не ослабленным правилом с
ложными срабатываниями ([D035](../../Decisions/035.md)). Наш код приводится к зелёному; пороги и
селекторы не ослабляются ради проходимости. Уровень реализации каждого под-правила и границы VAC
выбирает исполнитель (гейт держится зелёным).
