# P063 — чистая зона: случайность, сеть, потоки и консоль

## Feature

[B056](../Backlog/056.md): расширение проверки `zone: pure` правила `directory-architecture`
([D078](../Decisions/078.md)/[D083](../Decisions/083.md)) на точные пути энтропии (`rand::random`,
`rand::thread_rng`, `rand::rng`, `getrandom::getrandom`, `getrandom::fill`), префиксы `std::net`,
`std::thread`, `std::io::stdin`/`stdout`/`stderr` и print-макросы по имени. Источник —
исследовательская дуга (`coverage-map.md` R3, критика r0); реализация авторизована пользователем
2026-11-04 (/goal). Исходный контракт — ревизия карточки B056 в Git. Порядок и границы VAC — за
исполнителем.

## User capability

Потребитель получает из коробки: каталог, объявленный `pure`, не может незаметно читать энтропию,
ходить в сеть, запускать потоки или печатать; сообщение зоны называет эффект; описание контракта
(`lint-rules`) перечисляет расширенный набор. Escape прежний — не объявлять `pure`.

## Acceptance

Карточка **B056 (AC1–AC2, границы)**.
- **AC1** — ссылка в `pure`-каталоге, разрешённая в перечисленный путь или подпуть, → находка
  зоны с сообщением, называющим эффект.
- **AC2** — `print!`/`println!`/`eprint!`/`eprintln!` (в том числе `std::`) в `pure`-каталоге →
  находка зоны; `dbg!` остаётся [D081](../Decisions/081.md).

Изменение существующей проверки без изменения `lint.yaml` → ожидается только финальный пин
([D051](../Decisions/051.md)); decision, расширяющий D078/D083, при доставке; догфуд
`just candidate lint` → 0 находок (единственный `pure`-каталог `architecture/resolution` чист);
живая проба в `pure`-каталоге. Пороги не ослабляются.
