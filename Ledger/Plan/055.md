# P055 — global-state: процессно-глобальное изменяемое состояние без владельца

## Feature

[B052](../Backlog/052.md): новый вид правила `global-state` — `static`-элемент с глобальной
блокировкой (`Mutex`/`RwLock`/`DashMap`/`DashSet`, в том числе внутри `LazyLock`/`OnceLock`/
`Lazy`/`Arc`) или публичный `static` с любой ячейкой, без ссылки-обоснования прямо выше, включая
элементы `lazy_static!`/`thread_local!`. Источник — исследовательская дуга из семи раундов (архив
`agentrig-research/scratchpad`, принятая форма R2 от 2026-11-02); реализация всех находок дуги
авторизована пользователем 2026-11-04 (/goal). Исходный контракт — ревизия карточки B052 в Git.
Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки: глобальная блокировка или публичная ячейка в его Rust-коде либо
имеет владельца (приватна за функцией-владельцем, передана параметром или полем контекста), либо
несёт записанное обоснование; приватные `Atomic*`/`Cell` и `OnceLock` без ячейки не трогаются.
Навык ремонта `own-the-state` объясняет, как передать состояние владельцу.

## Acceptance

Карточка **B052 (AC1–AC3, список не-находок, границы)**.
- **AC1** — глобальная блокировка без обоснования → находка error; с `// DECISION:`/
  `// INVARIANT:` прямо выше → нет.
- **AC2** — публичный `static` с ячейкой без обоснования → находка.
- **AC3** — элементы внутри `lazy_static!`/`thread_local!` проходят AC1/AC2 (синтаксический обзор
  тела макроса, граница [D059](../Decisions/059.md)).
- Не-находки по карточке; тестовый код исключён.

Новый `kind:` → двухфазная доставка: источник (вид, детектор, тесты, decision) → мид-бранч пин
stable.txt + bootstrap → проводка (`catalog::ALL`, `lint.yaml`, навык в `assets.rs`, I020) →
догфуд `just candidate lint` (ожидается 0 находок: `static`-элементов в `Project` нет) → живая
проба: нарушающий фрагмент даёт находку, его удаление возвращает чистоту
([D051](../Decisions/051.md)). Пороги не ослабляются; притворных инвариантов нет.
