# P031 — Тестовая дисциплина

## Feature

[B022](../Backlog/022.md): тестовая дисциплина как durable-policy — размещение теста
по области поведения, тестирование только через публичную поверхность, проверка
поведения, а не внутреннего состояния, с enforcement статически проверяемых пунктов
и навыком-нормой для остального. Исходный контракт — ревизия этой карточки в Git
(2d4ca6f); согласовано и выбрано на исполнение пользователем 2026-10-28.

## User capability

Тесты переживают рефакторинг, давление тестов не течёт в публичный API продукта, а
место теста выводится из области поведения — и это проверяется у потребителя из
коробки, а не держится в голове.

## Acceptance

Карточка **B022 / TC1–TC7**, включая её границы и неизвестное. Статически проверяемые
пункты (кандидаты TC1/TC2) становятся правилом линтера/инвариантом и уезжают в
поставку `init`; осуществимость каждого подтверждается на этапе реализации, иначе
пункт остаётся нормой с явной записью причины — без «притворного» инварианта
(norm-or-choice). Непроверяемое (TC3, во многом TC4) — навык-норма, отданная
потребителю наравне с существующими навыками. Уровень реализации и границы VAC
выбирает исполнитель.
