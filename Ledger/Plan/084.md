# P084 — disallowed-methods: методы ФС с ошибкой без пути

## Feature

[B078](../Backlog/078.md): запись политики `disallowed` перечисляет имена методов; вызов такого метода без
аргументов с пробросом ошибки через `?` или `.map_err(Into::into)` вне `allow` — находка; запись `std::fs` в
`.agentrig/lint.yaml` перечисляет методы ФС, а сайты AgentRig вызывают обёртки `shared::fs`. Источник — карточка
B078 (ревизия в Git `e90d81a`); выбор и авторизация — пользователь 2026-11-07. Порядок и границы VAC — за
исполнителем.

## User capability

Ошибка файловой системы всегда называет действие и путь.

## Acceptance
