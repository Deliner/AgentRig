Проверка источников 2026-09-11: установлены Codex CLI 0.154.0 и Claude Code
2.1.201. В трёх локальных журналах Codex найдены `last_token_usage`,
`model_context_window` и явные записи суммаризации. Официальная
[документация Codex](https://learn.chatgpt.com/docs/hooks) описывает
`SessionStart` с `source: compact`, `PostCompact` и неблокирующий
`PreToolUse.additionalContext`; формат transcript не является стабильным
интерфейсом. Документация [Claude Code status line](https://code.claude.com/docs/en/statusline)
описывает `context_window.current_usage`, `context_window_size` и
`used_percentage`; [hooks](https://code.claude.com/docs/en/hooks) — события
суммаризации и передачу контекста агенту.

Источники найдены; сквозная работа адаптеров на поддерживаемых версиях и режимах
клиентов ещё не проверена. При реализации подтвердить обновление измерений,
доставку перед инструментом и сброс после подтверждённой суммаризации.
Данные status line не считаются автоматически доступными каждому режиму Claude.
Последние измерения не подменять накопленным расходом; при недоступности данных
сохранить поведение К1. Текущий reader и сброс при уменьшении счётчика сами по
себе не удовлетворяют B012. Новый сервис мониторинга не требуется.
