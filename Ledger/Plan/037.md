# P037 — Линтер безопасности

## Feature

[B026](../Backlog/026.md): добавить линты безопасности для кода AgentRig — обоснование
`unsafe` ссылкой на решение/инвариант (1.1), Bandit-группа ruff `S` для Python (1.2) и скан
хардкод-секретов (1.3) — и привести наш код к зелёному (догфуд). Исходный контракт — ревизия
карточки B026 в Git (7253a89); согласовано и выбрано на исполнение пользователем 2026-10-29
в составе набора кластеров 1–8.

## User capability

Агент из коробки не оставляет необоснованный `unsafe` и типовых дыр безопасности: опасный
код обязан нести рядом ссылку-обоснование, а типовые уязвимости Python и хардкод-секреты
ловятся гейтом до коммита, а не в ревью.

## Acceptance

Карточка **B026 (1.1–1.3)**, включая её границы. Правила — только внутри `Project`,
измеряемые чисто синтаксически (без вывода типов); возможность уезжает в поставку `init` как
universal ([D053](../Decisions/053.md)/[I020](../Invariants/020.md)) после поведенческой
проверки. Что не проверяется чисто, без ложных срабатываний, остаётся нормой с записанной
причиной (norm-or-choice), а не ослабленным правилом. Наш код приводится к зелёному; пороги и
селекторы не ослабляются ради проходимости. Уровень реализации и границы VAC выбирает
исполнитель (по одному под-правилу за VAC, гейт держится зелёным).
