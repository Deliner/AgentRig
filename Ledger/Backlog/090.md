# B090 — config-check сверяет цели тестов так же, как cargo

## Context

- config-check выводит путь модуля от ближайшего main.rs и сравнивает по префиксу, а cargo фильтрует по подстроке
  полного пути.
- Модули native в voxel-rust подключены через `#[path]` из src/core/lib.rs.
- После переноса в host config-check отклонил цели `game::tests::`, хотя cargo по ним тесты выполнял.

## Proposal

- Путь модуля определяется по дереву `mod` и `#[path]` от корня крейта.
- Цель принимается, если фильтр cargo по ней выбирает тесты файла.
- **AC1.** На фикстуре с `#[path]` принимаются и короткая цель, и полный путь.
- **AC2.** Цель, которая не выбирает тестов файла, отклоняется, как сейчас.
- **AC3.** В voxel-rust цели снова пишутся без префикса `host::`.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

`config-check` принимает те цели тестов, по которым cargo выполняет тесты файла, и не требует подбирать префикс под
устройство крейта.
