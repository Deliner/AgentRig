# B155 — Программы `just read` и `just write` не выходят за пределы проекта

## Context

- 2026-11-19 пользователь об отчёте аудита обходов: «не хочется все твои находки терять… давай их все исправим».
  Затем: «Пока только карточки заведи». Текст сохранён без показа в чате; до выбора в Plan его нужно согласовать.
- Аудит 2026-11-19, пункт C1. `just write` запускает программы без песочницы, с любым путём на машине:
  `just write -- cp x ~/.zshenv` проходит (`Project/command_runner/sandbox.rs`). Проба: хук разрешил.
- Пункт D2. Профиль песочницы `just read` на macOS начинается с `(allow default)`; через `open` или Apple Events
  процесс может запуститься вне песочницы. По документации macOS, не запускалось.

## Proposal

- **AC1.** Программы `just write` пишут только внутри репозитория. Запись вне него не происходит, и агент видит
  отказ.

  Проверка: `just write -- cp x ~/ИМЯ` в проекте после `init` не создаёт файл.
- **AC2.** Процесс внутри песочницы `just read` не может запустить программу вне песочницы, в том числе через `open`
  и Apple Events.

  Проверка: тест песочницы на macOS.

**Границы.** Git внутри `just write` пишет в `.git` как сейчас; правку настроек в `.git` закрывает B157.

## Expected benefit

Команда агента ничего не меняет вне проекта и не запускает процессы мимо песочницы.
