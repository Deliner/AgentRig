# B147 — Первая ветка сразу после `init`

## Context

- 2026-11-19 пользователь: «и пункт второй, который ты подсветил». Пункт второй: первую ветку после `init`
  приходится создавать через `git switch -c`.
- После `init` настройка ещё не закоммичена, и `just feature-start NAME` отказывает: «working tree must be clean;
  preserve or commit pending changes before switching branches». Ветка создаётся на той же вершине базы, поэтому
  изменения потеряться не могут.

## Proposal

- **AC1.** На базе `just feature-start NAME` создаёт ветку и переносит на неё незакоммиченные изменения.

  Проверка: тест на проекте сразу после `init`. Ветка создана, коммит настройки проходит гейт.

**Границы.**

- Запуск не с базы и незавершённая операция Git по-прежнему дают отказ.

## Expected benefit

Первая ветка проекта после `init` создаётся той же командой, что и все следующие.
