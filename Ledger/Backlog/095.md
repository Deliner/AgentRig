# B095 — init исключает lock-файлы из file-size

## Context

- В voxel-rust правило file-size мерило Cargo.lock и package-lock.json, их исключили вручную.
- Эти файлы пишет менеджер пакетов.

## Proposal

- `init` записывает в file-size исключения для Cargo.lock, package-lock.json и uv.lock в любом каталоге.
- Настройки существующих проектов не меняются.
- **AC1.** После `init` большой Cargo.lock в подкаталоге находки не даёт.
- **AC2.** Большой исходный файл рядом с ним находку даёт.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Новый проект не получает находок размера по сгенерированным файлам.
