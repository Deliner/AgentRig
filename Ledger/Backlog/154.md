# B154 — Аргументы разрешённых программ не запускают другой код

## Context

- 2026-11-19 пользователь об отчёте аудита обходов: «не хочется все твои находки терять… давай их все исправим».
  Затем: «Пока только карточки заведи». Текст сохранён без показа в чате; до выбора в Plan его нужно согласовать.
- Аудит 2026-11-19, пункт C2. Запрет `--exec` и `-x` для `git rebase` в `just write` сравнивает начало слова, а git
  принимает сокращение `--exe=` и слитные флаги вроде `-qx`. Проба: git исполнил команду из `--exe`.
- Пункт D1. В `just read` так же обходятся запреты `-O` и `--open-files-in-pager` у `git grep`, например
  `--open-files-in-pa=` и `-iO…`, и `--pre` у `rg`; `rg --hostname-bin` запускает программу. Прослежено по коду,
  поведение программ по их документации.
- Пункт C6. Команды каталога принимают любые аргументы. В Rust-проекте
  `just run test -- --config "target.'cfg(all())'.runner=['sh','-c','id']"` запускает любую программу
  (`Project/project_setup/template.rs:330-346`). Прослежено по коду, cargo по документации.

## Proposal

- **AC1.** Запрещённый флаг программы `just read` или `just write` получает отказ в любой записи, которую принимает
  сама программа: сокращение длинного флага, значение через `=`, слитные короткие флаги. Флаги, которые запускают
  другую программу, запрещены, в том числе `rg --hostname-bin`.

  Проверка: тест хука на примеры C2 и D1.
- **AC2.** Команда каталога отказывает аргументу, который заставляет её программу запустить другой код, например
  `--config` у cargo. Аргументы по назначению команды, например фильтр тестов, работают.

  Проверка: тест на пример C6 и на `just run test -- ИМЯ`.

**Неизвестное.** Как команда каталога описывает допустимые аргументы.

## Expected benefit

Разрешённая программа делает только своё дело и не запускает чужой код.
