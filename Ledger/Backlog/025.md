# B025 — Семантический анализ символов для структурного линтера

## Context

Три пункта тестовой дисциплины остались нормами навыка, а не статическими правилами, по
одной и той же причине — движок структурного линтера синтаксический. TC2/TC4
([B023](../Archive/Backlog/023.md)/[D057](../Decisions/057.md)): не извлекается видимость
символов, не собираются методы и ассоциированные функции, вызовы по получателю (`x.foo()`)
не захватываются, обратный индекс по свободным элементам разбивают glob-импорты,
ре-экспорты, макросы и функции-значения. TC1 ([B024](../Archive/Backlog/024.md)/[D058](../Decisions/058.md)):
ссылки резолвятся до файла, а не до символа, поэтому предмет проверки не отличить от
попутной общей ссылки. Источник — отчёт по итогам B023/B024; согласовано пользователем
2026-10-28.

## Proposal

Дать движку семантический слой разрешения символов для поддерживаемых языков (Rust,
Python), наблюдаемый через новые возможности анализа:

**K1 — разрешение идентичности символа.** Ссылка (квалифицированный путь, вызов метода по
получателю, использование через glob-импорт или ре-экспорт) разрешается в конкретный
объявленный символ-цель, а не только в файл; `use m::*`, `pub use` и цепочки ре-экспортов
проходятся до исходного объявления.

**K2 — видимость объявленного символа.** Для символа определяется его видимость: Rust —
`pub`/`pub(crate)`/`pub(super)`/путь/приватная; Python — соглашение об именах и `__all__`.

**K3 — обратный индекс на уровне символа.** Для символа движок знает множество
ссылающихся на него мест с разделением тестовых и продуктовых; множество методов и
ассоциированных функций учитывается наравне со свободными элементами.

**Границы и существенное неизвестное.** Карточка — об этой возможности движка, а не о
самих правилах. Её прямая окупаемость — TC2/TC4 (B023) становятся реализуемыми без ложных
срабатываний; по итогам следует пересмотреть норму-статус B023. Для TC1 семантика
усиливает сигнал (ссылка до символа вместо файла), но неоднозначность «предмет vs
попутное» из [D055](../Decisions/055.md) — отдельный открытый вопрос, и B024 этим само по
себе не закрывается. Объём большой: начинать спайком, измеряющим полноту разрешения
(ре-экспорт/glob/макросы/типы получателей) и стоимость в гейте ([D035](../Decisions/035.md)).
Возможность уезжает в поставку `init` как universal ([D053](../Decisions/053.md)/[I020](../Invariants/020.md))
только после поведенческой проверки. Проверяются символы внутри `Project`; внешние модули
— вне графа, как сейчас.

## Expected benefit

Движок видит, какой именно символ используется и кем, а не только какой файл на какой
ссылается. Это снимает единственный барьер, делающий TC2/TC4 статическими правилами «из
коробки», и даёт более точный сигнал для возможной статической проверки размещения теста.
