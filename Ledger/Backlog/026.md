# B026 — Линтер безопасности из коробки

## Context

Кластер 1 набора улучшений качества (мозгоштурм 2026-10-29). В духе запрета комментариев
([D037](../Decisions/037.md)): опасное требует явной ссылки-обоснования, а типовые дыры
безопасности ловятся готовыми инструментами. Согласовано пользователем 2026-10-29.

## Proposal

- **1.1 `unsafe`-обоснование.** Каждый `unsafe`-блок/функция в Rust обязаны нести рядом
  ссылку `DECISION:`/`INVARIANT:`; иначе — находка с ремонтным навыком. *[правило]*
- **1.2 Bandit для Python** через ruff (группа `S`): `shell=True`, `eval`/`exec`,
  инъекции, хардкод-креды. *[конфиг]*
- **1.3 Скан хардкод-секретов** по паттернам (ключи/токены), отдельно от typos. *[правило]*

**Границы.** Правила — только внутри `Project`; возможность уезжает в поставку `init` как
universal ([D053](../Decisions/053.md)/[I020](../Invariants/020.md)) после поведенческой
проверки; что чисто не проверяется без ложных срабатываний — норма с записью причины
(norm-or-choice). Догфуд: наш код приводится к зелёному.

## Expected benefit

Агент не оставляет необоснованный `unsafe` и типовых дыр безопасности; новый проект
защищён сразу из коробки.
