# B092 — Базовая линия следует за переименованием

## Context

- Базовая линия хранит находки по пути.
- Если перенести файл с принятой находкой, `lint-baseline` отказывает, как при новой находке.
- Тогда базовую линию приходится удалять и записывать заново.

## Proposal

- Если Git распознал перенос файла, `lint-baseline` переносит его принятые находки на новый путь.
- Рост числа находок по-прежнему отклоняется.
- **AC1.** Переименование файла с принятой находкой записывается.
- **AC2.** Переименование, при котором добавилась находка, отклоняется.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Перенос файла с принятыми находками не требует удалять и заново записывать базовую линию.
