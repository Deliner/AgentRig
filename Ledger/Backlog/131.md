# B131 — Готовые lint-ы Clippy для форм списка V

## Context

Пользователь 2026-11-13 разобрал список V, файл list-5-candidates.md, и согласился включить в профиль Clippy рига
готовые lint-ы для его форм: «по всем трем пунктам я согласен», «обязательно проведи замеры». Профиль рига включает
lint-ы поштучно, группы pedantic и restriction в нём не включены, поэтому эти lint-ы сейчас молчат.

Сверка с правилами рига при сохранении карточки показала, что часть форм у рига уже есть, и включать для них Clippy
значит завести второго владельца: V-4 ловит `disabled-test`, V-26 ловит `disabled-raii`, V-21 и V-22 закрывают
`comments`, который запрещает документ-комментарии, и `unsafe-justification`. V-23 и заведомо бесконечную часть V-30
ловят lint-ы Clippy из набора по умолчанию.

## Proposal

Профиль Clippy рига и проектов, которые ставит `init`, получает lint-ы из таблицы, прошедшие замер.

| Форма | Lint Clippy |
| --- | --- |
| V-12 `Default::default()` вместо имени типа | `default_trait_access` |
| V-16 десятичный литерал из пяти и более цифр без `_` | `unreadable_literal` |
| V-17 `^` между литералами вместо степени | `suspicious_xor_used_as_pow` |
| V-18 `to_ne_bytes` и `from_ne_bytes` | `host_endian_bytes` |
| V-19 крупный массив на стеке | `large_stack_arrays` |
| V-30 цепочка, которая может не кончиться | `maybe_infinite_iter` |

- **AC1. Шум.** Протокол записан до первого замера: находка верна, если к месту применима опасность из карточки списка
  и не подходит её пункт «Оставить». Стиль чужого проекта не оправдание. Lint-ы гоняются на копиях рига и voxel-rust:
  сборка чужого проекта запускает его код. Если находок много, проверяется выборка, и правило выборки записано
  заранее. Если верных меньше 90%, lint не включается, а причина записывается. Если находок нет, lint включается по
  D151.
- **AC2. Польза.** Для каждого включённого lint-а показаны настоящие находки: путь, строка и что там может сломаться,
  или прямо записано, что находок нет.
- **AC3.** Включённый lint стоит в команде `clippy` рига и в профиле, который ставит `init`; находки в коде рига
  исправлены, и гейт рига проходит.

**Границы.** У каждой формы один владелец: lint, который повторяет правило рига, не включается. Clippy рига по-прежнему
не смотрит тестовый код. Неизвестно, сколько находок даст каждый lint.

## Expected benefit

Лишний ноль в литерале, XOR вместо степени, порядок байт платформы, переполнение стека, тип, выведенный из контекста,
и цепочка без конца ловятся при сборке, а не после выпуска.
