# B073 — большой текст внутри кода: многострочный литерал вместо отдельного файла (Rust)

## Context

Идея из интервью 7 ноября 2026, в корпусе не измерялась, исследование её не рассматривало.
SQL, JSON, HTML или шаблон на десятки строк лежит строковым литералом прямо в файле кода.
Карточка заведена как идея; в Plan не выбрана.

## Proposal

Иллюстрация:

```rust
const REPORT_QUERY: &str = r#"
    SELECT …
    … ещё 40 строк …
"#;
```

Сегодня гейт молчит. Ремонт механический:

```rust
const REPORT_QUERY: &str = include_str!("report.sql");
```

У текста появляются своя подсветка, свои проверки и своя история правок, файл кода
остаётся кодом.

- **AC1 — большой литерал отмечается.** Строковый литерал длиннее заданного числа строк в
  коде Rust → находка на строке литерала с подсказкой `include_str!`.
- **AC2 — тесты не отмечаются.** Тот же литерал в тестовом коде, где ожидаемый вывод
  держат в коде намеренно → не находка.

**Границы и неизвестное.** Порог неизвестен, сорок строк в примере только иллюстрация;
частота на корпусе неизвестна. Python позже: ремонт там сложнее. Новый `kind:` →
двухфазная доставка по D051; решение при доставке.

## Expected benefit

Данные лежат отдельным файлом, код читается как код.
