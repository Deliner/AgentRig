# B096 — Рёбра зависимостей через вызовы методов

## Context

- Вызов `x.foo()` ребра не даёт.
- D059 отверг вывод типов: он слишком тяжёл для быстрого гейта и переносимой установки.
- Пробел я заметил в своём оракуле зависимых, а не в находке рига. Сколько рёбер теряется на реальных проектах, не
  измерено.

## Proposal

- Сначала замер на voxel-rust и AgentRig: какие зависимости между каталогами видны только через вызовы методов.
- Затем подтверждённые случаи, которые можно определить без вывода типов, дают ребро к каталогу метода.
- Если остальные случаи требуют вывода типов, решение за пользователем.
- **AC1.** Есть отчёт с числом потерянных рёбер в обоих проектах.
- **AC2.** Подтверждённый случай на фикстуре даёт ребро.
- **AC3.** Если ничего не подтвердилось, карточка закрывается отчётом.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Бюджеты и циклы считаются по реальным зависимостям.
