# B071 — длинное логическое выражение: больше трёх частей через `&&` и `||` (Rust, Python)

## Context

Идея из интервью 7 ноября 2026, в корпусе не измерялась, исследование её не рассматривало.
Правило named-if заставляет дать условию `if` имя, но не ограничивает, что лежит под этим
именем: `let ready = …` может держать выражение из пяти частей, и гейт молчит. Условия
`while` и охранные условия веток `match` named-if сегодня не проверяет. Аналоги: pylint и
ruff, правило PLR0916, допускают до пяти частей и только в `if`; checkstyle для Java
допускает до трёх операторов; в clippy счётного правила нет. Карточка заведена как идея;
в Plan не выбрана.

## Proposal

Иллюстрация:

```rust
let ready = user.active && !user.banned || admin && session.valid() && !maintenance;
if ready { … }

while !queue.is_empty() && budget > 0 && !cancelled.load(Relaxed) && retries < 3 { … }
```

Сегодня оба места проходят гейт: пять частей, и не видно, к кому относится
`!maintenance`. По карточке: находка на каждом из двух выражений. Ремонт дробит выражение
на куски с именами:

```rust
let regular = user.active && !user.banned;
let elevated = admin && session.valid() && !maintenance;
let ready = regular || elevated;
```

После ремонта видно, что техработы блокируют только админа.

- **AC1 — длинное выражение отмечается.** В любом месте кода, в условиях `if` и `while`,
  в охранных условиях `match`, в `let` и в возвращаемом значении, выражение, где больше
  трёх частей соединены `&&` и `||`, в Python `and` и `or` → находка на строке выражения.
- **AC2 — короткие выражения не отмечаются.** Выражение из трёх частей и меньше → не
  находка.

**Границы и неизвестное.** Порог три взят из показанного примера; окончательный выбирается
замером на корпусе. Как считаются части внутри скобок и в цепочках `if let … &&`,
решается при выборе. Новый `kind:` → двухфазная доставка по D051; решение при доставке.

## Expected benefit

Каждое условие читается с одного взгляда. Обход named-if через имя над длинным выражением
закрыт, `while` и охранные условия `match` получают ту же дисциплину.
