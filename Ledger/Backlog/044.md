# B044 — Tier B: пять правил-кандидатов из отчёта воркфлоу

## Context

Тот же отчёт воркфлоу-ревью (10 ревьюеров Sonnet, run `wf_b944977a-5c3` / task `we6yjitjd`). Tier B —
правдоподобные кандидаты (1–2 ревьюера, умеренная ценность), near-zero-FP при аккуратной формулировке.
Пользователь согласовал все пункты Tier A и Tier B 2026-11-01 на исполнение через догфудинг. Исполняется
после Tier A ([B043](043.md)).

## Proposal

До пяти новых правил `init`; каждое — новый вид + навык ремонта (двухфазная доставка), если при реализации
подтвердится near-zero-FP. Часть может честно оказаться нормой.

- AC1 **unchecked-index**: индексация/срез `x[0]`, `x[1..]`, `x[a..b]`, `&s[1..]`, `map[key]` вне тестов
  без обоснования — находка (паникующий путь, прямой аналог `panic-path` [D082](../Decisions/082.md),
  механизм `justified` [D065](../Decisions/065.md)). Эскейп — `// DECISION:`. *[правило]*
- AC2 **disabled-RAII**: `tempfile::…keep()`/`.into_path()`, `mem::forget`, `ManuallyDrop::new`,
  `Box::leak` вне тестов без обоснования — отключение авто-очистки. *[правило]*
- AC3 **toctou / path-exists**: `.exists()`/`.is_file()`/`.is_dir()` по пути с последующим действием по
  тому же пути (TOCTOU); плюс `Path::exists()` превращает ошибку I/O (EACCES/EIO) в `false`. *[правило,
  возможно норма при высоком FP]*
- AC4 **lossy-int-cast**: `as` к более узкому или знаковому целому (нужен список сужающих пар). Умеренный
  FP → по итогу правило либо норма (norm-or-choice, бар [D035](../Decisions/035.md)). *[правило/норма]*
- AC5 **sibling-cycle**: взаимные зависимости файлов-соседей внутри одного каталога (взаимный `pub use`) —
  расширение `directory-architecture` ([D070](../Decisions/070.md)/[D079](../Decisions/079.md)) на
  внутрикаталожные циклы; нового вида/навыка не добавляет. *[правило, расширение существующего]*

**Границы.** Формулировки с near-zero-FP; где вскроется высокий FP (lossy-cast, TOCTOU) — честно норма,
бар [D035](../Decisions/035.md) не ослабляется. Притворных инвариантов нет. Наш код приводится к зелёному
(догфуд). Объём каждого AC и очерёдность — за исполнителем.

## Expected benefit

Дополнительный охват панических (индексация), ресурсных (RAII), файловых (TOCTOU) и детерминизм-смеллов;
`sibling-cycle` закрывает внутрикаталожные циклы, которых не видит текущий граф. Переносимо на любой
Rust-проект, agent-native.
