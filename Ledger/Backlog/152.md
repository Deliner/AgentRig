# B152 — Хук проверяет каждый вызов инструмента и отказывает, если проверить не может

## Context

- 2026-11-19 пользователь об отчёте аудита обходов: «не хочется все твои находки терять… давай их все исправим».
  Затем: «Пока только карточки заведи». Текст сохранён без показа в чате; до выбора в Plan его нужно согласовать.
- Аудит 2026-11-19, пункт A1. Хук зарегистрирован только на `Bash|Shell|exec_command|apply_patch|Edit|Write`
  (`.claude/settings.json`, `.codex/hooks.json`), а неизвестное имя инструмента пропускает
  (`Project/agent_hooks/mod.rs:113-117`). Monitor запускает команду оболочки, NotebookEdit пишет `.ipynb`,
  инструменты MCP пишут файлы. Проба: на Monitor и NotebookEdit хук молчит.
- Пункт A6. Если лаунчер хука не запустился, команда хука завершается с кодом 126 или 1, а Claude Code блокирует
  вызов только при коде 2 или отказе в JSON (`Project/project_setup/adapters.rs:34`, `tooling/worker/run:8`).
  Проба: без `.agentrig/bin/agentrig` код 126; поведение Claude Code по его документации.
- Пункт A7. На macOS путь в другом регистре, например `ledger/State.md`, меняет тот же файл, но маршруты к навыкам
  его не узнают (`Project/shared/paths/glob_patterns.rs:17`). Прослежено по коду.

## Proposal

- **AC1. Каждый инструмент проходит хук.** Хук вызывается на каждый инструмент Claude Code и Codex. Инструмент,
  который запускает команды или пишет файлы, проходит те же проверки, что оболочка и правка файлов, либо получает
  отказ. Инструмент, который хук не знает, получает отказ с его именем.

  Проверка: тест хука на Monitor, NotebookEdit и вымышленный инструмент MCP; проба Claude Code в проекте после `init`.
- **AC2. Сбой запуска хука даёт отказ.** Если лаунчер или установленный рантайм отсутствует или не исполняется,
  вызов инструмента не выполняется, и агент видит причину.

  Проверка: копия проекта после `init` без лаунчера и без бита исполнения; команда хука отказывает в форме, которую
  Claude Code и Codex считают блокировкой.
- **AC3. Регистр не обходит маршруты.** Путь, который файловая система считает тем же файлом, получает те же
  маршруты, в каком бы регистре его ни написали.

  Проверка: тест маршрута на `ledger/State.md` на файловой системе без различия регистра.

**Границы.** Инструменты, которые не запускают команд и не пишут файлов, работают как сейчас.

**Неизвестное.** Какие инструменты Claude Code и Codex не запускают команд и не пишут файлов.

## Expected benefit

Нет инструмента или сбоя, при котором действие агента проходит мимо проверок рига.
