# B088 — Находки архитектуры показывают свои рёбра

## Context

- Находка бюджета зависимостей называет только число.
- Находка цикла показывает одно место, и оно перескакивает между файлами.
- Зависимых пришлось искать своим оракулом, а он не видит корни крейтов.
- Одиночная находка печатается в другом формате, чем групповая.
- README архитектуры молчит о полях `dependents` и `zone`.

## Proposal

- Находка бюджета перечисляет зависимые каталоги, у каждого пример файл:строка.
- Находка цикла называет каждое своё ребро с файлом и строкой и одинакова между запусками.
- Отдельная команда показывает входящие и исходящие рёбра каталога.
- Одиночная и групповая находки печатаются одинаково.
- README описывает все поля контракта.
- **AC1.** На фикстуре с превышенным бюджетом находка называет каждого зависимого.
- **AC2.** Два запуска на одном дереве дают одинаковую находку цикла.
- **AC3.** На voxel-rust команда рёбер для src/core/world выводит столько зависимых, сколько считает lint.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Находку архитектуры можно исправить по её тексту, без собственного оракула рёбер.
