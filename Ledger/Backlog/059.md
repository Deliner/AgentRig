# B059 — discarded-result: отброшенный исход команды `.status()?;` / `.output()?;`

## Context

Исследовательская дуга (`coverage-map.md` шаг 2 «discarded-outcome (b)»). Инструкция
`cmd.status()?;` или `cmd.output()?;` пробрасывает только ошибку запуска, а код завершения и
вывод команды молча выбрасываются: провалившаяся команда выглядит успешной. Форма
синтаксическая, как `.ok();` в D090. Собственный код: `shared/vcs/git.rs` и
`shared/vcs/directories.rs` используют значения (`let status = …`, `let output = …`) — ожидается
0 находок (проверяется при доставке). Авторизовано 2026-11-04 (/goal).

## Proposal

Расширить существующий вид `discarded-result`:

- **AC1.** Выражение-инструкция, чьё значение отбрасывается и чьё выражение — `<…>.status()?`
  или `<…>.output()?`, вне тестов, без строки-обоснования над инструкцией → находка. Сохранённое
  значение (`let s = …status()?;`), использование как операнда или аргумента
  (`….status()?.success()`) — не находки.

**Границы и неизвестное.** Изменение существующего детектора → двухфазная доставка (D051);
decision, расширяющий D090, — при доставке; навык `handle-discarded` дополняется.

## Expected benefit

Провалившаяся внешняя команда не остаётся незамеченной. Переносимо.
