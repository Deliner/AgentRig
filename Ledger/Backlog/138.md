# B138 — Свой навык для каждого lint-а профиля Clippy

## Context

- Сейчас любая ошибка Clippy ведёт на общий навык `repair`: «найди причину и почини, не ослабляя требование». У
  каждого правила lint рига есть свой навык именно для этого правила.
- Агент чинит ошибку Clippy по тексту самого Clippy: подсказка и ссылка на документацию lint-а. Стандарта рига по
  D151 и того, когда исключение со ссылкой на решение допустимо, этот текст не знает.
- В профиле рига 37 lint-ов Clippy. Часть из них ловит то же, что правила рига со своими навыками. Например, навык
  `handle-panic` правила `panic-path` уже называет `unwrap_used`, `expect_used` и `panic`.
- B137 делает каждое сообщение Clippy находкой lint с именем правила. Сейчас гейт видит только упавшую команду, и
  указать навык для отдельного lint-а негде.
- 2026-11-14 пользователь попросил отдельную карточку на навыки для правил Clippy.

## Proposal

Находка Clippy по lint-у из профиля рига ведёт на навык, который объясняет, как исправить именно этот lint.

- **AC1. Навык для каждого lint-а профиля.**
  - Находка по lint-у профиля называет навык этого lint-а в обычном выводе lint и в `--json`.
  - Навык называет lint и говорит, как переписать код, чтобы запрет выполнялся. Ещё он говорит, когда допустимо
    исключение со ссылкой на решение по навыку `justify-allow`.
  - После `init` файл навыка есть в проекте, как у навыков правил рига.

  Проверка: для каждого lint-а профиля находка ведёт на существующий навык, который называет этот lint. В проекте
  после `init` код с `as` даёт находку `clippy::as_conversions` с навыком, где описан `as_conversions`.
- **AC2. Одна починка, один навык.**
  - Если lint ловит то же, что правило рига, находка ведёт на навык этого правила, и навык называет lint.
  - Lint-ы с одной и той же починкой делят один навык.
  - Второго навыка с тем же разбором не появляется.

  Проверка: находка `clippy::unwrap_used` ведёт на `handle-panic`.
- **AC3. Остальные находки.** Находки вне профиля ведут на общий навык, как в B137. Сюда входят lint-ы, которые
  ошибками делает `-D warnings`, и ошибки сборки.

  Проверка: неиспользуемая переменная, lint `unused_variables`, ведёт на общий навык.

**Границы.**

- Карточка опирается на B137 и выполняется после неё.
- Навыков для lint-ов вне профиля в карточке нет. Это касается и lint-ов, которые проект сам запретил в
  `[lints.clippy]`.
- Профиль и уровни lint-ов не меняются.

## Expected benefit

Агент с ошибкой Clippy получает навык рига: как исправить этот lint по стандарту рига и не ослабить запрет.
