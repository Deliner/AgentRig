# B148 — AGENTS.md и CLAUDE.md с одним текстом

## Context

- 2026-11-19 пользователь: «я сразу хочу сделать, чтобы у нас автоматически генерировались agents MD и Claude MD,
  и на коммитах была проверка, что они эквивалентны, что они не разъезжаются. В смысле, у них контент одинаковый».
  Ещё он попросил посмотреть AGENTS.md и CLAUDE.md проекта voxel-rust: «там прям боевой сетап».
- Сейчас `init` пишет `AGENTS.md`, а `.claude/CLAUDE.md` содержит одну строку `@../AGENTS.md`, по которой Claude Code
  подставляет AGENTS.md. В риге так же.
- В voxel-rust оба файла лежат в корне с одинаковым текстом, и проверка `rules-same` роняет коммит, если они
  различаются.
- Шаблон `init` отстал от рига: в нём написано `just run read` и `just run write`, хотя в проекте есть рецепты
  `just read` и `just write`. Проба 2026-11-19: Claude Code в проекте после `init` следовал шаблону.
- 2026-11-19 пользователь выбрал два файла и проверку, как в voxel-rust, а не импорт.

## Proposal

- **AC1.** `init` пишет в корень `AGENTS.md` и `CLAUDE.md` с одинаковым содержимым. `.claude/CLAUDE.md` с импортом
  больше не создаётся, иначе Claude Code прочитает правила дважды. В риге сделано так же.

  Проверка: тест `init` и тест сравнения с ригом.
- **AC2.** Коммит, в котором эти файлы различаются, не проходит. Ошибка называет абсолютный путь к навыку, который
  объясняет, как это исправить.

  Проверка: тест гейта.
- **AC3.** Шаблон берёт из voxel-rust общие правила, без правил самой игры:
  - строку о том, что оба файла содержат один текст;
  - раздел State;
  - `just --list`;
  - команду каталога для повторного запуска, заведённую до второго использования;
  - `just check --staged`;
  - правило запускать только нужные проверки;
  - раздел Rust 1.100 для Rust-проектов.

  Лимиты прежние: 70 непустых строк, ширина 120. Проверка: lint проекта после `init`.

## Expected benefit

Codex и Claude Code в проекте после `init` получают одни и те же проверенные правила, и разъехаться они не могут.
