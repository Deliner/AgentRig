# B146 — Команды для чтения работают в песочнице без записи

## Context

- 2026-11-19 пользователь: «давай починим тогда пункт первый, который ты показал из неудобства». Пункт первый: в
  песочнице без записи не работает `just read`.
- Проба 2026-11-19: Codex с `-s read-only` в пустом проекте после `init`. Хук отказал прямой команде `cat` и
  направил к рецептам `just`. `just run read -- cat …` упал с `Operation not permitted` на каталоге
  `.cache/runtime/jobs/run-*`: каждый запуск команды каталога создаёт папку журнала (D092), а песочница запрещает
  запись. Codex не смог прочитать обязательный навык и остановился. Файлы Codex читает только через оболочку,
  поэтому в такой песочнице он не может ничего.

## Proposal

- **AC1.** В песочнице агента без права записи `just read -- PROGRAM`, `just lint`, `just config-check` и
  `just resume` выполняются и печатают результат.

  Проверка: Codex с `-s read-only` в пустом проекте после `init` получает вывод каждой команды.

**Границы.**

- Команды, которые пишут файлы, в такой песочнице по-прежнему отказывают.
- Вне песочницы журнал запусков работает как раньше.

## Expected benefit

Агент в песочнице без записи читает файлы, навыки и проверки через команды рига и может выполнять его правила.
