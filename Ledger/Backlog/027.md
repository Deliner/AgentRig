# B027 — Строгие профили clippy/ruff/mypy из коробки

## Context

Кластер 2 набора улучшений качества (мозгоштурм 2026-10-29). Урок [D059](../Decisions/059.md):
типовую работу делают clippy/mypy/ruff — усиливаем их профиль, а не строим свой вывод
типов. Согласовано пользователем 2026-10-29.

## Proposal

- **2.1 Safe-профиль clippy:** `unwrap_used`, `expect_used`, `panic`, `todo`,
  `unimplemented`, `unreachable`, `dbg_macro`, `print_stdout`, `print_stderr`; в тестах
  разрешено. *[конфиг]*
- **2.2 `mypy --strict`** по Project. *[конфиг]*
- **2.3 ruff-группы** `B` (bugbear), `SIM`, `PERF`, `UP`. *[конфиг]*

**Границы.** Догфуд = привести наш код к зелёному; объём правок — явный неизвестный, может
разбиться на под-VAC. Профиль уезжает в поставку `init`
([D053](../Decisions/053.md)/[I020](../Invariants/020.md)). Пороги не ослаблять ради
проходимости.

## Expected benefit

Новый проект сразу получает строгую типовую проверку и анти-паттерн-линт без ручной
настройки.
