# B042 — Анти-переусложнение: уже обеспечено комплексом правил сложности + нормой (карта покрытия)

## Context

Набор II улучшений качества (переносимо на любое приложение, agent-native), согласован
пользователем 2026-10-31 на автономное исполнение по моей рекомендации. Последний кластер — C8
«анти-переусложнение». Это область, где AgentRig уже силён: в репозитории УЖЕ поставляется комплекс
правил сложности и норма проектирования, покрывающие переусложнение/over-engineering. Задача C8 —
честно отделить уже покрытое от возможного нового и не добавить избыточного (добавление дублирующего
правила — само по себе переусложнение).

## Proposal

C8 **уже обеспечен** поставляемым комплексом правил сложности и нормой `complexity-discipline` — **без
нового правила**. Решение [D087] фиксирует карту покрытия и почему остаток — норма.

- AC1: карта покрытия (всё из коробки): длина функции → `function-lines`; вложенность → `nesting-depth`
  ([D061](../Decisions/061.md)); ветвления → `branch-budget` ([D063](../Decisions/063.md)); число
  параметров → `parameter-count`; булевы флаги-параметры → `boolean-parameter`
  ([D062](../Decisions/062.md)); осмысленные условия → `named-if-condition`; размер файла/каталога →
  `file-size`/`directory-entries`; каталоги-свалки → `dump-name` ([D072](../Decisions/072.md)); god-object/
  типы фич/циклы/fan-in/качество `purpose` → `directory-architecture`
  ([D070](../Decisions/070.md)/[D079](../Decisions/079.md)); дисциплина проектирования (ранги simplest-first,
  Indirection/Variability/Supporting machinery/Completion) → норма `complexity-discipline`. *[покрыто]*
- AC2: остаток C8 — норма: спекулятивная общность (one-variant enum, single-impl trait, ненужная
  обёртка), лишняя индирекция/слои, мёртвый код — семантичны или высоколожны (`#[non_exhaustive]`/FFI/
  легитимные адаптеры), что против near-zero-FP бара [D035](../Decisions/035.md); уже воплощены разделом
  «Reject changes that only appear to improve the result» и ранговой лестницей `complexity-discipline`. *[норма]*
- AC3: нового вида правила/навыка нет → набор видов правил и навыков не меняется
  ([I020](../Invariants/020.md) сбалансирован); наш код не меняется. Добавлять ещё правило/норму,
  дублируя покрытое, — само переусложнение; C8 само-консистентно решается картой покрытия. *[норма]*

**Границы.** Только решение-карта + норма. Нового правила нет (one-variant enum синтаксически детектируем,
но FP против D035 → не правило; остальное семантично). Притворный инвариант не вводится.

## Expected benefit

Явная, переносимая карта: анти-переусложнение уже обеспечено из коробки комплексом правил сложности
(`function-lines`/`parameter-count`/`nesting-depth`/`boolean-parameter`/`branch-budget`/`named-if-condition`/
`file-size`/`directory-entries`/`dump-name`/`directory-architecture`) и нормой `complexity-discipline`.
Набор II закрыт честно, без избыточной машинерии.
