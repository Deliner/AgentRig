# B128 — Rust 1.100 как стандарт рига и проектов

## Context

Rust 1.100 вышел 2026-11-12. Запрос пользователя 2026-11-13:

- «Найди список новых фичей в rust 1.100… проведи на него миграцию проекта и сделай это новым стандартом»;
- «А мы можем сделать единый источник истины для версии? init тоже требует 1.100 для проектов. Надо еще в agents.md
  пометить…»;
- «Плюс правила lint рига на старые формы».

Сейчас риг закреплён на Rust 1.98.1. Номер версии записан в одиннадцати местах: команды гейта, bootstrap, сборка
рантайма, CI, README и тестовые фикстуры. init не проверяет версию Rust у проекта.

## Proposal

**AC1.** Риг собирается, проходит rustfmt, Clippy и тесты на Rust 1.100.0. Установленный рантайм собран на 1.100.0 и
закреплён в `stable.txt`. Признак: полный гейт проходит без новых `allow` и `expect` и без ослабления порогов.

**AC2.** Код рига использует новые формы там, где они подходят:

- `trim_prefix` и `trim_suffix` вместо `strip_*(..).unwrap_or(..)`;
- `DropGuard` вместо ручных охранников `Drop` в тестах `change_delivery`.

Признак: на коде рига правила AC8 дают находки только при ссылке `DECISION:`.

**AC3.** В `Project/Cargo.toml` рига стоит `[lints.cargo] unused_dependencies = "deny"`. Признак: лишняя зависимость
останавливает гейт. После её удаления гейт проходит.

**AC4.** В корневом `.cargo/config.toml` рига задан карантин новых версий: `global-min-publish-age = "3 days"`.
Признак: при обновлении lock-файла cargo не берёт версию, опубликованную менее трёх дней назад.

**AC5.** Версия Rust записана в одном файле, `rust-toolchain.toml` в корне рига. Оттуда её берут:

- команды гейта, bootstrap, сборка рантайма, CI и тестовые фикстуры;
- init и doctor, через версию, встроенную при сборке рига.

Чтобы сменить версию, достаточно поправить одну строку. Признак: номер версии встречается только в этом файле и в
заголовке перечня AC7. Не считаются Archive, Assets и неизменные формулировки решений.

**AC6.** `init --language rust` требует от проекта Rust не ниже версии рига. init запускает `rustc --version` в
каталоге проекта, поэтому учитывает собственный `rust-toolchain.toml` проекта. Если Rust нет или он старее, init
останавливается до записи файлов и печатает:

- найденную версию;
- требуемую версию;
- способ обновиться: `rustup update` или правка toolchain-файла проекта.

`doctor` в уже настроенном проекте выполняет ту же проверку и сообщает о том же отказе. Python-проектов проверка не
касается. Признак: со старым Rust init отказывает и не создаёт файлов, на 1.100 проходит. doctor различает оба случая.

**AC7.** В AGENTS.md рига появляется короткий раздел: используем все возможности Rust 1.100, где они уместны. Дальше
идёт перечень новинок, по одной строке на каждую. init пишет тот же раздел в AGENTS.md нового Rust-проекта. Цель:
модель, которая не знает 1.100 по обучению, всё равно пишет современный код.

Черновик перечня:

- тип `!` стабилен, `Infallible` теперь его псевдоним;
- `core::mem::DropGuard`: действие при выходе из области, `dismiss` его отменяет;
- `trim_prefix` и `trim_suffix` у `str`, срезов и `Path`;
- `bool::toggle`, `Vec::from_fn`, `Box::map`, `Rc::map`, `Arc::map`, `Box::take`;
- API аллокаторов: `Allocator`, `Global`, `Box::new_in`, `Vec::new_in`;
- `[lints.cargo]` в `Cargo.toml`, `global-min-publish-age` в `.cargo/config.toml`.

Признак: перечень в обоих AGENTS.md совпадает, при расхождении проверка рига падает.

**AC8.** Lint рига находит старые формы, у которых в 1.100 есть прямая замена. Находка показывает место, старую форму
и новую. Как и в других правилах, находку можно оставить, если над строкой стоит ссылка `DECISION:`. Правила работают
в риге и в конфигурации lint, которую init создаёт для Rust-проектов. `lint-rules` их описывает.

| Старая форма | Новая форма |
| --- | --- |
| `x.strip_prefix(p).unwrap_or(x)`, то же с `strip_suffix` | `x.trim_prefix(p)`, `x.trim_suffix(p)` |
| `Infallible` | `!` |
| `(0..n).map(f).collect::<Vec<_>>()` | `Vec::from_fn` с той же длиной и функцией |

Признак: для каждой формы нарушающий фрагмент даёт находку с заменой, а исправленный не даёт.

**Границы.**

- init и doctor не правят ни `Cargo.toml`, ни toolchain проекта. Как обновляться, решает сам проект.
- Карантин и `unused_dependencies` действуют только в риге. init не пишет их проектам.
- AC8 не ловит формы, которые нельзя распознать без типов. Например, `x = !x` для `bool` вместо `toggle` и ручные
  охранники `Drop`.
- voxel-rust не трогаем.
- Edition остаётся 2024.
- Перечень AC7 ограничен новинками 1.100: пользователь 2026-11-13 «Давай оставим только 1.100».

## Expected benefit

Версия Rust меняется в одном месте. Риг и проекты пишутся на актуальном Rust. Модель без знаний о 1.100 видит новинки
в AGENTS.md, а lint подсказывает ей замену старой формы.
