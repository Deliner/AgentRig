# B109 — Оракул cargo привязан к своему файлу

## Context

- Пользователь 2026-11-11 одобрил записать идею в Backlog без срока.
- По [D157](../Decisions/157.md) memory-check ищет отмеченную функцию оракула cargo по концу имени цели в связанном
  файле. Отмеченную функцию с тем же локальным именем в другом файле, которую на деле запускает cargo, memory-check
  не замечает. D157 отклонил вариант, который выводит путь модуля файла из дерева `mod` и требует, чтобы цель была
  этим путём плюс имя функции.

## Proposal

Риг ищет тест важного правила именно в том файле, который указан у правила, и тест из другого файла не засчитывает.

- **AC1.** Оракул cargo проходит memory-check, только если его цель ведёт к функции в связанном файле.
- **AC2.** Оракул, цель которого ведёт в другой файл, memory-check не пропускает.

## Expected benefit

Тест с тем же именем в другом файле не может обмануть проверку инвариантов.
