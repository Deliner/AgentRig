# B111 — Вложенное необязательное значение ловит только Clippy

## Context

- Открытая находка P114: запись `Option<Option<T>>` останавливают и правило `ambiguous-option`, и линт Clippy
  `option_option`. Получается две ошибки об одном и том же, вопреки границе [B106](../Archive/Backlog/106.md)
  «у каждой формы один владелец».
- Пользователь 2026-11-11 решил оставить единственным владельцем этой формы Clippy, одобрил карточку и выбрал её в
  работу сразу после P115.

## Proposal

У записи `Option<Option<T>>` один владелец, Clippy.

- **AC1.** На записи `Option<Option<T>>` коммит останавливает только Clippy, ошибка одна.
- **AC2.** Правило `ambiguous-option` по-прежнему ловит `Option<bool>`, то есть значение «да, нет или неизвестно».

## Expected benefit

Агент получает одну ошибку на одну проблему.
