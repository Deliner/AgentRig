# B161 — Индекс в литерал массива вычисляет все элементы

## Context

- 2026-11-19 пользователь прислал ревью voxel-rust на ревизии `2304625` и попросил: «Посмотри, возможно на основе
  этого можно новых карточек наделать … для AST линтеров и в целом для процесса». О показанных черновиках:
  «Остальные можешь сохранить».
- Ревью, шаблон 2: `[values.clone().min(), values.max()][end]` в `src/tools/control/resources/light/feed.rs:189`
  вычисляет оба элемента ради одного; `end` принимает 0 и 1. В этой ревизии одно место. Метод с таким именем может
  быть пользовательским, а побочные эффекты элементов намеренными.

## Proposal

- **AC1.** Литерал массива, индексированный не литералом, где элементы содержат вызовы, даёт ошибку lint. Навык
  предлагает `match` или `if`, чтобы вычислялся только нужный элемент.

  Проверка: тест lint на пример из ревью.

## Expected benefit

Код не вычисляет значения, которые сразу выбрасывает.
