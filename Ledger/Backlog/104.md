# B104 — init отвечает за пороги Clippy в clippy.toml

## Context

- Пороговые значения нельзя передать флагами командной строки Clippy. D132 и D137 отказывались трогать файл
  настроек проекта.
- Источник: правило II-21 с порогом 1 и проверки экспортного API из списков запретов пользователя от 2026-11-10; D151.
- Вместе с этой карточкой исполнитель исправляет ещё одно несоответствие стандарту без нового правила: выбор
  изменённых файлов в гейте возвращает `Option`, где `None` значит «полный прогон»; по type-driven-discipline это
  должен быть enum.

## Proposal

- **AC1.** Структура с двумя полями `bool` не проходит проверку. Семь мест в риге исправлены, например `Observation` с
  флагами слияния и rebase становится enum.
- **AC2.** Проверки имён и типов Clippy действуют и на публичный API. Одно место в риге исправлено.
- **AC3.** Если в проекте уже есть свой clippy.toml, его настройки сохраняются, а пороги рига тоже действуют.

**Границы.**

- Неизвестно, как совместить файл рига с файлом проекта. Один из вариантов `CLIPPY_CONF_DIR`.

## Expected benefit

Недопустимые сочетания флагов нельзя записать ни в риге, ни в проектах.
