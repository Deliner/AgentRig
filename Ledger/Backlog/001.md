# B001 — Исправление конфигурации без блокировки агента

## Context

**Исходный запрос.** Вы сообщили о случае, когда ошибка в `agentrig.yaml` заблокировала даже действия, необходимые для её исправления. Нужно обеспечить восстановление в текущей агентской сессии.

**Основание.** [Предыдущая редакция B001](https://github.com/Deliner/AgentRig/blob/349f366c1c35277702e7a43f1fda0edee23f7646/Ledger/Backlog/001.md) и описанный вами сбой на версии 0.3.0. Наличие бага в текущей версии в этом проходе заново не проверялось.

## Proposal

**Пользовательский сценарий:** ошибка конфигурации → агент получает понятную причину → читает и исправляет файл → продолжает обычную работу; остальные незавершённые изменения сохраняются.

**Критерии приёмки**

| ID | Ситуация / действие | Ожидаемый результат |
|---|---|---|
| K1 | Файл отсутствует, YAML повреждён, указано неизвестное поле либо некорректные настройки команд или проверок | Диагностика называет файл и действительную причину. Поле или место ошибки указываются, когда эти сведения доступны. Ошибка содержимого не выдаётся за отсутствие файла или необходимость миграции |
| K2 | Агент читает и исправляет повреждённую конфигурацию | Доступны необходимые диагностика и прямое редактирование файла, включая редактирование без `just write` |
| K3 | Из-за конфигурации не загружаются настроенные команды | Агент всё равно может исправить её в текущей сессии. Исправная копия конфигурации, чистое рабочее дерево Git и ручное вмешательство вне сессии не требуются |
| K4 | В проекте есть другие незавершённые изменения | Восстановление сохраняет эти изменения и не требует отката файлов из Git |
| K5 | Конфигурация повреждена | Возможность её исправления не разрешает произвольные команды и не позволяет обходить проверки commit и merge |
| K6 | Агент исправил конфигурацию | Обычные команды и настроенные ограничения снова действуют; постоянного режима обхода не остаётся |
| K7 | AgentRig установлен в отдельный пользовательский проект | Поведение K1–K6 подтверждается для Codex и Claude Code |
| K8 | Пользователь или агент обращается к инструкции восстановления | Способ восстановления документирован; диагностика направляет к каноническому skill исправления, по которому можно выполнить описанный сценарий |

**Ограничения из прежней карточки.** Сохраняется действующий формат конфигурации. Новый формат и общий режим отключения hooks не требуются.

**Открытые вопросы.** По описанному поведению пока не выявлены.

**Зависимости.** Дополнительные зависимости от других фич не установлены.

## Expected benefit

**Нужный результат.** Пользователю не приходится восстанавливать файл из Git, самостоятельно редактировать его вне сессии или отключать всю обвязку, чтобы агент продолжил работу.
