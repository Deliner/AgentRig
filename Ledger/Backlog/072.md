# B072 — исходящие связи файла: сколько частей проекта тянет один файл (Rust, Python)

## Context

Идея из интервью 7 ноября 2026. Бюджет входящих связей уже есть, D079: сколько частей
проекта зависят от каталога. Обратного бюджета нет. Исследование проверяло вариант
`fan-out-budget`, который включается отдельно для каждого каталога: ложных срабатываний
ноль, отложен только потому, что тогда не было потребности. Карточка заведена как идея;
в Plan не выбрана.

## Proposal

Иллюстрация:

```rust
use crate::{auth, billing, config, metrics, network, render, storage};
```

Файл зависит от семи частей проекта и почти наверняка делает несколько дел сразу. Сегодня
гейт молчит.

- **AC1 — файл с лишними связями отмечается.** Файл, который использует больше заданного
  числа внутренних модулей проекта → находка на файле.
- **AC2 — точка входа программы не отмечается.** Тот же список связей в точке входа → не
  находка.

**Границы и неизвестное.** Открыт вопрос, можно ли задать порог по умолчанию без настройки
проекта. Что считается частью проекта, модуль верхнего уровня или каталог, решается при
выборе. Частота на корпусе неизвестна. Новый `kind:` → двухфазная доставка по D051;
решение при доставке.

## Expected benefit

Файл-свалка видна по списку `use`.
