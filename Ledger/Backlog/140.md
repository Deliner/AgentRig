# B140 — Почему `lint-structure` ставит эталон ниже деревьев агентов

## Context

Меньший итог команды должен значить «понятнее». Числа из P129, P131 и запуска 2026-11-14:

| Дерево | Итог команды | Понятность по Sonnet |
| --- | --- | --- |
| Исходное, P129 | 24,4 | 51,6 % |
| Деревья агентов v5, P129 | 9,6–12,6 | 63,8–70,3 % |
| Project до перестройки, P131 | 24,0 | - |
| Project по эталону v36, P131 | 18,2 | 76,9 % у v36 в P128 |
| Project 2026-11-14 | 17,9 | не мерили |

- Эталон получает итог хуже, чем деревья, которые Sonnet понимает хуже. Внутри v5 итог тоже не повторяет порядок по
  Sonnet.
- После P131 находок стало больше, 201 против 231, потому что единиц стало 222 вместо 192.
- Пользователь 2026-11-14: «у нас должно быть улучшение, а стало ухудшение… надо с этим разбираться».

## Proposal

- **AC1. Причина найдена.** Исходное дерево, деревья v5 и v36 считаются одной ревизией команды на одной основе.
  Записано, какие проверки команды и на каких каталогах дают эталону больше баллов, чем деревьям агентов. Каждая
  причина подтверждена проверкой: до проверки записано, как изменится порядок, если эту проверку убрать или поправить,
  и результат с этим совпал.
- **AC2. Эталон не ниже.** Если причина в правилах команды, они правятся. Итог команды должен ставить v36 выше деревьев
  агентов и исходного дерева на деревьях со слепой оценкой из P128 и P129. Согласие по рангам с Sonnet при этом не
  падает. Если причина не в правилах, она записывается, и правка без согласия пользователя не делается.

  Проверка: в Delivery таблица итогов по тем же деревьям до правки и после.

**Границы.**

- Структура Project не меняется.
- Блокирующих правил на этих числах карточка не вводит, они остаются в B126.

**Неизвестное.**

- Эталон один, и правила подбираются по нему же. Нужна проверка на дереве, которое в подборе не участвовало, а
  такого дерева пока нет.
- Сравнимы ли напрямую числа P129 и P131: основа и ревизия команды у них разные.

## Expected benefit

Итог `lint-structure` снова показывает, какая структура понятнее, и агент, следуя числам, не уводит дерево от эталона.
