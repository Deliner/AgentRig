# B052 — global-state: процессно-глобальное изменяемое состояние без владельца (Rust)

## Context

Исследовательская дуга из семи раундов (архив `agentrig-research/scratchpad`: `coverage-map.md`
шаг 4 «R2», `meta/register.md`), принятая форма от 2026-11-02. Статический элемент с блокировкой
или публичной ячейкой — глобальное изменяемое состояние, у которого нет владельца в дереве
каталогов: агент не находит его по архитектурной карте, а изменение поведения требует поиска всех
мест записи (Search/Change cost). Форма «блокировка ∨ pub» отобрана как near-zero-FP на корпусе
(приватные `Atomic*`/`Cell` — законные счётчики и флаги, они не берутся). Собственный код AgentRig
не содержит `static`-элементов (проверено грепом по `Project`), принятие правила проходит без
находок. Реализация всех находок дуги авторизована пользователем 2026-11-04 (/goal).

## Proposal

Новый вид правила `global-state` (цель file, уровень error, Rust). Наблюдаемое поведение:

- **AC1 — глобальная блокировка.** `static`-элемент без `mut`, тип которого (после разрешения
  псевдонимов `type … = …;` того же файла, не глубже трёх уровней) содержит сегмент `Mutex`,
  `RwLock`, `DashMap` или `DashSet` — в том числе внутри `LazyLock`/`OnceLock`/`Lazy`/`Arc` — без
  строки `// DECISION: …`/`// INVARIANT: …` непосредственно над элементом → находка; с такой
  строкой → не находка.
- **AC2 — публичная ячейка.** `static` с модификатором видимости (`pub`, `pub(crate)`, …), тип
  которого содержит любую ячейку (`Mutex`/`RwLock`/`DashMap`/`DashSet`/`RefCell`/`Cell`/
  `UnsafeCell`/`Atomic*`), без строки-обоснования над ним → находка.
- **AC3 — элементы `lazy_static!`/`thread_local!`.** Элементы, объявленные внутри этих макросов,
  проходят те же проверки AC1/AC2 (синтаксический обзор тела макроса без разворачивания —
  граница D059).
- **Не находки:** приватный `Atomic*`/`Cell`/`RefCell`; `OnceLock`/`LazyLock` без ячейки внутри;
  `static` внутри `macro_rules!`; `static mut` (форма B046 AC2); тестовый код (`in_test_context`,
  исключения `**/tests/**`, `**/tests.rs`).
- Сообщение находки называет элемент: «process-global mutable state `NAME`: give it an owner or
  justify with a DECISION line above». Навык ремонта `own-the-state`: передать состояние владельцу
  (параметр/поле контекста), оставить ячейку приватной за функцией-владельцем либо обосновать
  ссылкой.

**Границы и неизвестное.** Новый `kind:` → двухфазная доставка с мид-бранч пином (D051); decision
при доставке. Разрешение псевдонимов — только в том же файле; тип, объявленный в другом файле, не
разрешается (граница D059) — такая ячейка не ловится, это принятая узость.

## Expected benefit

Процессно-глобальная блокировка или публичная ячейка не появляется в коде потребителя
незамеченной: у состояния есть владелец либо записанное обоснование. Переносимо на любой
Rust-проект.
