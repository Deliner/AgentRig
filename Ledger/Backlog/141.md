# B141 — Все константы и строки лежат в ресурсах `res/`, написанных на Rust

## Context

- 2026-11-14 пользователь: «…по выносу всех там магических строк, магических символов, чисел и так далее в
  константы… Не знаю, как их лучше будет структурировать в репозитории».
- 2026-11-27 пользователь: «Идея сделать систему, как в Android ресурсах… единое место для ресурсов, и там должны
  быть указаны вообще все константы и вообще все строки»; «мне нравится Android-система, где у нас там R, потом
  вроде тип указывался, константы»; «разделение у строк… те, которые переводятся потенциально, и те, которые не
  переводятся».
- О цели: «чтобы ты на PR видел, что… логика не поменялась, а только поменялась такая-то константа».
- О тестах и лишнем: «тоже тестовый код проверяется, как и все»; «если ресурс не используется, хочется его
  находить».
- О месте в продукте: «это должен быть как бы один из модулей». О записи: «ресурс на Rust выглядит как что-то
  очень хорошее».
- Из вариантов агента пользователь выбрал: `0` и `1` только как шаг и отсчёт; группа в пути имени; подключаемый
  модуль.
- Сейчас значения записаны в коде. D073 не ввёл правило против магических чисел: по синтаксису их не отличить от
  законных. Грубый подсчёт по ригу: в коде ≈5 500 строк и ≈800 чисел, в тестах ≈8 900 и ≈2 300.

## Proposal

Проект, включивший модуль ресурсов, записывает строки, символы, байты и числа только в `res/`. Код берёт их по
имени: `R::тип::группа::ИМЯ`. Ресурсы — файлы Rust, их компилирует сам Rust.

- **AC1. Литерал вне `res/` — находка.** Lint выдаёт ошибку на каждый литерал строки, символа, байта или числа в
  коде и в тестах, в том числе в `const` и `static`, и на текст между подстановками в строке формата. `0` и `1`
  разрешены в арифметике, сравнении, индексе и границе диапазона. Пустая строка — находка. Находка называет файл,
  строку, литерал и навык.

  | Given | When | Then |
  | --- | --- | --- |
  | `sleep(3)`, `sleep(1)`, `const MAX: u32 = 3;`, `let mut count = 0;`, `name == ""`, `format!("refused: {path}")` | lint | находка на каждое |
  | `count += 1`, `items[0]`, `depth == 0`, `0..n`, `format!("{indent}{line}")`, `sleep(R::integer::poll::SECONDS)` | lint | находок нет |
  | тест сравнивает результат с `"expected"` | lint | находка |

- **AC2. Где Rust требует литерал, проверки нет.** Это аргументы атрибутов и макросов времени компиляции:
  `#[cfg(feature = "x")]`, `include_str!("a.txt")`, `concat!`, `env!`.
- **AC3. Навык.** Находка ведёт на навык: как выбрать тип и группу, назвать ресурс по смыслу значения, а не по
  самому значению, и что делать там, где Rust требует литерал.
- **AC4. Подключаемый модуль.** Проект включает модуль в `.agentrig/rust.yaml`; без включения ничего не меняется.
  Риг включает его у себя; код и тесты рига приведены к правилу.
- **AC5. Каталог ресурсов.** У каждого крейта свой `res/` рядом с `Cargo.toml`. В нём каталоги типов: `text` —
  тексты для человека, потенциально переводятся; `string` — технические строки: ключи, пути, имена; `char`,
  `bytes`, `integer`, `float`; `array` — списки. Файл каталога типа — группа.

  ```rust
  // res/integer/commit_gate.rs
  pub const MAX_RETRIES: u32 = 3;
  // res/string/commit_gate.rs
  pub const STATE_FILE: &str = "Ledger/State.md";
  // res/text/commit_gate.rs
  pub fn refused(path: &str) -> String {
      format!("commit refused: {path} is protected")
  }
  ```

  В коде: `R::integer::commit_gate::MAX_RETRIES`, `R::text::commit_gate::refused(path)`.
- **AC6. В `res/` только значения.** Файл ресурсов содержит только объявления модулей, `const` с литералом или
  списком литералов и функции, тело которых — один `format!`. Остальное — находка, как и литерал не того типа, что
  каталог.

  | Given | When | Then |
  | --- | --- | --- |
  | в `res/integer/poll.rs` стоит `pub const NAME: &str = "x";` | lint | находка |
  | в `res/text/poll.rs` функция с `if` | lint | находка |

- **AC7. Ресурсы тестов.** Литералы тестов лежат в `res_test/` того же вида. В сборку продукта он не входит; тесты
  видят оба каталога.
- **AC8. Неиспользуемый ресурс.** Ресурс `res/`, который не использует код продукта, и ресурс `res_test/`, который
  не использует ни один тест, останавливают гейт; названы файл и имя.

**Границы.**

- Только Rust. Перевода и выбора языка карточка не вводит.
- Генератора, `build.rs` и своего формата нет.
- Смысл имени и выбор между `text` и `string` не проверяются.
- Длинные тексты по-прежнему уходят в файлы по `embedded-text`.

**Открытые вопросы.**

1. Переносить ли файлы `embedded-text` в `res/raw/`?

**Неизвестное.** Точное число находок на Project и voxel-rust; где ещё Rust требует литерал; как принять имя модуля
`R`: Rust ждёт имя строчными. Выясняется при поставке.

## Expected benefit

Все значения и тексты крейта видны в одном месте. В PR смена значения отделена от смены логики. Тексты для человека
отделены от технических строк. Новому формату и новой сборке учиться не нужно.
