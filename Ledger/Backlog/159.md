# B159 — Тексты для агентов не противоречат друг другу и командам рига

## Context

- 2026-11-19 пользователь об отчёте аудита обходов: «не хочется все твои находки терять… давай их все исправим».
  Затем: «Пока только карточки заведи». Текст сохранён без показа в чате; до выбора в Plan его нужно согласовать.
- Аудит 2026-11-19, группа F. Пункты F1 и F3 о `just bootstrap` и `just lint-baseline` закрывает B150, пункт F2 о
  хуке и базе закрывает B156. Остальные:
  - F4. `doctor` и `memory-check` упоминаются в навыках repair и edit-plan, но рецептов нет; работает
    `just check --only memory`.
  - F5. develop-tools велит повторить напечатанную команду, repair велит перевести её в рецепт; напечатанная
    команда с абсолютным путём хуком запрещена.
  - F6. edit-backlog требует и «язык пользователя», и «на русском»; форма черновика расходится с обязательными
    разделами Context, Proposal и Expected benefit.
  - F7. Абзац «Current precedence» в Decisions.md кончается на D054 и не знает замен D057, D078, D173, D186, D187 и
    D189.
  - F8. Раздел Enforcement в testing-discipline говорит, что проверяются только отключённые тесты, хотя lint
    проверяет и подмену, панику, фиксированный порт и размещение тестов.
  - F9. clarify-structure требует полный `just check` на каждом шаге, а AGENTS.md и execute-plan-feature просят
    этого не делать.
  - Список маршрутов хука в AGENTS.md неполон.
  - README гейта и дистрибуции по-разному описывают запуск тестов, когда карта не нашла совпадений.
  - Место навыков названо тремя разными способами.
  - edit-backlog говорит об «architecture inventories» для Ledger, которых нет.
  - execute-plan-feature пишет `just run write`.
  - Пример проекта-потребителя запускает Git напрямую и гейт дважды.
  - testing-discipline и replace-comment расходятся в том, что пишется после `DECISION:`.
  - Описание команды `test` обещает фильтр по пути, а cargo фильтрует по имени теста.
  - AGENTS.md велит `tooling/worker/run`, который хук не пропустит.
  - Неясно, нужна ли согласованная карточка, когда агент сам откладывает работу.

## Proposal

- **AC1.** По каждому пункту выше тексты говорят одно и то же и совпадают с поведением рига.

  Проверка: в отчёте о выполнении для каждого пункта названы исправленные места.
- **AC2.** Каждая команда `just`, которую называют AGENTS.md, README и навыки рига, проходит хук в риге и в проекте
  после `init`.

  Проверка: тест, который берёт команды из этих текстов и проверяет их хуком.

**Границы.** Принятые решения и их детали не переписываются (D020); устаревшие ссылки исправляются там, где текст
можно менять.

## Expected benefit

Агент, следуя любому тексту рига, выполняет допустимую команду и не выбирает между противоречащими указаниями.
