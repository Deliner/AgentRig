# B112 — Риг на Linux работает так же, как на Mac

## Context

- Открытая находка P114: часть кода для Linux ни разу не компилировалась, и на Linux тесты рига не запускались.
- Пользователь 2026-11-11: у него есть удалённая машина с Linux, доступ к ней он даст позже. Он ожидает, что
  пользовательский функционал работает одинаково на Mac и на Linux, а компоненты для этого на двух системах могут
  быть разные. Карточку он одобрил.

## Proposal

Риг на Linux делает для пользователя то же, что на Mac.

- **AC1.** На Linux-машине пользователя риг собирается и проходит все свои тесты.
- **AC2.** Пользователь видит одно и то же на обеих системах: установку, подсказки агенту, проверку перед коммитом,
  запрет записи для команд чтения. Внутри механизмы могут отличаться: на Mac запрет записи даёт sandbox-exec, на
  Linux bubblewrap.

**Ждёт** доступа к машине, пользователь даст его позже.

## Expected benefit

Риг можно ставить в проекты на Linux с тем же поведением, что на Mac.
