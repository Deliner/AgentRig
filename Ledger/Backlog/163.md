# B163 — Ошибка не стирается через `.ok().flatten()` и запасное значение у `join()`

## Context

- 2026-11-19 пользователь прислал ревью voxel-rust на ревизии `2304625` и попросил: «Посмотри, возможно на основе
  этого можно новых карточек наделать … для AST линтеров и в целом для процесса». О показанных черновиках:
  «Остальные можешь сохранить».
- Ревью, шаблон 6: `.ok().flatten()` превращает `Result<Option<T>, E>` в `Option<T>` и теряет ошибку. Два места:
  `src/browser/legacy.rs:33`, где некорректный старый seed становится seed 41, и `src/browser/store.rs:140`.
- Ревью, шаблон 4: результат `join` рабочего потока заменён значением по умолчанию, и паника потока становится
  пустым фрагментом. Пять мест: три в зондах (`src/tools/control/resources/light/feed.rs:179`,
  `src/tools/control/resources/light/scenes.rs:150`, `src/tools/lod/biomes/landscape.rs:48`) и два вызова
  одноимённого `Simulation::join` в тестах.
- Правило silent-error рига эти формы не ловит.

## Proposal

- **AC1.** `.ok().flatten()` даёт ошибку lint правила silent-error.
- **AC2.** `.join()` без аргументов, за которым идёт `.unwrap_or*` или `.ok()`, даёт ошибку lint правила silent-error.

Навык: передать ошибку дальше или записать причину через `DECISION`.

Проверка: тест lint на примеры из ревью.

## Expected benefit

Ошибка разбора или паника потока не превращается молча в значение по умолчанию.
