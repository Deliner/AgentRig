# D130 — Error on a secret field printed by a derived Debug

## Context

B079 (user, 2026-11-07, after measuring a list of smells on the 7.8 million line
corpus of `agentrig-research/scratchpad/meta/experiments/list-rules/d-async/report.md`):
11 of 12 sampled sites are useful, two are real leaks, an API key reaching a log
in meilisearch and a password printed to stdout in uv. A derived `Debug` prints
every field in full wherever the struct reaches `{:?}`, a log macro or a panic
message. The card narrows the rule to `Debug`, because `Serialize` usually
describes an exchange format.

## Chosen

A new rule kind `secret-debug` with the repair skill `redact-secret`, shipped at
`error`. A struct item deriving `Debug` in an attribute above it, directly or as
a `derive` inside `cfg_attr`, is measured; every named field whose name is
exactly `password`, `passwd`, `secret`, `token`, `api_key`, `apikey`,
`private_key`, `access_token`, `refresh_token`, `client_secret`, `jwt` or `cvv`
and whose type is `String` under any path, `&str` with any lifetime, `Vec<u8>`
or an `Option` of one of them is a finding on the field line with the symbol
`Type.field`. The attribute walk is the one test exemption already uses, across
doc comments and other attributes. Test code is excluded by item and by path.
Two-phase delivery with a mid-branch pin (D051).

## Rejected

A `DECISION:` or `INVARIANT:` justification above the field: the card's
exemptions do not list one, and a masking type or a manual `Debug` is the repair
for every case. Matching names by substring, such as `db_password`: the card
keeps exact names. Tuple structs and enum variants: they have no field names to
match, and the card leaves variants out. `Serialize`: an exchange format is not
a leak by itself.

## Rationale

The derive, the field name and the field type are visible in one item's syntax,
so the rule needs no type resolution. A wrapper type is any other type, so the
repair leaves no finding without a special case.

## Consequences

A consumer's non-test Rust struct deriving `Debug` with a secret-named string or
byte field fails lint on `init` and before commit. Secrets under other names,
in enum variants or in tuple structs stay unseen. It ships B079 in full; it
supersedes nothing.
