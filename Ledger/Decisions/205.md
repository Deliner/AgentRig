# D205 — Report an indexed array literal whose elements call

## Context

B161 under D151. The voxel-rust review at `2304625`, template 2, found `[values.clone().min(), values.max()][end]` in
`src/tools/control/resources/light/feed.rs:189`: indexing the literal evaluates both elements and keeps one. The card
asks for a lint error on an array literal indexed by a non-literal whose elements contain calls, and for a skill that
selects with `match` or `if`. It notes that a method of that name may be a project's own and that the side effects of
the elements may be intended.

## Chosen

A Rust kind `indexed-array-literal` at level error with the repair skill `branch-on-the-index`. It reports an index
expression whose indexed value is an array literal listing its elements, at least one of which contains a call
expression, a method call included, and whose index is neither an integer literal nor the full range `..`. Test code
is included. A `DECISION:` or `INVARIANT:` reference on the line directly above lifts a finding, the card's leave for
intended side effects. The kind enters the runtime first, is pinned (D051) and is then enabled in the rig's
`lint.yaml`, the catalog and init with its skill.

## Rejected

- Exclude test code, as most standard-form kinds do: the card reports the form without that limit.
- Report a literal index: the card limits the form to a non-literal one.
- Report a repeat literal `[f(); n]`: it evaluates its element once.
- Report the full range `..`: it keeps every element, so nothing is discarded; a partial range discards and is
  reported.
- Count macro invocations as calls: the card names calls.
- Measure the predicate on corpora before shipping, as D181 did: the card fixes the predicate from one reviewed site.

## Rationale

The form reads as a selection but runs every element, so the calls of the elements not chosen cost time and can
fail, panic or change state for a value that is thrown away. `match` or `if` on the index runs only the chosen arm.
Calls are what can do that work; constants, paths and literals cost nothing.

## Consequences

Types are not resolved: a call inside a closure element is reported although the closure does not run, and a cheap
call such as a getter is reported like an expensive one; both take a reference. An array reached through a
parenthesis or a binding is not reported.
