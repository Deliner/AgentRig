# D212 — Keep the Just recipe groups in .agentrig/just/

## Context

D039 placed the recipe group files in a visible `just/` directory at the repository root, rejecting a hidden
directory name, so that the root listed Ledger, the configuration directory, the recipes and Project. D195 adds a root
`CLAUDE.md` beside `AGENTS.md`. With it the rig root has 16 entries, while the rig's directory-size rule fails at more
than 15, and every other root entry is required by a tool or by an earlier user choice. On 2026-11-19 the user was
offered three repairs: move `just/` into `.agentrig/just/`, revising D039; stop counting the root; move LICENSE into
Project. The user chose the first.

## Chosen

The recipe group files live in `.agentrig/just/`, both in the rig and in the files `init` writes, whatever the service
directory is. The root `justfile` still sets positional arguments and imports every group, now from that directory,
and holds no recipes. Group names, recipe names and their bodies stay as D039 and later decisions set them. This
supersedes D039's root location of the group files.

## Rejected

- Not counting the root in directory-size: it removes the size limit from the one directory every agent reads first.
- Moving LICENSE into Project: tools and readers expect the license at the root of the repository.
- The service directory: its name may be any path, including quotes, so each import line would need Just string
  escaping, while `.agentrig` always exists.
- A configurable recipe directory: one fixed place needs no new setting.

## Rationale

`.agentrig` is the one directory every rig project has at a fixed path. The recipes are generated adapters, like the
agent registrations in `.codex` and `.claude`, so a fixed place suits them. Just only needs the root `justfile`, which
can import from any relative path, so recipe names and invocations stay the same.

## Consequences

The rig root and a consumer root lose one entry; `.agentrig` holds the configuration modules and `just/`, plus the
runtime, hooks and skills when the service directory is the default. Decision links to recipe groups point into
`.agentrig/just/`. Hooks and the shell guard are unaffected, because they resolve recipes through the recipe table, not
through files. The rig's changed-path map treats recipe groups as configuration, which selects every test.
