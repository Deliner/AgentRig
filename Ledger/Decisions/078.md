# D078 — A directory may declare a pure zone that bars environment access

## Context

D044 limited directory contracts to purpose, files, directories and type. On
2026-10-31 the user agreed B034 (Набор II, merged C1+C2): a module declares a
zone class and the engine confines what that zone may reach, so one portable
discipline lays onto any application. Environment confinement was the first
real consumer of the zone mechanism, so the two merged into one feature (the
user's "Слить C1 в C2"). The minimum delivered is one zone class.

## Chosen

The architecture.yaml contract takes an optional `zone` field with one class,
`pure`. A directory declared `zone: pure` must not reference `std::env`,
`std::fs` or `std::process` in its own immediate files; the
directory-architecture rule reports each such reference at error level. The
check is opt-in — an untagged directory is unaffected — and additive; the
escape is to drop the `zone` or move the effect out. This supersedes D044's
four-field contract limit; D044's type classification remains.

## Rejected

The five-class example set (pure, io-adapter and the rest); a per-reference
DECISION: escape, redundant with the opt-in label; `std::net`, `std::time`
and `std::io` in the forbidden set, each of which holds pure value types
(`Ipv4Addr`, `Duration`, `Error`) that would raise false positives; a new rule
kind or skill, since the check extends the existing directory-architecture rule
(like D070 and D076), leaving I020 unchanged; a pretend invariant for the
non-syntactic parts (norm-or-choice, D059).

## Rationale

One zone class is the complexity-discipline minimum that proves the mechanism
with a real consumer. The three forbidden namespaces are each wholesale
effectful, so matching the full external path at a `::` boundary is
near-zero-false-positive against the gate bar (D035). Confinement is a
syntactic property the resolver already computes — it preserves each
reference's external origin (D076) — so it is a genuine rule, not a norm.

## Consequences

A directory opts into purity by declaring `zone: pure`; the engine then
rejects environment access in that directory's own files, not its children's.
The field ships to consumers through `init` with no new rule kind or skill, so
the I020 delivery sets are unchanged. The repository tags
`structural_lint/architecture/resolution` as the first pure demonstrator.
Further zone classes or forbidden namespaces are separate work.
