# D187 — init always names the source directory Project and the memory directory Ledger

## Context

On 2026-11-18 the user saw that a project set up by the rig kept its sources and memory under other names and asked:
«Мне нужна директория project, мне нужна директория ledger». The user explained that the rig dogfoods itself fully,
so AgentRig is expected to be laid out exactly like any project initialized by it. D040 made Project and Ledger the
defaults but kept `--source` and `--memory` configurable and rejected fixed names, because existing projects and the
examples used other layouts. D185 has since removed backward compatibility. The user asked for card B144 and its
delivery.

## Chosen

- `init` and `init --interactive` neither accept nor ask for the source or memory directory: `paths.sources` is
  `Project/**` and `paths.memory` is `Ledger`. `--source` and `--memory` are refused as unknown options before writing.
- The `agentrig` help, the init guide and the examples name only the remaining options; the example projects keep
  their code in `Project`.
- The fixed layout is a norm: invariant I022 states it and binds its test.
- `project.yaml` paths remain configuration: config-check does not require the names, and projects already configured
  keep their paths. A Rust project with its manifest at the root keeps its crate roots and test command; its code
  outside `Project` is not linted until the project moves it (D185).

## Rejected

| Alternative | Why |
| --- | --- |
| Keep the options with their defaults (D040) | a project can still diverge from the rig's layout, as one already did |
| Require the names in config-check | the card leaves configured paths free; the request concerns what init creates |
| Move existing code into `Project` during init | init leaves source files to the user (D040) |

## Rationale

One layout makes every initialized project read like the rig, so its instructions, skills and examples need no path
variants, and the rig's own repository is the reference layout for every consumer.

## Consequences

Supersedes D040's configurable `--source` and `--memory` and its rejection of fixed names; D040's names become the
only ones. Tests that passed other names now use `Project` and `Ledger`. The change to Project takes one final pin
(D051).
