# D170 — Outer boundary of B120: an interpolated shell command ships, the other forms do not

## Context

B120 under D151 takes three forms of list IV of 2026-11-11 about data that crosses into the outside world: IV-27 a
shell started with `-c` whose command is not built from a literal; IV-28 a `format!`, `write!` or `writeln!` template
of JSON or SQL with a placeholder; IV-30 an `exists()`, `is_file()` or `is_dir()` check followed by an action on the
same path. AC1 ships a rule only when at least 90% of its checked findings are true, by the protocol of D165 recorded
in the delivery of P120. All three forms are measured outside test code. The verdict clauses were committed in
`db4407e` before commit `e4b8d2c` froze the predicates as three inert kinds: `interpolated-shell`,
`interpolated-syntax` and `stale-check`. A probe of Clippy 1.98.1 with the defaults, the rig profile, and all
pedantic, nursery and restriction lints reported none of the three forms; the restriction lint `create_dir` reports
every `fs::create_dir` call and not the check before it.

## Chosen

IV-27 becomes the error-level kind `interpolated-shell` with the repair skill `pass-arguments-apart`: every Rust
`Command::new` call whose first argument is a string literal naming `sh`, `bash`, `zsh`, `dash`, `ksh`, `fish`, `cmd`,
`powershell` or `pwsh` by its last path component, with or without `.exe`, when the `.arg` and `.args([..])` calls
chained on it put `-c`, `/c`, `-Command` or a lowercase short-flag cluster ending in `c` directly before an argument
that is neither a string literal nor an uppercase constant name, outside test code as recognized by D148, without a
`DECISION:` or `INVARIANT:` reference on the line directly above the call.

The kind joins `catalog::ALL` and the Rust handler, and `init` ships it. The skill drops the shell where it only starts
one program and otherwise keeps the script literal: a POSIX shell takes the values as positional parameters after a
`$0` name, `fish` as `$argv`, and PowerShell as environment variables read with `$env:`; for `cmd` the program runs
directly. Its directory sits in `references`, and `justify-skip` moves into `references/false-pass`, whose purpose
becomes tests that keep the suite green while the behavior they claim goes unchecked, so `references` stays within
its limit of 15. The Clippy profile is unchanged, and the inert kinds `interpolated-syntax` and `stale-check` are
removed.

## Rejected

`interpolated-syntax`: 4 of 20 checked findings are true, 20%, among 1 on the rig, 1 on voxel-rust and 120 in 8 of 18
corpus projects. Most false ones substitute a number, a constant or a value already escaped for the format; one is
console text no parser reads and one generates Rust, not JSON.

`stale-check`: 26 of 41 checked findings are true, 63%, and 20 of 35 in the corpus, 57%, among 5 on the rig, 1 on
voxel-rust and 193 in 13 of 18 corpus projects. In 7 false ones the action's own failure is handled with the same
outcome, and in 5 the check exits with its own error while the action's error also propagates.

Positional parameters after the script for every shell: PowerShell joins the arguments after `-Command` into the
command text, and `cmd /c` has no parameters and expands `%NAME%` before it parses the line, so both would keep the
injection.

Narrowing a detector against the measured sites: the same sites would then both tune and judge it.

## Rationale

`interpolated-shell`: 2 of 2 findings are true, 100%, both in zed `crates/zed/build.rs:114` and `:133`, and none on
the rig or voxel-rust. They put `nupkg_path.display()` and `extract_dir.display()` into a PowerShell `-Command` script
inside single quotes, so an apostrophe in the build path closes the string and the rest runs as code. The precision
rests on two sites in one file; the predicate reads only a literal shell name, its command flag and a value that is
not fixed text.

`interpolated-syntax` and `stale-check` depend on facts their predicates do not read: the type and origin of the
substituted value, and whether the code around the action handles its failure.

## Consequences

The kind applies wherever it is configured as soon as a runtime carrying it is pinned (D051). The frozen predicates
remain in commit `e4b8d2c`, and the measured counts, classes and examples are in the delivery of P125. IV-28 and IV-30
remain review norms in list IV; a later decision may add a detector with a different predicate measured anew. The
true `stale-check` findings on the rig and voxel-rust are real races that this decision does not repair. A command
assembled in steps through a variable or chained inside a macro argument is not seen.
