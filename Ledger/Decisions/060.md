# D060 — Clippy panic-risk deny profile as a dev-gate, excluding print lints

## Context

B027 (quality cluster 2) proposed an out-of-the-box safe Clippy profile denying
`unwrap_used`, `expect_used`, `panic`, `todo`, `unimplemented`, `unreachable`,
`dbg_macro`, `print_stdout` and `print_stderr`. Two facts surfaced during delivery.
The `init` template (`project_setup/template.rs`) ships no external tools — only the
built-in structural linter and the `read`/`write`/`test` commands — so clippy, ruff and
mypy profiles are this repository's own development gate, not an `init` capability.
AgentRig is a CLI: `print_stdout`/`print_stderr` would fire on ~73 legitimate
product-output sites.

## Chosen

Clippy runs (`.agentrig/commands.yaml`) with `-D warnings` and a panic-risk deny set:
`panic`, `todo`, `unimplemented`, `dbg_macro`, `unreachable`, `expect_used`, `unwrap_used`.
`print_stdout`/`print_stderr` are excluded. The set does not apply to `#[cfg(test)]`
modules — clippy runs without `--all-targets`, so test code keeps `unwrap`/`expect`. The
profile is this repository's dev-gate; `init` does not ship it. Ruff gains the `PERF`
group alongside `B`/`SIM`/`UP`; `mypy --strict` was already configured.

## Rejected

Deny `print_stdout`/`print_stderr` (would break the CLI's output or demand blanket
`allow`s); ship clippy/ruff/mypy through `init` (external tools fall outside the portable
install); weaken a threshold or add product-code `allow`s merely to pass.

## Rationale

Denying hidden panics and debug prints catches the anti-patterns at the commit gate rather
than in review, without touching the CLI's intentional output; `dbg_macro` already covers
the debug-print intent. The policy lives in one gate's configuration and applies only to
this repository's own code.

## Consequences

AgentRig's non-test code stays free of `unwrap`/`expect`/`panic!`/`todo!`/`unimplemented!`/
`dbg!`/`unreachable!`; the commit gate blocks new such sites. Future edits to the profile
do not reintroduce the print lints without revisiting this decision. Delivered across
P035 VAC-A..D; the `init` delivery is unchanged.
