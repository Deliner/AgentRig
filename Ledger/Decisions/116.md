# D116 — Exempt the single-file lint rule registry from the file-size limit

## Context

P074 adds the repository rule for the new kind `unwind-justification` (D115),
and `.agentrig/lint.yaml` reaches 508 nonblank lines against the `file-size`
error limit of 500, which selects `.yaml` files across the repository. The
file is the repository's lint rule registry: every rule kind the repository
gates its own code with has one entry there, so it grows by one entry with
each delivered kind, and the selected Plan still adds new kinds. The lint
loader reads exactly one configuration file: it has no include mechanism,
and the shared YAML reader rejects anchors, aliases and tags. A consumer's
generated configuration lives outside its `Project/**` file-size scope and
is not affected.

## Chosen

Exclude exactly `.agentrig/lint.yaml` from the repository's `file-size` rule,
with a reference to this decision in the lint configuration, consistent with
the flat registry exemptions of D029, D030, D048 and D056. Every other file,
including the other `.agentrig/` modules, keeps the existing limits, and the
registry keeps configuration validation and every other rule.

## Rejected

Raise the general limit. Compress the entries into flow style or another
denser representation solely to fit, which the large-file repair forbids and
which only delays the conflict by a few kinds. YAML anchors for the shared
test-code exclusion: the configuration reader rejects them. Add a loader
mechanism that reads rules from several files: it is a new product behavior
that no current acceptance requires. Omit the repository rule for a new
kind: the repository would stop gating its own code with a delivered rule.

## Rationale

The representation is fixed by the runtime contract and has one
responsibility: listing the configured rules. Its length measures the number
of rule kinds the repository applies, not cohesion of code or prose, so the
size limit there blocks delivery without signalling a structural defect.

## Consequences

Adding a repository rule is no longer blocked solely by registry length. The
registry remains subject to `just config-check`, `just lint-config-check` and
the line-width and other rules that select it. Reassess this exception if the
loader later permits a meaningful split of the configuration.
