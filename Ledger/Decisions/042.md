# D042 — Place first-level features directly in Project

## Context

D041 moved the worker into Project as one crate with src/, assets/, examples/
and the Python harness. On 2026-10-26 the user stated that Project itself is not
the top-level feature: the top-level features are the entries directly in
Project, each with a two-word name (Requests.md, "Уточнение о фичах верхнего
уровня"). The user asked to apply this now and review the result; the rest of
the nested feature scheme in B003 is not agreed. The architecture rule forbids
directory cycles and more than 15 entries in a directory.

## Chosen

Project holds the features agent_hooks, change_delivery, command_line,
command_runner, project_config, project_memory, project_setup and
structural_lint, declared by lib.rs, plus shared for support that depends on no
feature: arguments, artifacts, diagnostics, paths, vcs, yaml, skills and test
support. Names use snake_case, as Rust and Python modules require.
Configuration is its own feature because its validation reads the lint
configuration; jobs nest in command_runner; check evidence lives in
project_memory beside the resume report that reads it. pyproject.toml and
uv.lock move to tooling, and Project/rust-toolchain.toml is removed because
every configured cargo invocation pins +1.98.1. This supersedes D041's
statement that tooling keeps only launchers and distribution.

## Rejected

Keep src/ under a scaffold umbrella; one-word or hyphenated names; keep
configuration in shared, which creates cycles with structural_lint and
command_runner; a separate evidence feature, which exceeds 15 entries; apply
the whole nested features/ scheme before agreement.

## Rationale

The first level of Project then names the product's capabilities, and the
architecture lint enforces the acyclic feature graph the layout states.

## Consequences

Rust paths are crate::<feature>, Python tests import Project.<feature>, and
uv and pytest run with the tooling project. The affected-test map, lint
scopes, build signature and skill symlink follow the new paths. Sub-feature
structure inside each feature is unchanged until B003 is agreed.
