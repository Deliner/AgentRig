# D004 — Python quality gate

## Context

The worker needs a small repeatable baseline for Python implementation.

## Chosen

Run Ruff formatting and linting, strict mypy, pytest, typos, and high-confidence Vulture checks.

## Rejected

Create custom equivalents or require product-specific analysis.

## Rationale

The established tools cover formatting, typing, behavior, spelling, and dead code without custom infrastructure.

## Consequences

All Python files participate in one gate configured by tooling/pyproject.toml.
