# D066 — Accept the command_runner/jobs libc FFI as sound

## Context

D065 requires every Rust `unsafe` to carry a `DECISION:` or `INVARIANT:`
reference on the line above it, or be removed. The worker's `unsafe` is confined
to eleven libc FFI calls in `command_runner/jobs`: process-identity sampling
(`sysctlbyname`, `proc_pidinfo`, `mach_timebase_info` and `MaybeUninit` fill on
macOS; `sysconf` on Linux) and process-group control (`kill`, `killpg`, `getpgrp`
for signal delivery). No safe `std` API exposes these calls, so the `unsafe` is
necessary rather than incidental, and the soundness argument is the same libc
contract in every case.

## Chosen

Record one justification covering the shared FFI pattern and reference it from
each of the eleven sites with a `// DECISION: D066` comment on the line directly
above the `unsafe`: every call passes arguments built to the libc signature,
reads scalar results or a struct the call fully initializes, and checks the
return value or `errno`; none retains a borrowed pointer past the call or aliases
Rust-owned memory. `MaybeUninit::assume_init` follows a zeroed or kernel-filled
struct, matching its contract.

## Rejected

A separate decision per call, when the soundness argument is one FFI contract
repeated; an `INVARIANT`, since the soundness here is a reviewed property, not a
statically-checkable test oracle (norm-or-choice); wrapping each call in a
hand-rolled abstraction, which only relocates the same `unsafe` without changing
its obligation; removing the `unsafe`, which is impossible while the capability
needs libc.

## Rationale

The eleven calls share one argument — correct libc usage with checked returns and
no memory aliasing — so one recorded reason, referenced at each site, is the
honest representation and avoids eleven near-identical decisions. Keeping the
reason a decision rather than an invariant matches what it is: a human-reviewed
soundness judgement about external calls, which no test can falsify on its own.

## Consequences

Each of the eleven sites carries `// DECISION: D066` on the line above its
`unsafe`, satisfying the unsafe-justification rule (D065) in the worker
repository. A new libc call added to these files must extend or supersede this
justification rather than inherit it silently, since the reference is written at
each site by hand.
