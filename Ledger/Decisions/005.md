# D005 — Just command gateway

## Context

Agent shell activity needs a discoverable surface, explicit mutation, and usage evidence.

## Chosen

Route shell operations through catalogued Just recipes; sandbox reads and make unrestricted writes explicit.

## Rejected

Allow arbitrary top-level shell commands or maintain undocumented recipes.

## Rationale

One command gateway centralizes enforcement and logging.

## Consequences

New recipes require a catalogue entry, dependency list, and adjacent what/why comment.
