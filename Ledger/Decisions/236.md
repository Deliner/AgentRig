# D236 — New decisions in three sections

## Decision

A decision that the committed memory does not hold has the sections `Decision`, `Reasons` and `Alternatives`, in
this order and none empty: what was decided, why, and which alternatives were considered and why each was not
applied. A decision that the committed memory holds keeps its five prior sections `Context`, `Chosen`, `Rejected`,
`Rationale` and `Consequences`. The memory check and the commit gate refuse a new decision in any other layout and
name its file and the three sections; in a project without Git history every decision is new. The skills
`edit-decisions` and `norm-or-choice` give three content rules that the check does not read: one decision records
one choice; each reason is a checkable fact or a link to a principle or a decision; each alternative names what it
offered and why it was not applied.

## Reasons

- The user set the content: «решение это что мы решили. Дальше просто список из того, почему мы это сделали. И
  список потом из того, какие альтернативы мы еще рассмотрели и почему они были не применены» (B206).
- The user kept the committed decisions: «давай старые оставим, а новые будем в новом формате делать» (B206), and
  D020 keeps their statements and details unchanged.
- In D235, `Context` and `Consequences` retell the card B205 and `Chosen` repeats its AC1–AC4.
- The history check of D215 already reads the checked revisions and the fork, so it names the committed decisions
  without a new record.
- A rig mechanism holds without the agent's cooperation (D234); a format kept only in the skills holds only while the
  agent follows them.
- Every section heading the memory check reads is English.

## Alternatives

- Rewrite the committed decisions in the three sections: one layout across the index. Not applied: D020 keeps
  committed details unchanged, and the user kept the old decisions.
- Keep the five sections for new decisions: no change of the check. Not applied: `Context` and `Consequences` retell
  the card, as in D235, and the user set three sections.
- Keep the format only in the skills: no change of the check. Not applied: the format would hold only while the agent
  follows the skills (D234).
- Name the sections in Russian, as the user spoke: closer to the user's words. Not applied: every heading the memory
  check reads is English.
