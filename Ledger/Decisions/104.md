# D104 — A `pure` zone also forbids entropy, network, threads and the console

## Context

B056 (research arc, `coverage-map.md` R3 and the r0 critique "keep entropy narrow: exact
calls, not the whole `rand` crate"), selected as P063 under the user's /goal of
2026-11-04. The `pure` zone (D078) bars `std::env`, `std::fs` and `std::process`, and
D083 added the wall clock, but a pure directory could still draw entropy, open a
socket, spawn a thread, read or write the console or print, and the gate stayed
silent. The directory-architecture resolver (D076) already produces each reference's
full external path and resolves a known standard macro such as `println!` to its
`std::println` origin, so every such effect is a syntactic property the engine
already computes. AgentRig's one pure directory
(`structural_lint/architecture/resolution`) has none of these effects in its own
files.

## Chosen

One classifier, `architecture::effect`, names the effect of a resolved external
path: the D078 namespaces give "access the environment", the D083 clock reads give
"read the wall clock", and a fixed table matched at a `::` boundary exactly like
D078 gives "draw entropy" for `rand::random`, `rand::thread_rng`, `rand::rng`,
`getrandom::getrandom` and `getrandom::fill`, "use the network" for `std::net`,
"use threads" for `std::thread`, and "use the console" for `std::io::stdin`,
`std::io::stdout`, `std::io::stderr` and the macro origins `std::print`,
`std::println`, `std::eprint` and `std::eprintln`. The dependency pass records an
impure use when the classifier answers, and the zone check puts that name into
the unchanged finding text ("zone `pure` directory must not {effect}; move the
effect out or drop the zone: {path}"). `dbg!` stays D081. The `lint-rules`
contract description lists the extended set. No new rule kind, repair skill,
oracle or `lint.yaml` entry is added, so the I020 delivery sets stay balanced and
the branch needs only the final D051 pin.

## Rejected

Banning the whole `rand` and `getrandom` crates or the `std::io` namespace by
prefix: `rand::Rng`, `rand::rngs::StdRng`, `getrandom::Error`, `std::io::Write` and
`std::io::Error` are pure types and traits, and the r0 critique asked for the exact
entropy calls (D035). A configurable path list: the set is fixed like `CLOCK`
(D083); a configuration dimension needs a current second behavior. A per-reference
`DECISION:` escape: redundant with the opt-in zone label (D078). `std::sync` in the
set: locks and atomics are not effects by themselves. A test-context exemption or a
new rule kind and skill: the check extends the existing directory-architecture
rule like D078, D079 and D083. A mid-branch pin: no new kind or configuration
reaches the stable binary.

## Rationale

A directory that promises purity must be free of every effect that makes it
non-deterministic or ties it to the process boundary, and each listed path is
such an effect wholesale, so matching it at a `::` boundary stays near-zero
false positive (D035) inside the syntactic engine (D059). One classifier owns the
whole forbidden set, so the recording pass and the finding text cannot drift
apart, and the finding names the effect the way D083 named the clock. An entropy
crate must be declared external (D076) like any other crate; an undeclared crate
is already an incomplete-analysis finding.

## Consequences

A `zone: pure` directory can no longer silently draw entropy, use the network,
use threads, use the console or print: each such reference in its own files
becomes an error finding naming the effect, in the worker repository and in every
consumer; the escape is unchanged, move the effect out or drop the zone. The
`lint-rules` description of directory-architecture lists the extended set.
AgentRig's pure directory stays green, so dogfooding reports zero findings. It
completes B056 and supersedes nothing.
