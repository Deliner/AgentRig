# D186 — The first edit of a decision record in a context stops until norm-or-choice is delivered

## Context

On 2026-11-18 the user showed the analysis of an agent in another project set up by the rig: norms, properties that
must always hold, were recorded as decisions, and their passing tests were not bound as invariants, so the memory
check did not follow whether those tests exist and run. The agent named the cause: nothing made it ask whether a
record is a choice or a norm. norm-or-choice holds that rule, but only edit-decisions and execute-plan-feature mention
it, and the Decisions route of D047 gives guidance without a stop. The user asked for card B143 and its delivery.

## Chosen

- The repository and the `init` template add a route with `include` on `Decisions.md` and `Decisions/**/*.md` of the
  memory directory, the skill norm-or-choice, the event `edit` and `block: true`. It follows the State check route.
- Under D047 the first edit of a decision record in each area of a context window stops with the requirement to read
  and apply norm-or-choice, beside the edit-decisions guidance; the retry passes.
- The stop is a norm: I012's predicate now states it as the one exception to guidance without a denial, and I012's
  oracle checks it. Opaque shell writes and the other memory files keep guidance only.

## Rejected

| Alternative | Why |
| --- | --- |
| Blocking the existing Decisions route on edit and shell | the first opaque shell write of every context would stop, though it names no decision |
| A required field in each new decision naming its norms | committed decisions cannot change (D020), so a check would have to tell old records from new ones |
| Only rewording the skills | the skills already state the rule; nothing made the agent read it before recording |

## Rationale

A stop is the rig's existing means to deliver a skill before an action (D047). Whether a statement is a choice or a
norm is a judgment no deterministic check can make, so the rig enforces the reading and leaves the judgment to the
skill.

## Consequences

Supersedes D047's rejection of blocking Ledger edits for decision records only. I012 is revised with its test; I020
keeps the delivered and repository route sets equal. Writing a decision index row and its detail stops once for each
of the two directories. The change to Project takes one final pin (D051).
