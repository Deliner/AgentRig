# D075 — B032 test-determinism and naming/placement checks stay norms

## Context

B032 (cluster 7 of the quality set, agreed 2026-10-29), besides the disabled-test
rule shipped as D074, proposes two further candidates: 7.2 — a test is
deterministic, not dependent on wall-clock time, random seeds, the network, the
ambient filesystem or another test's order; 7.3 — a test is named and placed by
the behavior it exercises. The structural engine is purely syntactic (D035): it
cannot tell a benign clock, RNG or network call from a nondeterminism bug, and
order dependence is not a syntactic property. Placement and behavior-naming are
already review norms in `testing-discipline` — point 1 (place by behavior, D055)
and point 5 (name the behavior, not the mechanism).

## Chosen

7.2 and 7.3 stay norms, not init rules. 7.2 is added to the delivered
`testing-discipline` skill as a determinism point: pin behavior through injected
or fixture values, and fix a nondeterministic dependence rather than disabling the
test. 7.3 is already covered by that skill's placement (1) and behavior-naming (5)
points, so nothing new is added for it. Only the decidable part of cluster 7 — a
test disabled without a justifying reference — ships as a rule (7.1, D074).

## Rejected

A 7.2 rule banning clock, RNG, network or filesystem calls in test code: such a
call is not by itself a bug (a fixture legitimately reads a clock or a temp file),
identifying "test code" adds a dimension the gate does not have, and order
dependence is invisible to a syntactic pass, so a blanket rule is
high-false-positive against the gate bar (D035). A 7.3 rule for naming or
placement: placement was already shown undecidable on import edges (D055) and
behavior-naming is semantic; both would only duplicate the existing norms. A
pretend invariant for either is forbidden by norm-or-choice.

## Rationale

Norm-or-choice: a rule fits a decidable, high-signal check; a norm fits a behavior
that cannot be checked statically without false positives. 7.1 is decidable and
shipped (D074); 7.2 and 7.3 are not, so they stay norms — 7.2 recorded as a new
determinism point in the delivered norm skill, 7.3 already present — rather than
noisy rules.

## Consequences

B032 ships one init rule, the disabled-test check (7.1, D074). Determinism (7.2)
becomes a visible norm in the delivered `testing-discipline` skill; naming and
placement (7.3) remain its existing norms (D055). No new rule kind, skill or
invariant is added for 7.2/7.3, so the I020 delivery sets are unchanged — only the
skill's text grows. Reassessing 7.2 as a rule would need the test-scope and effect
analysis the syntactic engine lacks (D059). With 7.1 (D074) and 7.2/7.3 (this),
B032/P041 is complete. It supersedes nothing.
