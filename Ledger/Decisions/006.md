# D006 — Complexity-discipline reminders

## Context

Long implementation sessions can accumulate unsupported mechanisms and stronger requirements.

## Chosen

Load the full discipline at session start, issue attention reminders, and require periodic full refreshes using configured token intervals.

## Rejected

Depend on memory alone or inject the full skill at every operation.

## Rationale

Tiered reminders preserve the reasoning constraint without continuously consuming context.

## Consequences

A project hook owns reminder state and the schedule remains directly testable.
