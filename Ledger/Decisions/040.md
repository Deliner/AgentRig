# D040 — Initialize memory in Ledger and sources in Project by default

## Context

The user described the system on 2026-10-26: after initialization a repository
has a Ledger directory, the configuration directory, the Just files directory
and a Project folder that holds only clean code and minimal text files
(Requests.md, part 2, item 4). init defaulted to `memory` for memory and `src`
for sources; this repository already uses Ledger and Project.

## Chosen

init defaults `--memory` to `Ledger` and `--source` to `Project`, so
`paths.sources` is `Project/**` unless overridden. Both options remain
configurable. init still leaves source files to the user.

## Rejected

Keep `memory` and `src`; remove the options and fix the layout; create an
empty Project directory or placeholder files during init.

## Rationale

Defaults make the described layout the result of a plain init without taking
away layouts that existing projects need, as the independent examples show.
Git does not track an empty directory, so creating one would not persist.

## Consequences

Tests and guides that relied on the old defaults name Ledger. Projects that
want other locations pass the options explicitly.
