# D159 — The latency measurement is a cargo example the gate's Clippy compiles

## Context

On 2026-11-11 the user decided to rewrite `measure.py`, the measurement of standalone hook and lint latency in fresh
consumers, without Python within P115. A replacement has to launch and time processes. Ruff, mypy and Vulture checked
the Python script, so its successor needs a checking owner as well. `cargo clippy` without target flags checks only
the library and the binaries, and the architecture rule allows `std::process::Command` only in `shared/vcs`,
`command_runner` and tests.

## Chosen

`Project/shared/testing/examples/measure.rs` is the cargo example `measure` of `Project/Cargo.toml`, run as
`cargo run --example measure -- --worker ABSOLUTE_AGENTRIG > REPORT.md`; it prints the report the script wrote, and
`--output` is gone. The dev-gate Clippy argv names `--lib --bins --examples`, so the gate compiles and lints the
example with the full profile, while test code stays outside the lints as D060 requires. The example is a lint root,
and the `std::process::Command` entry of the architecture rule allows this one file, which reads the exit status of
every process it launches and fails the run on any failure. The `std::fs` entries stay unchanged: the example copies a
consumer with `cp -R` into a `tempfile` directory.

## Rejected

A shell script under tooling: no gate check covers it, and bash 3.2 on macOS can time only through extra `date`
processes inside each short sample. A `[[bin]]` target: every release build would compile it. Launching through
`command_runner`: it wraps each launch in a job and the sandbox inside the timed interval, and an example crate cannot
reach `crate::` owners. Allowing the whole examples directory: the independent consumer examples live there too.

## Rationale

The example keeps the measurement in Rust under the same Clippy profile and structural lint as the product. The
one-file allow names a process owner that does what the rule asks of an owner: it reads each exit code.

## Consequences

Clippy also checks every future example with the full profile. Another example that launches processes needs its own
allow entry. Python stays only in the example Python consumer, which Ruff, mypy and Vulture check.
