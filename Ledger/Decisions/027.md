# D027

## Context

AgentRig develops the worker that runs its own development environment. Automatically rebuilding that environment from edited source makes a candidate compilation failure disable commands and hooks needed to repair it. The user explicitly requested an installed stable environment separate from the candidate.

## Chosen

Pin a verified commit and explicitly install its runtime using the existing package initializer. Working adapters invoke that installed executable. Candidate builds and tests use a separate launcher and cache. Update the pin only after acceptance and install it explicitly.

## Rejected

Automatically replacing the active environment on every source edit; bypassing required gates when the candidate fails; maintaining a second implementation of runtime services or a second environment generator.

## Rationale

The existing initializer already installs a self-contained executable and its embedded resources. A pinned installation preserves working orchestration while the product is being changed. The full gate still compiles and tests the candidate.

## Consequences

A fresh developer clone requires an explicit bootstrap and access to the pinned Git history and Rust toolchain. The installed development package is local generated data. Repository policy, memory and canonical skill sources remain editable and versioned. Consumer setup and upgrade retain their existing ownership and conflict behavior.
