# D216 — Count a decision marker only in a file its decision links

## Context

The bypass audit of 2026-11-19 (B158, example E3) found that a `// DECISION: DNNN` comment lifts a lint rule such as
`panic-path` or `unsafe-site` in any file while decision DNNN exists: the memory check of D037 confirms only that the
record exists, so an agent can quote any accepted decision over an `unwrap`, an `unsafe` block or an `expect`. B158 asks
that the marker lift a rule only in a file that the decision names as its application link, and that otherwise the
error name the decision and the file.

## Chosen

- The memory check reads each source file under `paths.sources` and accepts a `DECISION:` marker only when the
  decision's Applies-in cell links that file. Every other marker is refused in one error that lists each decision with
  its file and asks to link the file from the decision or to remove the marker.
- An `INVARIANT:` marker keeps the existence check of D037.
- The gate runs this check at each commit and at `feature-merge`, so a marker that lint accepts fails before it is
  committed.

## Rejected

- Checking the link inside lint: lint has no access to project memory (D037), and a second parser of the decision index
  in lint would duplicate the memory check that owns it.
- Requiring a link per marked function: Applies-in links name files, and a finer link would need a new link form.
- Applying the rule to invariant markers: an invariant links only its oracle test, and the example projects shipped in
  the rig carry markers of their own invariants in files the rig's invariants cannot link.

## Rationale

A link from the decision to a file is the existing record of where a choice applies, and the memory check already
requires each linked source file to carry the marker. Requiring the reverse makes the relation two-way, so a file the
decision does not name cannot borrow its marker.

## Consequences

The rig's decisions gained links to the files that already applied them, among them the size-exemption template of
`project_setup/lint.rs`, the mode enums of D062 and the comparisons that D156 lets keep their form. Adding a marker now
means adding a link in the same commit. The refusal is a memory-check error, so `just lint` alone still accepts the
marker. An invariant marker still lifts lint rules in any file while its invariant exists.
