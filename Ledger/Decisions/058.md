# D058 — Reject coverage-based test-placement enforcement; TC1 stays a review norm

## Context

B024 asked whether per-test code coverage could enforce TC1 (a test lives beside
the behavior it exercises) where import edges could not (D055), by collecting the
code each test executes (Rust llvm-cov, Python coverage.py) and flagging a test
whose coverage mass lies outside its owning directory subtree. Delivering B024
began with a spike into feasibility, cost and stability.

## Chosen

Keep TC1 a review norm in the testing-discipline skill (D055), already shipped to
consumers by P031. Add no coverage collection, rule, rule kind, invariant or
oracle, and no coverage tool dependency.

## Rejected

Build a per-test coverage subsystem and a "coverage mass outside the owner
subtree" rule; add llvm-cov and coverage.py dependencies to the toolchain and the
init delivery; or record a pretend invariant for a norm that cannot be checked
without false positives (norm-or-choice).

## Rationale

Coverage records every line a test executes, including the shared and dependency
code a correctly placed test naturally calls. "Mass outside the owner subtree"
therefore overflags the exact legitimate pattern D055 named — a test exercising
its own feature while incidentally executing a shared type elsewhere — so the
subject-versus-incidental ambiguity that made TC1 unprovable is not resolved by
coverage, only relocated to execution. Independently, per-test coverage needs
instrumented runs and coverage tooling absent from both toolchains today, bolted
onto a fast static gate selected by affected tests (D035); that is a new dynamic
subsystem whose cost conflicts with the fast-gate norm. Neither prong satisfies
B024's no-false-positive acceptance.

## Consequences

TC1 remains enforced by review through the testing-discipline norm, beside TC2
and TC4 (D057). A placement check becomes reconsiderable only with a signal that
distinguishes a test's subject from incidental execution without flagging normal
dependency use. B024 completes as a recorded norm with no code change.
