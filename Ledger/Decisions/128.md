# D128 — Shipped rules assert AgentRig's standard for new code

## Context

AgentRig's linter serves new projects: fast AI-first, agent-native, cross-platform Rust, large complex projects with a
planned support period of 20 years, all of it dogfooded here. The r8 research round measured the shipped rules on a
holdout of foreign repositories at 31 % useful findings; most of the rest were code written differently from the
shipped forms rather than defects. Several narrowings would have raised that number. The user closed them on
2026-11-07 without changes: AgentRig asserts its standard, code that does not conform is that code's problem, and the
target is mainly new code, all of which must conform.

## Chosen

A shipped rule states AgentRig's standard. Foreign code that is written differently is a violation of that standard,
not a false positive, and measurements on foreign code inform which rules to make without narrowing a shipped rule to
accept foreign idioms.

## Rejected

- Accepting `// SAFETY:` comments, `# Safety` documentation sections, `reason = "…"` in allow attributes and
  `#[ignore = "…"]` as justifications in place of a `DECISION:` or `INVARIANT:` reference.
- Narrowing `disabled-raii` (D092) to its path forms and dropping the `.keep()` and `.into_path()` method forms.
- Exempting a private cell from `global-state`.
- Turning the Tier 2 candidates `msgroster` and `variant-count-literal` (D110) into rules.

## Rationale

One reference form keeps every justification traceable to a recorded decision or an executable invariant, which a
free-text comment is not. A rule that bends to each foreign idiom loses the single form agents can write by default and
reviewers can check at a glance. Precision on foreign code still selects rules: a form that mostly marks correct code
written our way is not a rule.

## Consequences

Foreign holdout precision stays a selection measure for new rules, not a target for existing ones. Rules already shipped
keep their forms; an existing project adopts them through the ratchet baseline (D123). A later change to a shipped
form needs its own decision. Supersedes nothing.
