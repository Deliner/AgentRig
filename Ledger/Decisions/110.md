# D110 — Ship the arc's two disciplines as norm skills and record its verdicts

## Context

The research arc (seven rounds, closed 2026-11-04; B052–B063 selected by the
user's /goal the same day) measured every candidate check against the gate's
near-zero-false-positive bar (D035) on the syntactic engine (D059). Two
disciplines survived as norms whose repairs on this repository were made under
B062 (D108, I021), and a tail of candidates fell below the bar or lost their
predicate. B063 asks for the two norms as delivered skills and for one recorded
verdict per remaining candidate, so none is re-proposed without new data:

- N1, type-driven modelling: step-5 R6 `string-as-enum` (the `matchstr`
  selector reached 5/8 = 62.5 % precision, the best syntactic variant 71 %)
  and the step-6 facets — one dictionary with one definition (`litset-drift`),
  outside-world dictionaries as data (`longmatches`), sorted static tables,
  snapshot/restore (`fieldcopy`), path types (`strpath`), constant equality
  chains, forwarding shims, inverse literal pairs (53 %), integer-literal
  decoding (50 %), tuple variants with primitives (67 % on the holdout), ordinal
  comparison, macro justification and exhaustive destructuring.
- N2, fail-closed enforcement: step-8 R8 verdict-from-failure.
- Tier 2 of the register: `msgroster` drift (r2 5/6, 8/10 with discovery, no
  births on 3 077 additions), `variant-count-literal` (single-file
  configuration 9/11 = 82 %), `ord-eq-mismatch` (predicate not closed; 7/7 on
  the holdout with probe flaws), `enum-roster` (partial rosters are
  legitimate), `equality-chain` on literals (only an identifier with an explicit
  primitive or `&str` annotation), the declared mirror marker (no agent value
  shown in H16/M8, M9 pending) and `sync-comment` v3 (a review signal; in the
  bevy `ui_node.rs:1304` case the compiler already carries the obligation).
- `test-seam` v2 (critic r0: uv `base_client.rs:1114` is a security seam;
  seams for security, linker and test runtime are legitimate).
- `dump-item-name` as a growth threshold.
- R5 layer order and R7 reach-through depth.
- The step-6 dropped candidates (`okdefault`, `emptyif`, `samematch`,
  `numsuffix`, `varset`, `wakelock`, `repeatlit`, `placeholder`, file
  `sortedtable`, `strpath`, `fieldcopy`, `extern "Rust"` hooks, const-bool
  generics, `duplicate-block`, `safety-comment`, `let-underscore`,
  `local-import`, swappable same-type parameters, discarded spawn,
  `machine-path`, `test-assertion-free`) and the critic's four drops
  (`labelled-bool-argument`, `raw-pointer-parameter`, `doc-echo`,
  `cfg-density`).

## Chosen

Two norm skills ship through `init` and live in a `discipline` group beside
`testing-discipline` (D054), with flat symlink aliases so every existing skill
path keeps resolving and the skills root keeps its `directory-size`:

- `type-driven-discipline` (N1): a type earns its definition by closing a
  named invariant, mode or lifecycle — a newtype with one validating entry,
  an `enum` after one parse at the boundary matched exhaustively, constructors
  over `Default` plus setters, typestate only where it forbids a dangerous
  operation, `pub` fields only on a record without an invariant; the step-6
  facets are its related forms; the critic's softenings hold (a named
  invariant rather than "two or more booleans"; staged construction is lawful
  while no invalid object is live). The repository and the delivered AGENTS.md
  name it beside complexity-discipline.
- `fail-closed-enforcement` (N2): a two-variant verdict, `Allow` only from the
  positive check, an error or unknown becomes `Deny` with the cause carried to
  the final decision, a negative test per contract refusal, `Result<bool>`
  allowed when the error propagates. It gets an advisory `edit` route without
  `block`: on `Project/agent_hooks/**` and `Project/change_delivery/**` here,
  on the configured source tree in the delivered template, so the delivered
  and live route sets stay equal (I020).

`Ledger/Norms.md` indexes N1 and N2. Verdicts: `string-as-enum` (R6) is closed
by N1, since 62.5 % is below the bar and the decidable slices already ship as
`boolean-parameter`, `tuple-as-record` and `global-state`; the seven Tier 2
candidates are not rules until new data; `test-seam` v2 is a norm; `dump-item-
name` as a growth threshold is covered by the `file-size` rule (error at 500
non-blank lines, the accepted form), with no separate rule; R5 is withdrawn
because dependency direction is already checked per feature type by
`features::direction` (D044) and a global order would be a second source of
truth; R7 is withdrawn because depth is not encapsulation and its decidable
slice shipped as `super-super-reach` (D100); R8 is withdrawn as a rule because
the polarity of `unwrap_or(false)` is not recoverable from syntax — it is N2
plus the B062 behavioral tests, and the visible `Result<bool>` collapse stays in
`silent-error` (D097); the step-6 dropped candidates and the critic's four
drops carry no rule, skill or norm. No rule kind, oracle, invariant or
`lint.yaml` entry is added; the norms have no executable oracle beyond the
B062 AC1 test already bound as I021.

## Rejected

- Shipping `string-as-enum` or any Tier 2 candidate as an `init` rule: the
  precision is below the bar (D035) or the predicate needs the type-resolving
  frontend the engine omits (D059).
- A blocking route for N1 on the source tree: having read a skill does not
  verify compliance (critic r0), and the stop would hit every edit.
- A pretend invariant for either norm, forbidden by norm-or-choice (D077).
- Two more top-level skill directories: the skills root sits at its
  `directory-size` limit, and raising the limit would weaken a threshold.
- Clippy substitutes: `wildcard_enum_match_arm`, `map_err_ignore`, `cast_*`
  and `allow_attributes_without_reason` were not selected by the user
  (2026-11-02, D107); `missing_fields_in_debug` already covers the Debug
  mirror facet.

## Rationale

Each candidate was measured; a norm with a delivered skill keeps the discipline
portable without a false-positive-prone rule, and the advisory route puts N2
where the cost asymmetry lives — a wrong denial costs a retry, a wrong
permission defeats the policy. Recording the verdicts once prevents
re-proposing the same candidates, as D071, D086, D087 and D093 did for earlier
families. Grouping the three disciplines consolidates a real responsibility
(review norms without an oracle) rather than relaxing the size limit.

## Consequences

B063 ships two skills, one phrase in two AGENTS.md files and one advisory route
in both configurations; the delivered skill set grows by two and the route set
by one, both staying equal to the repository (I020). N1 and N2 are review
norms: an agent applies N1 by instruction and N2 by route guidance, and the
repository's own conformance is the P066 repairs (D108) with the I021 oracle.
Revisiting any verdict needs new data — a closed predicate at or above 90 %
precision on a holdout, or the type-resolving frontend (D059). The change to
`Project` takes one final pin (D051). It supersedes nothing.
