# D196 — A path program's write names only the hook routes its paths reach

## Context

B149: every non-read-only catalog command counted as an opaque shell write, so the hook named the skills of every
route listening to shell writes. In a probe after `init`, `just run write -- mkdir -p Project/data` received the five
memory skills although it touched no memory file, and the agent rightly skipped them; such noise teaches an agent to
skip hook guidance. D047 rejected predicting the targets of opaque shell commands, but mkdir, cp, mv, rm, touch and
chmod receive the paths they change as explicit arguments.

## Chosen

When a catalog command that is not read-only runs mkdir, cp, mv, rm, touch or chmod, the hook takes its operands as
paths relative to the repository root: words after the program that do not start with `-`, and every word after `--`.
A route listening to shell writes applies when an operand and the literal directory prefix of one of the route's
patterns, the components before the first one with glob syntax, are equal or one contains the other, so a directory
operand reaches the routes beneath it; operands outside the repository reach none. The requirement reads `shell
write of PATH` and is keyed by the operand's directory like an edit. An option carrying `=` or `/` before `--`, or an
operand that cannot be resolved, leaves the command opaque, and Git, `just scratch` and other programs stay opaque.

## Rejected

| Alternative | Why |
| --- | --- |
| Exact glob match of each operand | `rm -r Ledger` would name no memory skill though it removes them all |
| Per-program option tables | a table for six programs on several platforms for a guidance list; an unknown option stays opaque |
| Inspect the file system to tell files from directories | the destination of a copy or a move may not exist yet |
| Parse Git subcommands | out of the card; Git paths include pathspecs, revisions and options that change their meaning |

## Rationale

Explicit operands make these writes as visible as an edit, and the prefix overlap errs toward naming a skill: an
operand inside a route's directory, or a directory holding it, names the route even when its glob would not match the
operand itself. Anything the hook cannot classify keeps the earlier list of every shell route.

## Consequences

`just write -- mkdir -p Project/data` names no memory skill, while `just write -- rm Ledger/Plan/001.md` names
edit-plan only. D047's opaque shell write now covers Git, `just scratch` and other programs; the rest of D047 remains.
