# D173 — One rust-toolchain.toml names the rig's Rust

## Context

D042 removed `Project/rust-toolchain.toml` because every configured cargo
invocation pinned `+1.98.1`. By 2026-11-13 that number stood in eleven places:
the rustfmt, Clippy and test commands of the gate, the worker build, bootstrap,
CI, three READMEs and two test fixtures that run `rustc`. Rust 1.100.0 was
released on 2026-11-12. The user asked to migrate the rig and make it the new
standard with one source of truth for the version (B128).

rustup selects a toolchain from a `rust-toolchain.toml` found in the working
directory or its ancestors, not from `--manifest-path`, and sets
`RUSTUP_TOOLCHAIN` for the processes a proxied `cargo` starts: a probe on
2026-11-13 showed `cargo` in the repository printing 1.100.0 and a child
process in `/tmp` seeing `RUSTUP_TOOLCHAIN=1.100.0-aarch64-apple-darwin`.

## Chosen

`rust-toolchain.toml` in the repository root names the rig's Rust: channel
`1.100.0`, the minimal profile and the rustfmt and Clippy components. Every
cargo call takes the toolchain from it through rustup:

- the gate's rustfmt, Clippy and test commands drop `+1.98.1`;
- `tooling/worker/build` runs cargo from the repository root and adds the file
  to its source signature, so a version change rebuilds the worker;
- bootstrap archives the file together with `Project` from the pinned revision
  and builds inside that archive, so the revision's own version applies;
- CI installs the toolchain with `rustup toolchain install` without arguments;
- test fixtures run plain `rustc` and inherit the toolchain of the cargo that
  runs the tests.

READMEs refer to the file instead of a number.

## Rejected

Keep `+X.Y.Z` in each invocation: a version change edits eleven places and one
missed place silently tests on another compiler. Put the file in `Project/`:
commands run from the repository root, where rustup does not see it. A separate
plain version file read by every script: it duplicates what rustup already
reads and still needs rustup to pin the components.

## Rationale

rustup already resolves the toolchain for every cargo and rustc call in the
tree, so one file read by rustup is the version everywhere without code that
reads it.

## Consequences

Changing the rig's Rust is one line. A machine without the listed toolchain
installs it on first use through rustup or CI's install step. This supersedes
D042's removal of `Project/rust-toolchain.toml` and its `+1.98.1` pins; the rest
of D042 remains. Earlier decisions that name Clippy 1.98.1 record the probes of
their time.
