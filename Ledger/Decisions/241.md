# D241 — The protected North Star holds the rig's purpose instead of the opening of AGENTS.md

## Decision

The paragraph that D234 put at the opening of AGENTS.md and CLAUDE.md, the rig's purpose and the criterion for a rig
mechanism, is the text of `Ledger/NorthStar.md` under the heading `# North Star`, and both instruction files no longer
hold it. The North Star is a protected file, so it changes only with the user's `just approve`, and every agent
context receives it in full at its start, together with `Ledger/Glossary.md`. The paragraph keeps D234's wording; only
its place changes.

## Reasons

- B208 AC7 requires the project description to move from the first paragraph of AGENTS.md to the North Star, with its
  text approved by the user through `just approve`; the user approved it on 2026-11-28.
- B208 AC3 gives the North Star in full to the agent whenever its context starts, at launch, after clearing and after
  compaction, so a session still knows the purpose from its first step, as D234 intends.
- B208 AC4 lets the North Star change only with the user's approval, and AGENTS.md is not a protected file.

## Alternatives

- Keep the paragraph in AGENTS.md and CLAUDE.md as well: an agent that reads only the instructions still sees it. Not
  applied: B208 AC7 moves the text, and a copy outside the protected file could change without approval and diverge
  from the approved one.
- Keep the purpose only in AGENTS.md and CLAUDE.md (D234): no new file. Not applied: the purpose could then change
  without the user's approval, which B208 AC4 rules out for the project description.
