# D180 — The shared Clippy profile denies five lints of list V; `unreadable_literal` stays out

## Context

B131 under D151. List V of 2026-11-13 names forms that ready Clippy lints outside the default set detect: a value
whose type comes from context (V-12), a long literal without separators (V-16), XOR used as a power (V-17), host byte
order (V-18), a large array on the stack (V-19) and an iterator chain that may not end (V-30). The P135 protocol
measured each lint alone with Clippy 1.100 on the rig's `Project/` at `89992fa` and on voxel-rust with default
features and with `native`. `default_trait_access` reports 2 sites in the rig and 30 in voxel-rust, all true.
`unreadable_literal` reports 24 sites in voxel-rust, 12 true. The other four report none, and a probe crate shows
each of them firing on its form.

## Chosen

`PROFILE` in `Project/project_setup/rust/clippy.rs` and the dev-gate argv add `default_trait_access`,
`suspicious_xor_used_as_pow`, `host_endian_bytes`, `large_stack_arrays` and `maybe_infinite_iter`, so the shared
profile denies 37 lints. The rig's two struct fields name `Capabilities::default()` and `Lifetime::Task`.

## Rejected

`unreadable_literal`: 12 of its 24 voxel-rust findings are hash constants copied from external specifications, FNV-1a,
SHA-256, the golden ratio and murmur3, which card V-16 leaves, so its precision of 50% is below the 90% of B131 AC1.

Waiting for target code before the four lints without findings: D151 keeps a check that raises quality without it.

## Rationale

Each denied lint forbids a form that compiles and fails later: a default value that changes silently with the field
type, an XOR read as a power, bytes that another host reads in another order, a stack overflow at run time and a
chain that never ends.

## Consequences

`maybe_infinite_iter` also reports an infinite source ending in `find`, `position`, `any`, `all` or `take_while`,
which card V-30 leaves; such a site keeps its form under a referenced `#[expect]` (D080). `large_stack_arrays` uses
Clippy's default threshold of 16384 bytes. `init` writes the five lints for a new project; an existing `clippy`
command keeps its list (D132), and voxel-rust's 30 `default_trait_access` sites are repaired by its own work.
