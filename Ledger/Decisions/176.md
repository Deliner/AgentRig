# D176 — The rig denies unused dependencies and waits three days for new versions

## Context

B128 AC3 and AC4 adopt two Cargo settings of Rust 1.100 for the rig only. The
`unused_dependencies` lint in `[lints.cargo]` reports a dependency that no
target of the package uses. `registry.global-min-publish-age` makes resolution
skip versions published less than the given age ago, keeping an older
compatible one. The rig's dependencies are locked, and the gate builds with
`--locked`; only `cargo add`, `cargo update` or a lockfile regeneration
resolves versions. B128 keeps both settings out of consumer projects.

## Chosen

`Project/Cargo.toml` sets `[lints.cargo] unused_dependencies = "deny"`, so the
gate's Clippy and build stop on a direct dependency that no target uses. The
root `.cargo/config.toml` sets `[registry] global-min-publish-age = "3 days"`,
which cargo reads for every command run inside the repository, so a lockfile
update takes only versions at least three days old. Init writes neither.

## Rejected

A warning level: the card asks for a dependency that stops the gate. The
cooldown in `Project/.cargo`: cargo finds configuration from the working
directory upward, and the gate, the worker build and agents run cargo from the
root as well as from `Project`. A per-registry `min-publish-age`: the rig
resolves only from crates.io, and the global key covers it. Delivering either
setting to consumers: the card's boundary leaves their dependency policy to
them.

## Rationale

An unused dependency adds build time and supply-chain surface without
purpose. The first days after a release are when a broken or compromised
version is usually found and yanked, and the rig rarely needs a dependency on
its release day.

## Consequences

Cargo does not report a direct dependency that the graph also reaches through
another one, as observed with `memchr`; review still covers that case. A fix
published within three days needs the wait or an explicit
`CARGO_RESOLVER_INCOMPATIBLE_PUBLISH_AGE=allow` for that resolution. Bootstrap
builds the locked archive and does not resolve versions.
