# D083 — A `pure` zone also forbids reading the wall clock

## Context

D078 added the architecture.yaml `zone: pure` class, forbidding a
directory's own files from reaching std::env, std::fs or std::process.
On 2026-11-01 the user agreed B038 (Набор II, C3 «детерминизм»): a
module that promises purity must also be reproducible, yet the zone
check misses the canonical non-deterministic read, the wall clock. The
cluster's other sub-points stay norms — entropy/RNG detection is
crate-specific and noisy, collection-iteration order and thread timing
need the rejected type/dataflow frontend (D059), and test determinism
is already testing-discipline 7.2 (D075). The one new portable static
core is the clock read, a reference the resolver already produces as a
full path.

## Chosen

The `pure` zone check additionally reports a reference to
std::time::Instant::now or std::time::SystemTime::now in a zone: pure
directory's own files, at error level, like environment access. The
directory-architecture resolver already resolves each reference to its
full external path (appending the ::now call segment), so the clock
read is matched by exact full-path equality, distinguishing it from the
pure value types of std::time (Duration, the UNIX_EPOCH constant). The
pure-zone finding names the category: "must not read the wall clock"
for a clock read, the unchanged "must not access the environment" for
env/fs/process. This extends D078's zone behavior; D078's environment
set and D079's dependents budget remain.

## Rejected

A blanket clock-read rule everywhere with a justifying-reference
escape, which would false-positive every legitimate timeout, timestamp
and benchmark against the near-zero-FP bar (D035); banning the
std::time namespace by prefix, which would false-positive Duration and
the UNIX_EPOCH constant, the reason D078 excluded std::time; detecting
entropy/RNG, which is crate-specific and noisy; detecting
collection-iteration order or thread timing, which need the rejected
type/dataflow frontend (D059); a new rule kind or skill, since the
check extends the existing directory-architecture rule (like
D079/D076/D070/D078), leaving I020 unchanged and reusing
refactor-large-directory for repair; a pretend invariant for the norm
sub-points (norm-or-choice, D059).

## Rationale

A zone: pure directory promises deterministic, effect-free behavior;
reading the wall clock breaks determinism exactly as reading the
environment breaks effect-freedom, so it belongs in the same contract.
The clock read is a syntactic property of a reference the resolver
already computes, so it is a genuine rule, not a norm. Exact full-path
matching on ::now is near-zero-FP: an Instant has no deterministic
constructor and SystemTime::now is the only non-deterministic
SystemTime associated function, while Duration and UNIX_EPOCH stay
legal. Keeping it opt-in (only pure-declared directories) means the
discipline is additive and never bites code that has not promised
purity.

## Consequences

A directory that declares zone: pure cannot silently read the wall
clock: a time dependence is caught at the gate like environment access.
The extension ships to consumers through init with no new rule kind or
skill, so the I020 delivery sets are unchanged. The repository's one
pure directory (structural_lint/architecture/resolution) reads no clock
and stays green. The strict Clippy profile (D060) is unaffected.
Entropy/RNG, collection-iteration order, thread timing and test
determinism stay norms (D059/D075); further zone classes are separate
work.
