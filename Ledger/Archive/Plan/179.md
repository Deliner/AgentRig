- VAC 2 `c49b0b8`: удалены функции без вызовов в продукте и то, что служило только им.

| Место в `Project/shared` | Что удалено |
| --- | --- |
| `vcs/tree_entry.rs` | метод `FileKind::mode`, его не вызывал никто |
| `vcs/repository.rs` | метод `Repository::diff` и проверка его вывода в тесте `revisions_are_read_exactly_and_preserve_worktrees` |
| `atomic_files/bounded_read.rs` | файл с `read_regular`, его реэкспорт, запись в architecture.yaml и тесты `exact_limit_reads_preserve_bytes_and_fingerprints` и `non_regular_paths_cannot_supply_artifact_bytes` |
| `fs_with_context/mod.rs` | реэкспорт `OpenOptionsExt`, им пользовался только `read_regular` |

Проверка `digest` из удалённого теста осталась у владельца отпечатков: тест
`fingerprints_are_lowercase_sha256_hex_of_the_content` сверяет тот же SHA-256 строки `abc`.

Пробная сборка на голове ветки, где модули закрыты внутри крейта, а вызовы бинарников оставлены, не находит функций
без вызовов. Она называет только реэкспорты типов, которые вызывающий получает из сигнатур:

| Тип | Откуда его получает вызывающий |
| --- | --- |
| `project_config::AffectedTests` | поле `affected` у `Check` |
| `fs_with_context::Error` | ошибка в `fs_with_context::Result` |
| `vcs::Observation` | результат `Repository::observe` |
