# P168 — tests-directory: тесты лежат только в директории `tests/`

## Feature

[B179](../Backlog/179.md): тесты лежат только в директории `tests/`. Выбор — пользователь 2026-11-20: «5-ю сохраняй,
правку применяй. Бери в работу». Карточка в Git в первом VAC ветки `feature/tests-directory`. Границы VAC — за
исполнителем.

## User capability

Тесты любой директории всегда в одном месте, и набор растёт без переезда.

## Acceptance

Карточка **B179 (AC1–AC4)** — критерии и формулировки там; идентификаторы те же.
