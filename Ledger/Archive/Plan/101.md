# P101 — false-edges: граф зависимостей Rust без ложных рёбер

## Feature

[B087](../Backlog/087.md): граф зависимостей Rust без ложных рёбер. Источник — карточка B087 на ревизии `54aa528`; выбор
и авторизация — пользователь 2026-11-10. Порядок и границы VAC — за исполнителем.

## User capability

Проверка архитектуры Rust видит только настоящие зависимости, и проекту не нужно менять видимость или атрибуты ради
анализатора.

## Acceptance

Карточка **B087 (AC1–AC3, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/false-edges` (база master после слияния P100): правка, тесты и ротация — один VAC. Карточка задаёт
поведение полностью, отдельное решение не потребовалось.

- AC1 — выполнен. Инспектор Rust не заходит в модификатор видимости, поэтому путь в `pub(in …)` не записывается как
  ссылка (`structural_lint/architecture/source/rust/mod.rs`). Тест `test_visibility_path_is_not_a_dependency`:
  фикстура компилируется rustc, `pub(in crate::a)` внутри `a::b` не даёт ребра b → a и цикла; тот же файл с настоящим
  вызовом `crate::a::seven()` даёт цикл. На установленном `a4113fa` первый случай падает.
- AC2 — выполнен. `expect` входит в список встроенных атрибутов рядом с `allow`, `warn`, `deny` и `forbid`, и крейт с
  `#[expect]` или `#![expect]` анализируется полностью. Случай `expect` в
  `test_rust_attributes_preserve_dependency_evidence`: без обратного ребра находок нет, с ним — цикл через тело
  функции под атрибутом; на установленном `a4113fa` случай падает. На клоне voxel-rust `71440d0` с
  `#[expect(clippy::expect_used)]` вместо `#[allow]` в `src/core/control/local.rs` установленный рантайм даёт 4310
  находок о незавершённом анализе, кандидат — ни одной.
- AC3 — выполнен. На клоне voxel-rust `71440d0` восемь `pub(crate)` в `src/native/host/game.rs` и
  `src/native/host/profiles.rs` возвращены к `pub(in crate::native)`: установленный рантайм даёт цикл src/native →
  src/native/android → src/native/host → src/native и превышение fan-out, кандидат — ни одной находки.
- Внешний крейт: случай `bindgen` того же теста уже проходил и на установленном рантайме — импорт `wasm_bindgen` не
  даёт рёбер внутри проекта; на чистом клоне voxel-rust циклов нет. Тесты архитектуры — 137 passed.
- Границы — соблюдены: проверка на переносимых фикстурах, затем на клоне voxel-rust без правок проекта; обходы
  voxel-rust снимаются в финальном проходе по его ветке.
