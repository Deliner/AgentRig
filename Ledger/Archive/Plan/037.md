# P037 — Линтер безопасности

## Feature

[B026](../Backlog/026.md): добавить линты безопасности для кода AgentRig — обоснование
`unsafe` ссылкой на решение/инвариант (1.1), Bandit-группа ruff `S` для Python (1.2) и скан
хардкод-секретов (1.3) — и привести наш код к зелёному (догфуд). Исходный контракт — ревизия
карточки B026 в Git (7253a89); согласовано и выбрано на исполнение пользователем 2026-10-29
в составе набора кластеров 1–8.

## User capability

Агент из коробки не оставляет необоснованный `unsafe` и типовых дыр безопасности: опасный
код обязан нести рядом ссылку-обоснование, а типовые уязвимости Python и хардкод-секреты
ловятся гейтом до коммита, а не в ревью.

## Acceptance

Карточка **B026 (1.1–1.3)**, включая её границы. Правила — только внутри `Project`,
измеряемые чисто синтаксически (без вывода типов); возможность уезжает в поставку `init` как
universal ([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md)) после поведенческой
проверки. Что не проверяется чисто, без ложных срабатываний, остаётся нормой с записанной
причиной (norm-or-choice), а не ослабленным правилом. Наш код приводится к зелёному; пороги и
селекторы не ослабляются ради проходимости. Уровень реализации и границы VAC выбирает
исполнитель (по одному под-правилу за VAC, гейт держится зелёным).

## Delivery

Выполнено на ветке feature/security-lint; контракт — ревизия B026 в 7253a89. Статус:
complete. Три под-правила доставлены, каждое чисто синтаксически, только на `Project`, с
уездом в поставку `init` ([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md)):

- **1.1 unsafe-justification** ([D065](../../Decisions/065.md)/[D066](../../Decisions/066.md))
  — каждый Rust `unsafe`-блок/функция обязан нести ссылку `DECISION:`/`INVARIANT:` на строке
  выше, иначе находка; 11 FFI-мест `command_runner/jobs` помечены общим обоснованием D066.
- **1.2 ruff bandit (`S`)** ([D064](../../Decisions/064.md)) — группа `S` включена для Python
  в dev-гейте; шум assert/subprocess (S101/S603/S607) сведён к тестовому коду. Это
  dev-гейт-профиль, не init-возможность.
- **1.3 hardcoded-secret** ([D067](../../Decisions/067.md)) — находка на строковый литерал,
  совпавший с фикс-набором форматов учёток (PEM private-key, AWS, GitHub, Google, Slack), в
  Rust и Python; additively к bandit (ловит по значению, в обоих языках). Ремонтный навык
  remove-secret; три refactor-* навыка сгруппированы под `refactor/` ради лимита каталога.

1.1 и 1.3 — отдельные `Kind` структурного линтера в `rules::ALL` и обоих хендлерах, уезжают в
`init`; 1.2 — профиль ruff. Наш код зелёный под всеми тремя (у воркера нет таких литералов;
тест матчера строит образцы конкатенацией). На правила-`Kind` — двухкоммитная схема
(enabling → пин+бустрап → live), так как гейт `[lint]` гоняет установленный бинарь. Пин
stable.txt на gate-принятую голову ветки перед merge ([D051](../../Decisions/051.md));
memory-check зелёный после переноса карточек в Archive.

Проверка: коммит-гейт каждого VAC зелёный; на go-live 1.3 — build/lint/memory/rustfmt/clippy/
rust-test 85/ruff/ruff-format/mypy/pytest 304/typos/vulture все PASS.
