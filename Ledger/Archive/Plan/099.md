# P099 — lock-exclude: `init` исключает lock-файлы из file-size

## Feature

[B095](../Backlog/095.md): `init` исключает lock-файлы из file-size. Источник — карточка B095 на ревизии `4518103`;
выбор и авторизация — пользователь 2026-11-10. Порядок и границы VAC — за исполнителем.

## User capability

Новый проект не получает находок размера по сгенерированным файлам.

## Acceptance

Карточка **B095 (AC1–AC2, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/lock-exclude` (база master после слияния P098): правка, тест и ротация — один VAC. Карточка задаёт
поведение полностью, отдельное решение не потребовалось.

- AC1 — выполнен. Описание правила file-size несёт исключения по умолчанию `**/Cargo.lock`, `**/package-lock.json` и
  `**/uv.lock` (`structural_lint/rules/structure.rs`); их получают шаблон `init` и `lint-rule nonblank-lines
  --example`. Тест `test_shipped_file_size_skips_package_manager_lock_files`: после `init` три lock-файла по 600 строк в
  `Project/tool` находок file-size не дают; на установленном `c21b07e` тест падает.
- AC2 — выполнен. В том же тесте `large.rs` из 600 строк рядом с ними даёт находку file-size. Тест примеров правил
  `test_rule_examples_ship_excludes_only_where_decided` ждёт теперь и эти исключения у file-size.
- Границы — соблюдены. Существующие настройки не меняются: исключения по умолчанию читает только пример каталога
  правил. На клоне voxel-rust `71440d0` без блока исключений file-size `src/Cargo.lock` (3443 строки) и
  `src/package-lock.json` (574) дают ошибки, с поставляемыми шаблонами — ни одной; ручные исключения voxel-rust можно
  заменить поставляемыми при обновлении проекта.
