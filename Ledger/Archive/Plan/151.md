# P151 — hook-every-tool: хук проверяет каждый вызов инструмента

## Feature

[B152](../Backlog/152.md): хук проверяет каждый вызов инструмента и отказывает, если проверить не может. Выбор —
пользователь 2026-11-19: «Со 142 по 168 можешь последовательно делать». Карточка в Git на ревизии `40bd894`,
согласование текста в `577777c`. Границы VAC — за исполнителем.

## User capability

Нет инструмента или сбоя, при котором действие агента проходит мимо проверок рига.

## Acceptance

Карточка **B152 (AC1–AC3, границы, неизвестное)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/hook-every-tool` от master `52d728b`. Решения [D199](../../Decisions/199.md) и
[D200](../../Decisions/200.md).

- VAC 1 `28cf511`: разбор пути заменяет каждое существующее имя, кроме символической ссылки, на имя, которое хранит
  файловая система.
- VAC 2 `5f8e081`: классификатор `agent_hooks/tools.rs` для диспетчера и режима восстановления, `notebook_path` как путь

- VAC 3: пин `5f8e081` командой `just bootstrap HEAD`, живая проба Claude Code в риге и перенос P151 и B152 в архив.
