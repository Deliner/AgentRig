# P059 — super-super-reach: путь через два уровня модулей вверх

## Feature

[B058](../Backlog/058.md): новый вид правила `super-super-reach` — `use`-объявление либо путь в
выражении или типе, содержащий `super::super`, вне тестового кода и без обоснования. Источник —
исследовательская дуга (`coverage-map.md` шаг 2, `meta/register.md` ремонт 3); реализация
авторизована пользователем 2026-11-04 (/goal). Исходный контракт — ревизия карточки B058 в Git.
Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки: файл ссылается на владельца через `crate::` или реэкспорт у
родителя, а не на своё место в дереве; перенос каталога не ломает импорты. Навык ремонта
`anchor-at-crate`. Наш код: восемь продакшн-строк в шести файлах переводятся на `crate::`.

## Acceptance

Карточка **B058 (AC1, границы)**.
- **AC1** — `super::super` в `use` или пути вне тестов без обоснования → одна находка на сайт;
  один `super::` — не находка.

Новый `kind:` → двухфазная доставка с мид-бранч пином ([D051](../../Decisions/051.md)): источник →
пин → проводка (`catalog::ALL`, `lint.yaml`, навык в `assets.rs`, I020) → догфуд: ремонт восьми
сайтов (`architecture/runner/analysis.rs`, `architecture/source/rust/macros.rs`,
`resolution/rust/tree.rs`, `resolution/rust/macros.rs`, `initialization/init.rs`,
`initialization/wizard.rs`), `just candidate lint` → 0 находок, существующие тесты зелёные; живая
проба. Пороги не ослабляются.
