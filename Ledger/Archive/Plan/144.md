# P144 — state-current-vac: State описывает текущую VAC

## Feature

[B142](../Backlog/142.md): State описывает текущую VAC. Выбор — пользователь 2026-11-19: «Со 142 по 168 можешь
последовательно делать». Карточка в Git на ревизии `564868f`. Границы VAC — за исполнителем.

## User capability

State всегда описывает текущую VAC и остаётся коротким, каждый коммит несёт State своей VAC, а агенту не нужны лишние
команды, чтобы так его вести.
