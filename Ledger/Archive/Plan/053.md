# P053 — Tier B: unchecked-index, disabled-RAII, sibling-cycle (+ оценка TOCTOU / lossy-int-cast)

## Feature

[B044](../Backlog/044.md): пять пунктов Tier B из того же отчёта воркфлоу-ревью, расширяющих охват
панических / ресурсных / файловых / приведения-типов смеллов плюс внутрикаталожные циклы. Исходный
контракт — ревизия карточки B044 в Git; согласовано пользователем 2026-11-01 в составе Tier A+B.
Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки дополнительные переносимые проверки: (1) `unchecked-index` — индексация
или слайсинг (`x[0]`, `x[1..]`, `map[key]`) вне тестов без обоснования становится находкой (панический
путь, аналог `panic-path`); (2) `disabled-RAII` — отключение RAII (`tempfile …keep()`/`.into_path()`,
`mem::forget`, `ManuallyDrop::new`, `Box::leak`) вне тестов без обоснования становится находкой;
(3) `sibling-cycle` — взаимные зависимости соседних файлов одного каталога (встречный `pub use`)
становятся находкой расширением `directory-architecture`. Для каждого правила — эскейп `// DECISION:`/
`// INVARIANT:`. TOCTOU (`.exists()`/`.is_file()` перед действием) и lossy-int-cast (`as` в более узкий
или знаковый тип) оцениваются как правило или норма при реализации.

## Acceptance

Карточка **B044 (AC1–AC5 + границы)**. AC1 `unchecked-index`: индексация/слайсинг вне тестов без
обоснования — находка; AC2 `disabled-RAII`: перечисленные отключения RAII вне тестов без обоснования —
находка; AC5 `sibling-cycle`: встречные sibling-зависимости в одном каталоге — находка (расширение
`directory-architecture` D070/D079, без нового вида/навыка). AC3 TOCTOU/path-exists и AC4 lossy-int-cast
оцениваются правило-vs-норма при реализации; где вскроется высокий FP (поток/типы, семейство D059) —
честно норма (бар D035, norm-or-choice), а не ослабление порога, притворных инвариантов нет. Новые виды
правил идут двухфазной доставкой с мид-веткой бутстрапом; I020 растёт согласованно (вид правила + навык
на каждое новое правило). Наш код приводится к зелёному (догфуд).

## Delivery

Ветка `feature/tier-b-rules` (база master `4ce7316`), сохраняется после интеграции. Приёмка заземлена на
near-zero-FP бар ([D035](../../Decisions/035.md)) и честную норму там, где вскрывается высокий FP
(семейство [D059](../../Decisions/059.md)); пороги не ослаблены, притворных инвариантов нет. Из пяти
кандидатов одно — переносимое правило, четыре — норма.

- **AC2 `disabled-raii` — ПРАВИЛО, выполнено.** Новый вид правила двухфазной доставкой:
  VAC-B1 `515e585` (инертный источник — вид `DisabledRaii`, детектор `disabled_raii`/`raii_marker`, тест
  маркеров, [D092](../../Decisions/092.md)), мид-ветка пин stable=`515e585` (`81ed95c`), VAC-B2 `f06e2a3`
  (проводка `registry` rust.rules + `catalog::ALL`, живое правило в `lint.yaml`: error, только `.rs`,
  tests excluded; навык `own-the-resource`; строка D092 дополнена `[repository rule]`+`[skill]`). I020:
  вид правила и навык выросли на один (delivered == live). Догфуд: `.keep()` в
  `command_runner/jobs/storage.rs` обоснован `// DECISION: D092`; `just candidate lint` по репозиторию —
  0 находок. Коммит-гейт VAC-B2 зелёный целиком (build/lint/memory/rustfmt/clippy/rust-test 107/ruff/mypy/
  test 347 вкл. I020).
- **AC1 `unchecked-index` — НОРМА ([D093](../../Decisions/093.md)).** Синтаксический движок не отличает
  паникующую индексацию (`Vec`/срез/`HashMap`) от непаникующей (`serde_json::Value` → `Null`) без вывода
  типов (D059); бланкет-правило дало бы преобладание ложных против near-zero-FP бара (D035). Это «честная
  норма при высоком FP» из границ карточки, а не ослабление порога.
- **AC3 `toctou` — НОРМА ([D093](../../Decisions/093.md)).** Пара «проверка→использование» требует анализа
  потока данных через окно гонки, которого движок не даёт (D059). Карточка прямо допускала норму.
- **AC4 `lossy-int-cast` — НОРМА ([D093](../../Decisions/093.md)).** Сужение `as` требует исходной и
  целевой разрядности (вывод типов, D059); флаг на каждый `as` зашумляет законные расширения. Карточка
  прямо допускала норму.
- **AC5 `sibling-cycle` — НОРМА ([D093](../../Decisions/093.md)), НЕ расширение.** Модель
  `directory-architecture` намеренно трактует каталог как одну связную единицу (`graph.rs` пропускает
  рёбра внутри каталога), детектируя циклы только между каталогами ([D079](../../Decisions/079.md));
  взаимные ссылки файлов-соседей идиоматичны в Rust (наши собственные `structural_lint/languages`-соседи
  ссылаются взаимно), поэтому правило было бы высоколожным и противоречило бы зафиксированной модели.
  Кросс-каталожные циклы остаются под существующим правилом.

Финальный пин stable.txt на голову ветки ([D051](../../Decisions/051.md)) + bootstrap выполняется
отдельным коммитом до `just feature-merge`. **Tier A ([P052](052.md)) + Tier B отчёта воркфлоу
завершены.**
