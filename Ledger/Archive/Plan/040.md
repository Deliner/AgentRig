# P040 — Линты именования

## Feature

[B031](../Backlog/031.md): имена отражают смысл, а не прячут свалку — запрет имён-помоек (6.1),
осмысленные идентификаторы (6.2), запрет магических чисел (6.3) — и привести наш код к зелёному
(догфуд). Исходный контракт — ревизия карточки B031 в Git (7253a89); согласовано и выбрано на
исполнение пользователем 2026-10-29 в составе набора кластеров 1–8.

## User capability

Каталог-свалка (`utils`/`helpers`/`misc`/`common`) ловится гейтом до коммита, а не в ревью;
`shared` остаётся легитимным домом для кросс-фичевых листьев. Имена каталогов отражают
ответственность, а не служат мусорным ведром.

## Acceptance

Карточка **B031 (6.1–6.3)**, включая её границы. Чисто-синтаксическая, высокосигнальная часть
уезжает в поставку `init` ([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md));
шумящее остаётся нормой с записанной причиной (norm-or-choice), а не ослабленным правилом с
ложными срабатываниями ([D035](../../Decisions/035.md)). Наш код приводится к зелёному; пороги и
селекторы не ослабляются ради проходимости. Уровень реализации каждого под-правила и границы VAC
выбирает исполнитель (гейт держится зелёным).

## Delivery

Выполнено на ветке feature/naming-lints; контракт — ревизия B031 в 7253a89. Статус: complete.
Решения по правилу norm-or-choice (движок синтаксический, без вывода типов — D035/D059):

- **6.1 имена-помойки** ([D072](../../Decisions/072.md)) — доставлено в `init` новым правилом
  `dump-name` (target directory, Level): каталог, чей собственный basename — один из фикс-набора
  `{utils, helpers, misc, common}`, это находка; `shared` вне набора (легитимный дом кросс-фичевых
  листьев). Мера читает имя каталога из inventory, без языкового обработчика. Двухкоммитная схема
  lint-kind: вариант+дескриптор+мера+тест → пин+бустрап → `catalog::ALL` + правило
  `.agentrig/lint.yaml` (scope Project) + маркеры. Навык ремонта — существующий
  `refactor-large-directory` (новый навык не добавляется); I020 по skills не меняется, растёт
  только rule-kinds. Правило механизирует норму «reuse alone does not justify shared/common/utils
  buckets», которую прежде ничто не проверяло.
- **6.2 осмысленные идентификаторы** и **6.3 магические числа** ([D073](../../Decisions/073.md)) —
  норма, не init-правило: 6.2 требует анализа области видимости (отличить законное короткоживущее/
  цикловое имя от бессмысленного модульного), а `data`/`tmp`/однобуквенные часто законны; 6.3 не
  отделяет магический литерал от законного (индексы, размеры, коды, степени двойки) без контекста —
  поэтому clippy/ruff держат такие линты в opt-in шумных группах. Оба высоколожны против near-zero-FP
  бара (D035); ослабленная версия ослабила бы высокосигнальный бар всего набора.

Наш код зелёный под `dump-name` (в Project нет каталогов-свалок; кандидат-линт exit 0). Пин
stable.txt на gate-принятую голову ветки перед merge ([D051](../../Decisions/051.md)); memory-check
зелёный после переноса карточек в Archive.
