# P079 — file-fan-out: исходящие связи файла

## Feature

[B072](../Backlog/072.md): файл, который использует больше заданного числа внутренних частей проекта, — находка;
точка входа программы не отмечается. Источник — карточка B072 (ревизия в Git `759a2eb`); выбор и авторизация — /goal
пользователя 2026-11-07. Порог по умолчанию и единицу «части проекта» исполнитель выбирает замером на корпусе и
записывает в Delivery. Порядок и границы VAC — за исполнителем.

## User capability

## Acceptance

Карточка **B072 (AC1–AC2, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/file-fan-out` (база master `25a5a97`). Один VAC без нового вида правила: проверка расширяет правило
directory-architecture, как бюджет входящих связей D079; затем пин D051.

- Выбор при доставке. Единица «части проекта» — точный каталог, как у D079. Считаются разрешённые ссылки на файлы
  `.rs`, `.py` и `.pyi` в других каталогах; объявления `mod`, свой каталог и ресурсы вроде `include_str!` не
  считаются. Порог по умолчанию 10, одна настройка проекта `fan_out` в разделе `architecture:` правила. Находка на
  файле без строки, с уровнем и навыком правила и списком каталогов. Точки входа — файлы из `rust_roots` и Python
  `__main__.py`.
- Замер. В AgentRig 157 файлов используют другие каталоги: 154 не больше семи, три — 11, 12 и 14. Корпус r8 движком
  не измерить: корни крейтов с неподдержанными макросами не разбираются. Прокси по путям `use`, сверенный с движком
  на 158 файлах AgentRig со средней разницей 0,44, дал на 10 944 файлах внутри одного крейта: больше 6 — 96, больше
  7 — 55, больше 8 — 36, больше 10 — 13. С соседними крейтами рабочего пространства выше 10: bevy 226 из 1 307, uv 70
  из 643, ruff 56; alacritty, coreutils, ripgrep, tokio, vaultwarden и zed — 0. Отсюда порог 10 и настройка на весь
  проект, а не на каталог.
- AC1 выполнен: тест `test_fan_out_default_budget_flags_files_above_ten_directories` — `src/hub/api.py` с импортом
  11 пакетов даёт находку `file uses 11 other project directories (budget 10)`, с импортом 10 пакетов молчит; тест
  `test_fan_out_setting_flags_wide_files_but_not_crate_roots` с `fan_out: 1` — `src/a/mod.rs`, который использует
  `src/b` и `src/c`, даёт находку с этим списком.
- AC2 выполнен: тест `test_fan_out_exempts_python_main_entry_point` — те же 11 импортов в `src/hub/__main__.py`
  находок не дают; те же ссылки в корне крейта `src/lib.rs` тоже молчат.
- Свои три файла разделены по ответственности без изменения поведения: запуск проверки —
  `change_delivery/gate/check.rs`, оценка правил — `structural_lint/evaluation.rs`, команды с загруженным проектом —
  `command_line/project.rs`, проверка конфигурации — `project_setup/doctor.rs`. После ремонта у трёх файлов по 10
  каталогов, больше нет ни у одного.
- Навык `refactor-large-directory` получил ремонт широкого файла, README архитектуры описывает `fan_out`,
  `lint-rules` показывает настройку. Ссылки D036 и D072 на измерения перенесены в `evaluation.rs`.
- Проверки перед VAC: `just candidate lint` — код 0; clippy с `-D warnings` чист; тесты fan-out — 5 passed. Решение
  [D121](../../Decisions/121.md).
