# P091 — rust-expansion: анализатор зависимостей Rust разбирает include!, macro_rules! и атрибуты

## Feature

[B083](../Backlog/083.md): анализатор зависимостей Rust учитывает `include!` со строковым путём, `include!` кода
`OUT_DIR`, тела `macro_rules!`, экспортные атрибуты и атрибут-макросы внешних крейтов без кодогенерации. Источник —
карточка B083, сохранённая первым VAC ветки `feature/rust-expansion`; выбор и авторизация — пользователь 2026-11-07.
Порядок и границы VAC — за исполнителем.

## User capability

Rust-проект с генерацией кода, FFI-экспортом и wasm проходит проверку архитектуры по реальным зависимостям.

## Acceptance

Карточка **B083 (AC1–AC5, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/rust-expansion`: карточка, выбор, разбор и решение [D136](../../Decisions/136.md) — VAC A, после
перебазирования на master `02071e7` это `2c163ed`; ротация — завершающий VAC. На `2c163ed`:
`just run rust-test -- structural_lint::architecture` — 52 passed; тесты включений, макросов, атрибутов и `init` —
54 passed; `just run lint` по AgentRig — код 0 без находок.

- AC1 — выполнен. `test_source_includes_compose_the_including_module`: литеральный `include!` даёт цикл через
  подключённый файл, отсутствующий файл — находку «incomplete»; `includes_and_local_macros_resolve_to_their_files`
  разрешает включение в файл и отклоняет отсутствующий.
- AC2 — выполнен. Тот же тест: `include!` кода `OUT_DIR` проходит без находок, вычисляемый путь `concat!("api",
  ".rs")` — «incomplete».
- AC3 — выполнен. `test_macro_dependencies_and_provenance` для `definition` и `generated`: путь из тела
  `macro_rules!` с `$crate` даёт ребро модуля-владельца, находки нет;
  `rust_expansion_forms_become_includes_macro_paths_and_generated_scopes` пропускает `Self::`.
- AC4 — выполнен. `test_rust_attributes_preserve_dependency_evidence`: `no_mangle` в `unsafe(...)` и `export_name`
  без находок, `#[wasm_bindgen]` — зависимость от `wasm_bindgen`, атрибут своего крейта — «incomplete».
- AC5 — выполнен. Кандидатный lint на voxel-rust `52dac3e` с конфигурацией `init`: без правки кода voxel остаются
  135 неполных находок Rust в src/schema/abi и одна в src/ui/touch/tests.rs. Эти файлы подключаются через
  `include!` в два крейта, библиотеку и генератор схемы, и `crate::` в них значит разные крейты. После замены на
  `quarterworld::` с `extern crate self as quarterworld;` в src/core/lib.rs неполных находок Rust нет, а
  `cargo check --locked --tests --examples --features ui,test-fixtures` проходит. Правка коммитится в voxel первым VAC
  исправлений. В AgentRig `just run lint` — без находок.
- Границы — соблюдены: макросы не раскрываются, код из `OUT_DIR` не читается, атрибут-макрос своего крейта и
  вычисляемое включение остаются неполными.
