# P058 — discarded-result: `.status()?;` / `.output()?;`

## Feature

[B059](../Backlog/059.md): расширение правила `discarded-result` ([D090](../../Decisions/090.md)) на
выражение-инструкцию `<…>.status()?;` / `<…>.output()?;`, где код завершения и вывод команды
молча выбрасываются. Источник — исследовательская дуга (`coverage-map.md` «discarded-outcome (b)»);
реализация авторизована пользователем 2026-11-04 (/goal). Исходный контракт — ревизия карточки
B059 в Git. Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки: провалившаяся внешняя команда, чей исход выброшен инструкцией
`….status()?;`/`….output()?;`, — находка; сохранённое или использованное значение — нет.
Навык `handle-discarded` дополняется формой.

## Acceptance

Карточка **B059 (AC1, границы)**.
- **AC1** — инструкция с отброшенным `….status()?`/`….output()?` вне тестов без обоснования прямо
  выше → находка; `let s = …status()?;`, `….status()?.success()`, аргумент — не находки.

Изменение существующего детектора без изменения `lint.yaml` → мид-бранч пин нужен только если
stable-бинарю требуется принять новую конфигурацию (ожидается: нет — только финальный пин
[D051](../../Decisions/051.md)). Decision, расширяющий D090, при доставке; догфуд
`just candidate lint` → 0 находок (наши `status()`/`output()` let-связаны — проверяется); живая
проба. Пороги не ослабляются.

## Delivery

Ветка `feature/discarded-result-ext`, один VAC: `discarded_method` под `discarded_result` в `languages/rust.rs`
(`try_expression` → `call_expression` без аргументов с методом `status`/`output`; `ok` — только голый вызов),
дескриптор `discarded-result`, тест `rust_flags_propagated_status_and_output_statements_that_drop_the_outcome`
в `languages/tests/markers.rs`, навык `handle-discarded` с формой `status()?`/`output()?` (+ строка назначения в
`references/architecture.yaml`), [D099](../../Decisions/099.md), ротация; `lint.yaml` не менялся, мид-бранч пин не
нужен — только финальный ([D051](../../Decisions/051.md)). Наблюдаемая верификация 2026-11-04 на рабочем дереве:
`cargo fmt --check` OK, `cargo clippy --all-targets -D warnings` OK, `cargo test --lib` — 119 passed (AC1: находки
строк 2 и 5 фикстуры — `Command::new("git").status()?;` и многострочная цепочка `.output()?;`; не-находки —
обоснованная `output()?;`, `let status = …status()?;`, `…status()?.success();`, аргумент `check(…output()?)`,
`writer.output(data)?;` с аргументом, `…status();` без `?`, `thing.ok()?;` и тестовый модуль); догфуд
`tooling/worker/run run candidate -- lint` — 0 находок (exit 0; наши `status()`/`output()` в `shared/vcs/git.rs` и
`shared/vcs/directories.rs` let-связаны); живая проба — `fn probe` в `shared/vcs/git.rs` с
`command(root, &["status"]).status()?;` и `….output()?;` даёт `ERROR [discarded-result] … git.rs:249 (status)` и
`… git.rs:250 (output)` с навыком `handle-discarded`, после отката снова 0 находок. AC1 и догфуд выполнены.
