# P085 — exit-code: вердикт `.success()` и один владелец процессов

## Feature

[B076](../Backlog/076.md): линт находит функцию `Result<bool>`, которая возвращает `.success()` статуса процесса
без `.code()`; `std::process::Command` разрешён только владельцам запуска процессов, три сайта AgentRig переходят к
ним. Источник — карточка B076 (ревизия в Git `e90d81a`); выбор и авторизация — пользователь 2026-11-07. Форму
правила исполнитель решает при доставке и записывает в решении и Delivery. Порядок и границы VAC — за исполнителем.
