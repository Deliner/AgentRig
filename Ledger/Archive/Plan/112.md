# P112 — clippy-config: init отвечает за пороги Clippy в clippy.toml

## Feature

[B104](../Backlog/104.md): init отвечает за пороги Clippy в clippy.toml. Источник — карточка B104 на ревизии `d45f3a2`; выбор и авторизация — пользователь 2026-11-10. Порядок и границы
VAC — за исполнителем.

## User capability

Недопустимые сочетания флагов нельзя записать ни в риге, ни в проектах.

## Acceptance

Карточка **B104 (AC1–AC3, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/clippy-config` от master `7990589`: исправления, пороги, `init`, решение
[D154](../../Decisions/154.md) и ротация одним VAC. `Project/clippy.toml` задаёт `avoid-breaking-exported-api = false`
и `max-struct-bools = 1`; Clippy гейта читает его для рига, `init` берёт пороги из него же. Пробы в открытом модуле
`project_config`: структура с двумя полями `bool` роняет `just run clippy` с кодом 101 и ошибкой «more than 1 bools
in a struct», открытый enum из трёх вариантов, один из которых оканчивается именем enum, — с ошибкой «variant name
ends with the enum's name». После удаления проб профиль проходит.

- AC1 — выполнен. Семь структур с двумя `bool` получили enum. `read_only` у `Command` и записи задачи стал `Access`,
  один тип в `project_config` вместо трёх копий; `process_group` записи задачи стал `Grouping`. Флаги слияния и
  rebase у `Observation` стали `Operation`, rebase главнее. Три поля источника в записи доказательств стали
  `Source`: рабочее дерево, индекс с отпечатком или ревизия. `module_declaration` зависимости стал `Relation`, `json`
  и `validate_only` вывода линтера стали `Format` и `Mode`, `context_reset` напоминания возвращает `advance`. В
  `commands.yaml` и записях задач остались булевы `read_only` и `process_group`; `resume` показывает
  `vcs.operation`, `checks.json` пишет `source`, старые файлы читаются как рабочее дерево.
- AC2 — выполнен. `avoid-breaking-exported-api = false` распространяет проверки имён и типов на открытый API.
  Единственное место, `Reference::CommentReference`, стало `Reference::Comment`; имя `comment-reference` в
  настройках линтера не изменилось.
- AC3 — выполнен. `init --language rust` находит файл, который читает Clippy: первый `.clippy.toml` или
  `clippy.toml` от каталога манифеста до корня. Недостающие пороги дописываются в начало, остальное сохраняется
  байт в байт; без файла создаётся `clippy.toml` в корне; другое значение порога — коллизия до установки. Мастер
  показывает файл в списке. `test_clippy_profile.py`: новый проект получает файл рига; файл проекта в каталоге
  манифеста под обоими именами и в корне над ним дополнен, другого файла нет; дополнен `.clippy.toml`, а
  `clippy.toml` рядом не тронут; другое значение отклоняет `init`, файлы не меняются; у Python проекта файла нет.
  Живая проба на потребителе с комментарием, `msrv` и таблицей `[[disallowed-methods]]`: до `init` Clippy принимает
  структуру с двумя `bool` с кодом 0, после `init` падает с кодом 101 на `struct_excessive_bools`, настройки
  проекта на месте.
- Границы — `CLIPPY_CONF_DIR` отклонён: Clippy читает один файл и пропустил бы файл проекта; причины в D154.
- Выбор файлов в гейте: `changes` и `targets` возвращают `Scope` с `Full` и `Only` вместо `Option`, где `None`
  значил полный прогон.

Анализатор архитектуры не разбирает `#[serde(with = ...)]` и тогда бросает анализ всего крейта, поэтому колбэки
названы через `deserialize_with` и `serialize_with`.
