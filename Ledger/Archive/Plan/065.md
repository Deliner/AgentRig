# P065 — C-профиль dev-гейта и ограждение `unsafe`

## Feature

[B060](../Backlog/060.md): профиль clippy dev-гейта (`.agentrig/commands.yaml`,
[D060](../../Decisions/060.md)) получает `-D clippy::exit`, `should_panic_without_expect`,
`missing_fields_in_debug`, `rest_pat_in_fully_bound_structs`, `self_named_module_files` (по одному
VAC); крейт получает `#![deny(unsafe_code)]` с единственным обоснованным `#[allow(unsafe_code)]` на
поддереве `command_runner::jobs`. Источник — решение пользователя 2026-11-02 п. 3 и шаги 2/6
исследовательской дуги; реализация авторизована пользователем 2026-11-04 (/goal). Не выбраны:
`wildcard_enum_match_arm`, `map_err_ignore`, `cast_*`, `allow_attributes_without_reason`. Исходный
контракт — ревизия карточки B060 в Git. Порядок и границы VAC — за исполнителем.

## User capability

Разработчик AgentRig: dev-гейт проваливает скрытый выход из процесса, паникующий тест без
ожидания, ручной `Debug` с пропущенными полями, `..`-образец в полностью связанной структуре и
смешение стилей модулей; `unsafe` вне `command_runner/jobs` не компилируется. Потребителям не
поставляется (dev-гейт этого репозитория).

## Acceptance

Карточка **B060 (AC1–AC7, границы)**.
- **AC1–AC5** — по одному линту за VAC; гейт зелёный; пробный нарушающий фрагмент проваливает
  проверку clippy кандидата, удаление возвращает зелёный.
- **AC6** — `#![deny(unsafe_code)]` в `Project/lib.rs`; `#[allow(unsafe_code)]` со строкой
  `// DECISION:` над объявлением поддерева; `unsafe` вне поддерева не компилируется.
- **AC7** — decision, расширяющий D060: набор, невыбранные линты, проверка
  `derived_hash_with_manual_eq`/`derive_ord_xor_partial_ord` как deny-по-умолчанию.

Изменяются `commands.yaml` и `Project/lib.rs`/`command_runner/mod.rs` → финальный пин
([D051](../../Decisions/051.md)); `lint.yaml` не меняется. Ожидаемый объём ремонта — 0 по всем пяти
линтам (проверяется гейтом). Пороги не ослабляются.
