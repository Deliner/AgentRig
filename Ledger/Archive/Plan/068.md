контракт — ревизия карточки B063 в Git. Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает из коробки две дисциплины агентного кода: типы, закрывающие названный
инвариант (newtype с единственным входом, `enum` вместо строк-режимов, конструкторы вместо
`Default`+сеттеров, типосостояния только против опасной операции, `pub`-поля без инварианта) и
fail-closed вердикты (двухвариантный enum, `Deny` с причиной при ошибке, негативный тест на сайт);
AGENTS.md называет N1 рядом с complexity-discipline; отклонённые кандидаты записаны, чтобы не
предлагаться заново без новых данных.
