приведения его в порядок.

## Acceptance

## Delivery

Выполнено на ветке feature/dogfood-init поверх 40dbc30; контракт — ревизия B020
в 561f1ae. Статус: complete.

`init` отдаёт три markdown-правила (Project/project_setup/lint.rs, helper
`markdown`), параметризованные путями проекта: `markdown-size` (nonblank-lines,
README/AGENTS, ошибка при >70, исключён каталог памяти), `markdown-width`
(line-width, README/AGENTS, ошибка при >120, исключён каталог памяти),
`markdown-placement` (forbidden-file, `.md` под деревом исходников, кроме
README/AGENTS/SKILL, уровень error). Все три ссылаются на `condense-markdown`.
Навык `condense-markdown` добавлен в поставку (Project/project_setup/assets.rs).
Генерируемый AGENTS.md теперь переносится по словам до 100 колонок (`wrap`/`fold`
в assets.rs, после подстановки путей), поэтому собственный `check` потребителя
держит отданные рамки при любой длине путей.

- K1: конфигурация после `init` содержит три правила с ожидаемыми параметрами;
  каталог памяти исключён из size/width (проверено в тесте — README под Ledger не
  даёт находок size/width).
- K2: `lint` сообщает о README длиннее 70 строк, строке шире 120 и постороннем
  `.md` в дереве исходников; файлы в границах проходят без находок.
- K3: `condense-markdown` среди отданных навыков, и markdown-правила указывают его
  навыком ремонта.
