# P086 — clippy-types: пять линтов clippy с типами в dev-гейте

## Feature

[B075](../Backlog/075.md): команда `clippy` в `.agentrig/commands.yaml` запрещает `string_slice`,
`iter_over_hash_type`, `collection_is_never_read`, `read_zero_byte_vec` и `unchecked_time_subtraction`; сайты
AgentRig отремонтированы. Источник — карточка B075 (ревизия в Git `e90d81a`); выбор и авторизация — пользователь
2026-11-07. Порядок и границы VAC — за исполнителем.

## User capability

Гейт ловит классы дефектов, которым нужны типы.

## Acceptance

Карточка **B075 (AC1–AC6, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/clippy-types` (база master `52cfe55`), по одному VAC на линт и финальный пин D051: аргументы команды
`clippy` новых полей не требуют. Каждый линт доказан пробой: фрагмент, дописанный в `Project/lib.rs`, проваливает
`just run clippy` с кодом 101 и ошибкой этого линта, после удаления — код 0. Пересчёт на `52cfe55`: `string_slice` —
16 сайтов, `iter_over_hash_type` — 1, остальные три — 0, как в карточке.

- AC1 и AC6, VAC `666e61a`. 15 сайтов без среза строки: `strip_prefix` в `project_memory/format.rs` и
  `structural_lint/config/mod.rs`, `get(..)` в `project_memory/mod.rs`, `project_memory/source.rs` (5),
  `shared/syntax/mod.rs`, `architecture/source/rust/conditions.rs` (2), `languages/rust/global_state.rs` и
  `languages/rust/mod.rs`, `trim_start_matches('.')` в `architecture/resolution/python/mod.rs`, `bytes()` в
  `languages/manifest.rs`. Владелец `text()` переехал в P085 из `languages/mod.rs` в `languages/measure/mod.rs` и
  остаётся со срезом под `#[allow(clippy::string_slice)]` и `DECISION: D127`. Для `project_memory/source.rs` выбран
  `get`, а не второй владелец среза в `shared/syntax`. Проба `&text[1..]` — «indexing into a string may panic».
  Решение [D127](../../Decisions/127.md) фиксирует набор и отвергнутые линты разбора с причинами.
- AC2, VAC `b28b9bd`. Граф зависимостей Plan в `plan` и `acyclic` хранится в `BTreeMap`. Проба `for` по ключам
  `HashMap` — «iteration over unordered hash-based type».
- AC3, VAC `211b6b1`. Проба с вектором, в который только пишут, — «collection is never read».
- AC4, VAC `0073f22`. Проба `read` в `Vec::with_capacity(8192)` — «reading zero byte data to `Vec`».
- AC5, этот VAC. Проба `timeout - elapsed` для `Duration` — «unchecked subtraction of a `Duration`».
- Гейты коммитов: `666e61a` — все проверки PASS, rust-test 155 и test 352 passed, после повтора: первый запуск упал
  с «No space left on device», `cargo clean --profile dev` для `.cache/worker` освободил 19,2 ГБ; `b28b9bd` — test
  233 passed; `211b6b1` и `0073f22` — test 114 passed; везде все проверки PASS.
