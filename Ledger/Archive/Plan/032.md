# P032 — Статическая проверка публичной поверхности тестов

## Feature

[B023](../Backlog/023.md): статически выявлять TC2 («элемент сделан публичным лишь ради
теста») и TC4 («чёрные ходы в приватные внутренности») из навыка `testing-discipline`,
дав движку извлечение видимости символов и обратный индекс ссылок. Исходный контракт —
ревизия карточки B023 в Git (568c683); согласовано и выбрано на исполнение пользователем
2026-10-28.

## User capability

«`pub` ради теста» и чёрный ход в приватные внутренности выявляются из коробки, а не
держатся в голове ревьюера; давление тестов не расширяет незаметно публичную поверхность
продукта.

## Acceptance

Карточка **B023 (K1–K3)**, включая её границы и неизвестное. Осуществимость и
отсутствие ложных срабатываний на реальном репозитории подтверждаются на этапе
реализации; иначе пункт остаётся нормой с записью причины (norm-or-choice), без
«притворного» инварианта — прецедент [P031](031.md)/[D055](../../Decisions/055.md).
Уровень реализации и границы VAC выбирает исполнитель.

## Delivery

Выполнено на ветке feature/test-visibility-norm; контракт — ревизия B023 в 568c683.
Статус: complete. Кода не добавлено.

По исследованию движка структурного линтера (architecture/source/rust, resolution/rust,
модель источника) установлено: это синтаксический анализатор зависимостей модулей —
видимость символов не извлекается; объявления собираются только на уровне модуля, методы
и ассоциированные функции не собираются; ссылки суть use/квалифицированный путь/модуль/
макрос и резолвятся до файла, а вызовы методов по получателю не захватываются; тип не
резолвится. Поэтому ни K1 (видимость), ни K2 (обратный индекс ссылок по символу), ни K3
(правило «публично только ради теста») нельзя реализовать без ложных срабатываний:
главный случай (метод/ассоциированная функция, расширенные до `pub` ради теста) движок
не видит вовсе, а для свободных элементов обратный индекс разбивают glob-импорты,
ре-экспорты, тела макросов и функции-значения.

- TC2 — только публичная поверхность: норма. Кандидат на правило отклонён
  ([D057](../../Decisions/057.md)).
- TC4 — без чёрных ходов: норма; тот же пробел возможностей, что у TC2.

Границы совпали с карточкой: осуществимость подтверждалась при реализации и отклонена;
норма TC2/TC4 уже отдана потребителю навыком `testing-discipline` (P031), страж
докфудинга I020 не менялся (правил, видов правил и навыков не добавлено). Статический
контроль станет возможен лишь при семантическом резолвинге (типы получателей, ссылки
через glob/ре-экспорт/значения). Проверка: VAC прошёл коммит-гейт; memory-check зелёный
после переноса карточек в Archive.
