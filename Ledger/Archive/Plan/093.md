# P093 — coverage-include: `config-check` проверяет карту affected только на файлах из include проверки

## Feature

[B085](../Backlog/085.md): правило покрытия D124 в `config-check` смотрит для каждой проверки только файлы из её
include. Источник — карточка B085, сохранённая первым VAC ветки `feature/coverage-include`; выбор и авторизация —
пользователь 2026-11-09. Порядок и границы VAC — за исполнителем.

Проекты с отдельными наборами тестов под разные фичи проходят `config-check` честной картой.
