# P109 — platform-runtime: рантайм проекта на нескольких платформах

## Feature

[B086](../Backlog/086.md): рантайм проекта на нескольких платформах. Источник — карточка B086 на ревизии `54aa528`;
выбор и авторизация — пользователь 2026-11-10. Порядок и границы VAC — за исполнителем.

## User capability

Проект с AgentRig коммитит и сливает ветки на Linux и macOS с одной ревизии, без обхода хуков.

## Acceptance

Карточка **B086 (AC1–AC3, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/platform-runtime` (база master после слияния P108 `13ea029`), один VAC
([D150](../../Decisions/150.md)).

- Решение, переданное исполнителю: двоичные файлы рантайма хранятся в Git, по одному на платформу, в
  `{service}/bin/PLATFORM/agentrig`. `{service}/bin/agentrig` стал постоянным POSIX-скриптом запуска: он выбирает
  рантайм по `uname -sm` с именами архивов выпуска `macos-arm64` и `linux-x86_64`. Новая команда `runtime-add`
  ставит скрипт и свой исполняемый файл как рантайм текущей платформы и заодно переводит проект с одним бинарником.
  Шаблон tools покрывает `bin/**`.
- AC1 — выполнен на macOS arm64 и на имитации Linux x86_64. Тест
  `test_hooks_run_the_runtime_built_for_the_reported_platform` переносит рантайм в каталог платформы, которую сообщает
  фальшивый `uname`, и хук pre-commit доходит до проверки ветки рантаймом для `Darwin arm64` и `Linux x86_64`.
  Настоящий запуск на Linux x86_64 не проведён: здесь нет Linux-машины и Linux-сборки. Его покажет матрица CI с
  Ubuntu 24.04 и macOS 15 или пользователь.
- AC2 — выполнен на macOS arm64. `test_runtime_add_moves_a_single_binary_project_to_platform_runtimes` переводит
  проект с одним бинарником командой `runtime-add`, коммитит через хуки и проходит `feature-merge` вместе с проверкой
  tools. `test_independent_project_delivery` (I002) проходит коммит и `feature-merge` в новой раскладке. Для Linux
  x86_64 действует та же оговорка, что в AC1.
- AC3 — выполнен: без рантайма для `linux-riscv64` хук pre-commit завершается с кодом 2 и называет платформу, каталог
  и команду `agentrig runtime-add`.
- Ограничение записано в D150. При `git switch` на базу git запускает хук reference-transaction из дерева базы,
  поэтому первое слияние, которое приносит в базу рантайм новой платформы, выполняется на платформе, которую база уже
  поддерживает. Вариант со слиянием до переключения отклонён: он меняет интеграцию и не помогает при rebase.
- Границы. На клоне voxel-rust `71440d0` в scratchpad `runtime-add` перевёл раскладку, после смены шаблона tools на
  `bin/**` проверка tools проходит. Коммит через хуки запускает рантайм macOS через скрипт запуска и останавливается
  только на двух находках D148 в телах макросов; их разбирает финальный проход voxel-rust. С фальшивым Linux x86_64
  хук называет платформу и команду. По D150 ветка voxel-rust сливается в main с Linux после `runtime-add` там; это
  проверяет пользователь. Под voxel-rust риг не подгонялся.
