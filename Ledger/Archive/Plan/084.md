# P084 — disallowed-methods: методы ФС с ошибкой без пути

## Feature

[B078](../Backlog/078.md): запись политики `disallowed` перечисляет имена методов; вызов такого метода без
аргументов с пробросом ошибки через `?` или `.map_err(Into::into)` вне `allow` — находка; запись `std::fs` в
`.agentrig/lint.yaml` перечисляет методы ФС, а сайты AgentRig вызывают обёртки `shared::fs`. Источник — карточка
B078 (ревизия в Git `e90d81a`); выбор и авторизация — пользователь 2026-11-07. Порядок и границы VAC — за
исполнителем.

## User capability

Ошибка файловой системы всегда называет действие и путь.

## Acceptance

Карточка **B078 (AC1–AC2, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/disallowed-methods` (база master `d0d4f2e`), две фазы с пином D051: установленный runtime отвергает
неизвестное поле `methods` в `.agentrig/lint.yaml`. Фаза 1, VAC `f7a539f`: поле `methods`, извлечение вызовов в
`architecture/source/rust/calls.rs`, политика и вызов из анализа, тест, README, решение D125. Пин `5a05e0b`. Фаза 2:
обёртки владельца, ремонт сайтов, запись в `.agentrig/lint.yaml`, Delivery и ротация P084/B078.

- Выбор при доставке. Вызов внутри аргументов макроса тоже находка: дерево разбора не содержит выражений внутри
  `ensure!`, поэтому та же форма `. имя ( ) ?` или `. имя ( ) . map_err ( Into::into )` ищется по токенам. Без этого
  проба давала 11 строк вместо 15: четыре сайта стояли в `ensure!`. Для дескриптора, открытого через `fs::open`,
  владелец получил `file_metadata(file, path)`, для проверки существования — `try_exists(path)`; обе ошибки — «inspect
  <путь>». `project_config/mod.rs` стал бы 21-м зависимым `shared/fs` при бюджете 20, поэтому корень проекта
  разрешает `project_root` в `project_config/settings`, который уже зависит от владельца, рядом с `relative`.
- AC1 выполнен: тест `test_disallowed_methods_flag_bare_calls_whose_errors_propagate` — находки в строках 2, 4, 12 и
  14 файла вне `allow`: `?`, `.map_err(Into::into)` через перенос строки и обе формы в `assert!`. Не находки:
  `.map_err` с другой функцией, `.ok()`, вызов без проброса, `if let`, вызов с аргументом, метод вне списка, тот же
  код в разрешённом файле. `lint-config-check` отвергает пустое имя и `path.exists`; `lint-rules` описывает поле.
  Тест — 11 passed.
- AC2 выполнен: проба кандидата с копией конфига, где запись `std::fs` перечисляет `canonicalize`, `read_dir`,
  `metadata`, `symlink_metadata`, `read_link` и `try_exists`, дала ровно 15 строк и 16 вызовов, как в карточке. Все
  сайты вызывают обёртки `crate::shared::fs`, запись в `.agentrig/lint.yaml` перечисляет эти методы, `just candidate
  lint` — код 0 без находок. Тест владельца `existence_and_handle_metadata_name_the_path` проверяет текст ошибки
  `try_exists`. Решение [D125](../../Decisions/125.md).
- Гейт коммита `f7a539f`: все проверки PASS, test 226 passed. Пин D051 `5a05e0b`: `stable.txt` = `f7a539f`,
  `just bootstrap` прошёл.
