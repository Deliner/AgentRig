# P067 — владелец консольного вывода

## Feature

[B061](../Backlog/061.md): один лист в `Project/shared` владеет записью в stdout/stderr, 73 сайта
`print_*` печатают через него (AC1); профиль clippy dev-гейта получает `-D clippy::print_stdout`/
`print_stderr` с обоснованным `allow` на владельце (AC2); decision, уточняющий
[D060](../../Decisions/060.md) (AC3). Источник — исследовательская дуга (`coverage-map.md` шаг 6
«продуктовые исходы»); реализация авторизована пользователем 2026-11-04 (/goal). Исходный
контракт — ревизия карточки B061 в Git. Порядок и границы VAC — за исполнителем.

## User capability

Разработчик AgentRig находит источник любой строки вывода в одном месте и меняет формат одним
изменением; наблюдаемый вывод всех команд не меняется (тесты CLI, hook и lint зелёные); пробная
печать вне владельца проваливает гейт.

## Acceptance

Карточка **B061 (AC1–AC3, границы)**.
- **AC1** — владелец в `Project/shared` (имя — за исполнителем); продакшн-код печатает только
  через него; вывод не меняется.
- **AC2** — `-D clippy::print_stdout -D clippy::print_stderr` в профиле; `#[allow]` со строкой
  DECISION у владельца; пробная печать вне владельца — красный гейт.
- **AC3** — decision: вывод — продукт, печатает владелец.

Изменяется `Project` и `commands.yaml` → финальный пин ([D051](../../Decisions/051.md)); `lint.yaml` не
меняется; `just candidate lint` → 0 находок (в том числе `directory-architecture`: владелец
объявляет реальный радиус `dependents`). Тестовый код и `dbg!` ([D081](../../Decisions/081.md)) вне
AC.

## Delivery

Ветка `feature/console-owner` (база master `806c2a1`). VAC-A `92a4703` (AC1), VAC-B (AC2, AC3,
[D109](../../Decisions/109.md), ротация P067/B061).

- AC1 выполнен: владелец — `Project/shared/console` (`architecture.yaml`: `type: flat`, `dependents: 13`
  — реальный радиус, без строки lint сообщает «depended on by 13 other directories (budget 6)»);
  функции `stdout(impl Display)`, `stderr(impl Display)`, `prompt(impl Display) -> io::Result<()>`
  (`print!` + `flush` для вопроса мастера `init --interactive`). 73 продакшн-сайта в 23 файлах
  (55 `println!`, 17 `eprintln!`, 1 `print!`) печатают через него: `console::stdout("literal")` (7),
  `console::stdout(value)` (18), `console::stdout(format!(…))` (47), `console::prompt(format!(…))?` (1);
  бинари `main.rs`/`standalone.rs` импортируют `agentrig::shared::console`. Вывод не изменился: на итоговом
  дереве полный pytest `run test -- Project -q` — 435 passed (наборы CLI, hook и lint сравнивают текст
  stdout/stderr), `cargo test --lib` 128 passed; гейт VAC-A — 128 rust-test, 371 pytest.
  Проектный выбор: макросы `out!`/`err!` отвергнуты — анализатор архитектуры по построению не
  анализирует `#[macro_export]` и вызовы макросов своего крейта (D059), и без экспорта макрос недостижим
  из бинарей; владелец — функции (зафиксировано в D109).
- AC2 выполнен: в `clippy` профиля `.agentrig/commands.yaml` — `-D clippy::print_stdout`,
  `-D clippy::print_stderr`; `shared/console/mod.rs` открывается `// DECISION: D109` +
  `#![allow(clippy::print_stdout, clippy::print_stderr)]` (форма D080). Проба: `println!` + `eprintln!` в
  `command_runner/summary.rs` → `tooling/worker/run run clippy` красный с именами обоих линтов;
  после восстановления файла — зелёный.
- AC3 выполнен: [D109](../../Decisions/109.md) — вывод — продукт, печатает владелец; снимает исключение
  print-линтов D060, остальное D060 в силе.
- Границы соблюдены: тестовый код не тронут (clippy без `--all-targets`), `dbg!` вне AC; `lint.yaml` не
  менялся; `just candidate lint` → 0 находок. Сырые байтовые ретрансляции (`io::stdout().write_all` в
  `streams.rs`) — не print-макросы, вне AC.
- Финальный пин D051 — отдельным коммитом перед `just feature-merge`.
