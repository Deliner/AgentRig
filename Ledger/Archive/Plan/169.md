# P169 — test-code-out: тестовый код не живёт в файлах кода

## Feature

[B177](../Backlog/177.md): тестовый код не живёт в файлах кода. Выбор — пользователь 2026-11-20: «Бери в работу. ...
Вот эти все 5 штук». Карточка в Git в редакции первого VAC ветки `feature/tests-directory`. Границы VAC — за
исполнителем.

## User capability

Тест не может опереться на приватное файла. Внутренности файла меняются без правки тестов.

## Acceptance

Карточка **B177 (AC1–AC4)** — критерии и формулировки там; идентификаторы те же.

## Delivery

- Ветка `feature/test-code-out` от master `4846866`. VAC 1 `f5e51af`, решение [D224](../../Decisions/224.md): вид
  правила `test-in-code-file`, его детектор и навык `move-test-code-out`; навыки `relocate-tests` и
  `testing-discipline` объявляют тесты только через вход; `init` пока не выдаёт правило.
- VAC 2 `0749148`: тестовый код рига вынесен из `actionable_findings.rs`, `agent_hooks/input.rs`, `shared/vcs/git.rs`
  и `extraction/rust/conditions.rs` в `tests/` своих директорий. Тест приватной `grouped` заменён тестом через
  `lint --warnings`. Тест контекста Git раньше проходил впустую, теперь требует один пройденный дочерний тест.
  Пример Rust держит `tests::doubles` в `tests/mod.rs`. Гейт: 580 тестов.
- Две фазы: пользователь подтвердил пин `0749148`, закреплённый в `f9b5528`, затем предложение `.agentrig/lint.yaml`
  с правилом после `test-placement`. Фаза 2 `dd0e05f`: правило включено в риге, `init` выдаёт его. Гейт: 597 тестов.
