# P048 — Контракты поведения: `debug_assert!` не подменяет реальный контракт (Rust)

## Feature

[B039](../Backlog/039.md): новое правило `debug-assertion` — вызов макроса `debug_assert!`,
`debug_assert_eq!` или `debug_assert_ne!` в не-тестовом Rust-коде без ссылки `DECISION:`/`INVARIANT:`
на строке прямо выше становится находкой. Семейство `debug_assert` компилируется только при
`cfg(debug_assertions)` и вырезается в release, поэтому закреплённый им контракт молча не выполняется
в проде. Кластер C5 Набора II (agent-native, переносимо на любое приложение) — следующий после C3.
Исходный контракт — ревизия карточки B039 в Git; согласовано пользователем 2026-10-31 в составе
набора C1–C10 (блок-одобрение карточек).

## User capability

Проект получает из коробки правило «контракт поведения не закрепляется на проверке, вырезаемой в
release»: вызов `debug_assert!`/`debug_assert_eq!`/`debug_assert_ne!` в не-тестовом Rust-коде без
ссылки `DECISION:`/`INVARIANT:` прямо выше — находка до коммита. Агент обязан поднять проверку до
`assert!` (контракт во всех сборках), убрать её как лишнюю либо записать обоснование ссылкой на
решение/инвариант. `assert!` не трогается — это реальный контракт; тестовый код исключён; совпадение
внутри строкового литерала находкой не считается.

## Acceptance

Карточка **B039 (AC1–AC3)**, включая границы. AC1: каждый вызов `debug_assert!`/`debug_assert_eq!`/
`debug_assert_ne!` в Rust без ссылки `DECISION:`/`INVARIANT:` на строке прямо выше — находка error;
с ссылкой прямо выше — без находки. AC2: тестовый код не затрагивается — тела `#[cfg(test)]`-модулей
и `#[test]`-функций (обход предков, как у `panic-path`) и файлов тестовых каталогов (`**/tests/**`,
`**/tests.rs`); разбор по AST, строковый литерал `debug_assert` — не находка. AC3: новый вид правила
`debug-assertion` и новый навык ремонта `firm-up-assertion`; вид в `catalog::ALL`, навык в
`assets.rs` → возможность уезжает в `init` ([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md)),
наборы видов правил и навыков растут на один и остаются сбалансированными (delivered == live); наш
код зелёный (в репозитории нет вызовов `debug_assert!`). Границы: только Rust;
`assert!`/`assert_eq!`/`assert_ne!` не трогаются; Python `assert`, `#[must_use]`/проглоченный
результат ([D059](../../Decisions/059.md)/[D068](../../Decisions/068.md)), контракт прозой
([D037](../../Decisions/037.md)), механизм `INVARIANT` ([D020](../../Decisions/020.md)) — норма/покрыто;
профиль clippy ([D060](../../Decisions/060.md)) остаётся строгим dev-гейтом. Притворного инварианта нет.
