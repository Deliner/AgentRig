# P153 — program-arguments: аргументы разрешённых программ не запускают другой код

## Feature

[B154](../Backlog/154.md): аргументы разрешённых программ не запускают другой код. Выбор — пользователь 2026-11-19:
«Со 142 по 168 можешь последовательно делать». Карточка в Git на ревизии `40bd894`, согласование текста в `577777c`.
Границы VAC — за исполнителем.

## User capability

Разрешённая программа делает только своё дело и не запускает чужой код.

## Acceptance

Карточка **B154 (AC1–AC2, неизвестное)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/program-arguments` от master `654e76f`. Решение [D202](../../Decisions/202.md).

- VAC 1 `3af5afb`: запись `deny` стала типом `Flag`, который разбирается при загрузке конфигурации. `--name` запрещает
  сокращения и значения через `=`, `-c` запрещает слитные короткие флаги с этой буквой, `-name` запрещает слова с этим
  началом. Запись другой формы считается ошибкой конфигурации. `rg` рига запрещает `--pre` и `--hostname-bin`.
  `accepts_args` принимает `operands`, и команда `test` от `init` отказывает словам агента, которые начинаются с `-`.
- VAC 2: пин `3af5afb` командой `just bootstrap HEAD`, команда `test` рига переведена на `operands`, живые пробы, перенос
  P153 и B154 в архив.

| Критерий | Итог |
| --- | --- |
| AC1 | выполнен: `denied_flags_are_refused_in_every_spelling_their_program_reads` отказывает `git rebase --exe=id`, `--exec id` и `-qxid`, `git grep --open-files-in-pa=cat` и `-iOcat`, `rg --pr`, `--pre=cat` и `--hostname-bin=sh`, `find -okdir` и пропускает `--empty=drop`, `git grep --or`, `rg --pretty --pre-glob`, `find -name`; со старым сравнением начала слова тест падает; живые `just read -- rg --pr cat x` и `just read -- git grep -iOcat x` получили отказ, `just read -- rg --pretty -c …` прошёл |
| AC2 | выполнен: шаг `test_words_only_name_tests` в обоих тестах поставки кладёт чужой `foreign.toml` с runner для cargo или `foreign.py` для pytest; `just run test -- --config foreign.toml` и `just run test -- -p foreign` завершаются с ошибкой, файл-метка не появляется, а `just run test -- ИМЯ` проходит с «1 passed»; если `operands` пропускает флаги, оба теста падают; живой `just run test -- --config foreign.toml` в риге получил отказ, фильтр `just run test -- project_config::tests::settings …` прошёл |
| Неизвестное | решено: команда каталога описывает допустимые слова полем `accepts_args`: `true`, `false` или `operands`, только имена и пути |
