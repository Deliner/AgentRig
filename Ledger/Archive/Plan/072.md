# P072 — self-hygiene: находки межпроектного обзора в собственном коде

## Feature

[B051](../Backlog/051.md): проза обоснований D066/D095 совпадает с кодом сигналов, преобразование PID в
`jobs/process.rs` идёт проверяемым путём, предусловие `MaybeUninit::zeroed` записано у сайта. Источник — карточка
B051 (ревизия в Git `7b5629c`); выбор и авторизация — /goal пользователя 2026-11-07. Порядок и границы VAC — за
исполнителем.

## User capability

Собственный код AgentRig соответствует дисциплине, которую проект предлагает правилами: обоснования не переобещают,
преобразование PID согласовано, предусловие zeroed-инициализации явно.

## Acceptance

Карточка **B051 (AC1–AC3, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/self-hygiene` (база master `ff23ad9`). VAC 1 `c7e6842` (AC1–AC3, решение D113), финальный VAC
(Delivery, ротация P072/B051). Гейт VAC 1 зелёный: rust-test 15 passed, test 219 passed, memory и clippy PASS.

- AC1 выполнен через решение-преемник [D113](../../Decisions/113.md): три best-effort сайта в `jobs/process.rs`
  (`libc::signal(…, SIG_DFL)` в `restore_default_signals`, два `libc::kill`) ссылаются на D113, где проверка
  результата и `errno` для них не заявлена; утверждение о проверке остаётся за проверяющими сайтами `group.rs`,
  macOS identity и `poll`. Тексты D066 и D095 не менялись (D020); у D066 убрана ссылка применения на
  `process.rs`, функция `restore_default_signals` сохраняет ссылку D095. Код сайтов не менялся.
- AC2 выполнен: оба преобразования PID в `jobs/process.rs` — `i32::try_from(child.id())?`, как в `group.rs`;
  для корректных PID поведение то же — тесты `command_runner` в гейте зелёные.
- AC3 выполнен: строкой выше `MaybeUninit::<T>::zeroed()` в `identity/macos.rs::info<T>` стоит
  `// DECISION: D113`; D113 требует, чтобы `T` был структурой libc из простых данных, у которой любой набор бит,
  включая все нули, — допустимое значение.
- Границы соблюдены: поведение для текущих входов не изменилось, нового правила, инварианта и настроек нет.
