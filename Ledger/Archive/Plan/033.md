# P033 — Размещение теста по реально исполняемому коду

## Feature

[B024](../Backlog/024.md): проверять TC1 (тест лежит рядом с тем, что проверяет) по
реально исполняемому коду — собирать per-test покрытие (Rust `llvm-cov`, Python
`coverage.py`) и помечать тест, чья масса покрытия лежит вне поддерева владельца.
Исходный контракт — ревизия карточки B024 в Git (568c683); согласовано и выбрано на
исполнение пользователем 2026-10-28.

## User capability

Место теста выводится из того, что он реально трогает, а не из текстовых импортов;
«тест судится по коду, который он трогает» становится проверяемым, если покрытие
окупается.

## Acceptance

Карточка **B024 (K1–K2)**, включая её границы и неизвестное. Сначала спайк
осуществимости; по итогам — проверка либо фиксация, что покрытие не окупается/нестабильно,
и TC1 остаётся нормой с записью причины (norm-or-choice), без «притворного» инварианта —
прецедент [P031](031.md)/[D055](../../Decisions/055.md). Уровень реализации
и границы VAC выбирает исполнитель.

## Delivery

Выполнено на ветке feature/test-placement-norm; контракт — ревизия B024 в 568c683.
Статус: complete. Кода не добавлено, зависимостей покрытия не добавлено.

Спайк осуществимости: инструментов покрытия нет ни в одном тулчейне — `cargo llvm-cov`
отсутствует (`error: no such command: llvm-cov`), в Python нет ни `coverage`, ни
`pytest_cov` (ImportError). Их пришлось бы добавить в тулчейн и отдать в поставку `init`.
Содержательно покрытие не решает TC1: оно учитывает весь исполненный код, включая общий
и зависимый, поэтому правило «масса покрытия вне поддерева владельца» переотмечает ровно
тот законный случай, что назвал [D055](../../Decisions/055.md) — тест, исполняющий общий
тип в `rules/kind.rs` при проверке своей фичи. Неоднозначность «предмет vs попутное»
не снимается покрытием, а лишь переносится с импорта на исполнение. Независимо: per-test
покрытие — медленная динамическая подсистема инструментированных прогонов поверх быстрого
статического гейта, выбираемого затронутыми тестами ([D035](../../Decisions/035.md)).

Решение [D058](../../Decisions/058.md): TC1 остаётся нормой (рядом с D055/D057), без
правила, вида правила, инварианта и зависимостей покрытия. Границы совпали с карточкой:
осуществимость измерялась спайком и отклонена; норма TC1 уже отдана потребителю навыком
`testing-discipline` (P031). Проверка: VAC прошёл коммит-гейт; memory-check зелёный после
переноса карточек в Archive.
