## Delivery

Ветка `feature/clippy-revisit` от master `48310aa`: профиль, исправления, решение [D153](../../Decisions/153.md) и
ротация одним VAC. Три lint-а добавлены в `PROFILE` в `Project/project_setup/clippy.rs` и в argv `clippy` в
`.agentrig/commands.yaml`, всего 32. Для каждого пробный фрагмент в открытом модуле `project_config` роняет
`just run clippy` с кодом 101 и ошибкой своего lint-а: `match` по своему enum с `_`, `value as u64` и
`#[allow(dead_code)]`. После удаления фрагментов профиль проходит.

- AC1 — выполнен. Все 20 мест перечисляют варианты, в том числе 7 по чужим enum: `Component` 5, `Value` из YAML и
  `DeValue` из TOML. `Command` разделён на команды без проекта, `Runner` для команд `command_runner` и `Configured`
  для команд с загруженной конфигурацией; три частичных разбора команды стали полными, недостижимая ошибка «unknown
  scaffold command» удалена. Тест с `_` в `architecture/source/tests.rs` переписан через `let ... else`.
- AC2 — выполнен. Четыре преобразования, которые могут не удаться, идут через `TryFrom` с ошибкой через `?`:
  смещение в журнале агента, длина в хэше доказательств, размер ответа и среднее в отчёте задач. Семь приведений
  счётчиков структурного линтера исчезли без преобразования: счётчики, пороги и поля `actual` и `limit` диагностики
  стали `usize`, вид YAML и JSON не изменился. `as` в тесте `panic_surface.rs` заменён на `Vec::<usize>::new()`.
- AC3 — выполнен. Четыре `#[allow]` и внутренний `#![allow]` владельца консоли стали `#[expect]` со ссылками
  DECISION. `allow_attributes` не видит внутренние атрибуты, это записано в D153. Текст нарушения `panic-path` и
  навык `justify-allow` теперь велят писать `#[expect]`.
- Границы — соблюдены. `allow_attributes_without_reason` не включён. AC1 принят, поэтому
  `match_wildcard_for_single_variants` не нужен.

voxel-rust `621b999` с `native`: 6 мест `wildcard_enum_match_arm`, 319 `as_conversions` и 3 `allow_attributes`; там
они исправляются отдельной работой, путь для преобразования float в целое записан в D153.

VAC `e0eb185` прошёл хук коммита: build, lint, memory, rustfmt, clippy, rust-test 171, test 423, ruff, mypy, typos и
vulture — PASS. Пин D051 записывает `e0eb185` в `tooling/distribution/stable.txt`, `just bootstrap` установил его.
