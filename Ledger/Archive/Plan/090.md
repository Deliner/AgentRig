# P090 — clippy-delivery: `init` поставляет профиль clippy новым Rust-проектам

## Feature

[B082](../Backlog/082.md): `init --language rust` создаёт команду и проверку `clippy` с набором dev-гейта; тест
AgentRig держит оба набора одинаковыми. Источник — карточка B082 (ревизия в Git `79be435`); выбор и авторизация —
пользователь 2026-11-07. Зависит от P087: поставляемый набор включает линты B081. Порядок и границы VAC — за
исполнителем.

## User capability

Новый Rust-проект с первого коммита проходит тот же clippy, что и AgentRig.

## Acceptance

Карточка **B082 (AC1–AC4, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/clippy-delivery` (база master `21c0b30`), один VAC. Решение [D132](../../Decisions/132.md).

- AC1 — выполнен. `Project/project_setup/clippy.rs` строит argv `cargo clippy --manifest-path <манифест test> --
  -D warnings` и `-D clippy::<линт>` для 23 линтов; `template.rs` добавляет Rust-проекту команду и проверку `clippy`
  с навыком `repair`. Проба в scratchpad: `init --language rust` для пакета с `src/lib.rs`;
  `pub fn value() -> u8 { Some(1).unwrap() }` — `check --only clippy` код 101, `clippy::unwrap_used`,
  `ERROR [clippy]`. Полный `check` при этом сначала падает на `[panic-path]` линта AgentRig: проверки идут по порядку
  и останавливаются на первой ошибке. С `&text[..1]`, который ловит только clippy, полный `check`: PASS lint, memory,
  tests, tools, затем `ERROR [clippy]` с `clippy::string_slice`. После исправления на `1` полный `check` — код 0,
  `PASS [clippy]`.
- AC2 — выполнен. `test_rust_scaffold_delivers_the_dev_gate_clippy_profile` сравнивает множества после `-D` в
  сгенерированной команде и в команде `clippy` из `.agentrig/commands.yaml` и проверяет, что каждый флаг — `-D`.
- AC3 — выполнен. `test_python_scaffold_has_no_clippy`: ни команды, ни проверки `clippy`.
- AC4 — выполнен. D132 заменяет часть D060 о профиле только для dev-гейта и ту же оговорку D068, D107, D127 и D129.
- Границы — соблюдены: toolchain не закреплён, `--locked` и `--all-targets` не ставятся, конфигурации существующих
  проектов не меняются. Мастер `init --interactive` теперь предлагает проверки, созданные шаблоном: для Rust в списке
  есть `clippy`, иначе интерактивный выбор по умолчанию расходился бы с `init --language rust`.
