# P196 — после слияния ветки агент сжимает контекст

## Feature

[B203](../Backlog/203.md): после слияния ветки агент сжимает контекст. Выбор — пользователь 2026-11-22, после показа
карточки целиком и ответов на её вопросы: «сохрани и сделай, требовать, подсказку мода убери». Карточка в Git в первом
VAC ветки `feature/compact-after-merge` от master `273cb8b`. Границы VAC — за исполнителем.

## User capability

Каждая следующая задача начинается с короткого контекста; с модом рига автономный прогон сжимается после каждой
карточки и продолжает работу сам.

## Acceptance

Карточка **B203 (AC1–AC10)** — критерии и формулировки там; идентификаторы те же.

## Delivery

- Ветка `feature/compact-after-merge` от master `273cb8b`, решения [D230](../../Decisions/230.md) и
  [D231](../../Decisions/231.md).
- VAC 1 `7352c62`: карточка B203 сохранена и выбрана.
- VAC 2 `18c7f5d`, требование: успешный `feature-merge` пишет отметку в каталоге рантайма и заканчивает вывод
  указанием из `Project/change_delivery/git/compaction.txt`. Хук агента (`agent_hooks/mod.rs`, `tools.rs`) при отметке
  отказывает любому инструменту с этим указанием, кроме `mcp__self-compact__compact`. Отметку снимает начало сессии с
  источником `compact`, `clear` или `startup`; `resume` и `fork` её оставляют. Нечитаемая отметка даёт отказ с
  причиной. Отметка закрыта для агентов.
- VAC 3 `6101968`, мод: исходник в `Project/shared/mods`, маркетплейс `agentrig` с плагином `self-compact` — модуль
  пользователя без подсказки после `git commit` и `git merge`. `init` пишет его в `.agentrig/mods`, включает
  `self-compact@agentrig` в `.claude/settings.json`, защищает `mods/`, исключает его из правила языков программ и
  помечает исполняемыми только файлы `bin/` и `hooks/` служебного каталога. Риг держит те же файлы и настройки. Гейт:
  633 теста.
- VAC 4 `f72dee2`: сохранена согласованная карточка B204; к P196 не относится.
- Codex: средства, которым агент Codex сам сжимает свой контекст, нет, поэтому мод для Codex не ставится; агент Codex
  после слияния заканчивает ход и просит пользователя набрать `/compact`. Начало сессии регистрируется для обоих
  агентов одинаково, с источниками `startup|resume|clear|compact`.
- Пин: `just propose-pin HEAD` подготовил `f72dee2`; согласие не действовало, пин поставил пользователь командой
  `! just approve`.
- Живая проверка — в проекте `.tmp/agentrig-live`, установленном `just candidate init`. Codex 0.170.0 запускается
  командой каталога `codex` (`codex exec`), её добавление одобрил пользователь. Codex запускает хуки проекта, только
  когда доверяет проекту (`--trust`) и самим хукам: доверие хукам хранится по хешу каждого хука в
  `~/.codex/config.toml`. Без него Codex молча не запускал хуки, и отказа не было. Проверка шла с флагом
  `--dangerously-bypass-hook-trust` (только на сам запуск) с разрешения пользователя.
- Пределы: Claude Code один раз на машине просит доверять папке и поставить маркетплейс и плагин; до этого агент после
  слияния просит набрать `/compact`. Codex в каждом новом проекте исполняет хуки рига только после того, как
  пользователь один раз одобрит их (`/hooks`); `codex exec` об этом не спрашивает.
