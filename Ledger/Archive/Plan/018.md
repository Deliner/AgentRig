# P018 — Исправление конфигурации без блокировки агента

## Feature

[B001](../../Backlog/001.md), контракт `30bf0e08faa6053d77b7a4370168ec008c9e3bfb`.
Выбран первым 2026-09-11.

## User capability

Агент самостоятельно устраняет ошибку настройки и возвращается к продуктовой задаче без потери работы и ручного вмешательства пользователя.

## Acceptance

Исходная карточка **B001 / K1–K8**, включая её границы и приёмку.
Содержание требований и идентификаторы сохраняются без второй спецификации.

## Delivery

Ветка feature/target-state: восстановление `579474d`
([D045](../../Decisions/045.md)), чтение и патчи Codex `52471a0`
([D046](../../Decisions/046.md)), закрепление и bootstrap `1628d67`.
Конфигурация состоит из модулей .agentrig/ ([D038](../../Decisions/038.md)).
До изменения в потребителе кандидата отклонялось всё, включая SessionStart,
правку конфигурации и `just config-check`. Смысловую оценку вместо удалённого
runner ревью ([D033](../../Decisions/033.md)) выполнил исполнитель.

- K1 — выполнено: `diagnostics_distinguish_missing_corrupt_unknown_and_invalid_configuration`
  (нет файла, YAML, неизвестное поле, проверка, lint) с файлом модуля и без
  «required»; проба в потребителе на шести видах поломки.
- K2 — выполнено: `invalid_configuration_leaves_only_its_repair_and_check_available`
  и `invalid_configuration_can_be_read_only_through_cat_of_its_files`; в K7 агенты
  прочитали skill и файл, исправили его и запустили проверку в той же сессии.
- K3 — выполнено: при ошибке хуки отвечают по самой ошибке, не загружая
  команды; в K7 была сломана команда `read`, а `just config-check` не зависит от
  каталога команд.
- K4 — выполнено: неотслеживаемый Project/notes.txt сохранился в обеих
  сессиях, откат из Git не использовался.
- K5 — выполнено: прочие правки и команды, `cat` других файлов и с
  перенаправлением отклоняются (тесты); guard-commit не дал закоммитить в
  потребителе со сломанной конфигурацией. feature-merge загружает ту же
  конфигурацию; отдельно при поломке не запускался.
- K6 — выполнено: каждое событие заново загружает конфигурацию; тест
  восстанавливает файл и получает обычное поведение; в Codex промежуточные
  ошибочные версии оставались в режиме исправления до успешной проверки.
- K7 — выполнено: Claude Code (haiku, кандидат D045) и Codex (gpt-5.6-luna,
  кандидат D046, `--dangerously-bypass-hook-trust`) прошли «ошибка → чтение →
  исправление → `just config-check` → Project/hello.txt и `just list`»; Codex
  вернул commands.yaml в точности к исходному. Первый прогон Codex выявил
  непрочитанный `tool_input.command` и отсутствие чтения, исправленные в D046.
- K8 — выполнено: диагностика называет установленный repair skill; его
  раздел Runtime binding описывает путь исправления, и оба агента по нему
  завершили сценарий.
