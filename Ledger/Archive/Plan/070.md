# P070 — delivery-repairs: поставка D1 без расхождений с контрактом B065 и D103

## Feature

[B067](../Backlog/067.md): `delivery-repairs` — ремонт поставки D1 (P069/B065) по закрытому списку критики Codex
2026-11-06: обнаружение Cargo (`**` на любую глубину, `..` внутри корня, `workspace.exclude`), JSON-находка
`configuration` в проектном режиме `lint --json`, `#[cfg_attr(cond, unsafe(..))]` без находки unsafe-justification,
точный навык split-boolean-parameter, обслуживание (карта влияния `Project/shared/fs/**`, State, перевод строки в
`Backlog.md`). Источник — карточка B067 (ревизия в Git, коммит VAC 1 ветки `feature/delivery-repairs`); выбор и
авторизация — /goal пользователя 2026-11-05 (бриф D3). Порядок и границы VAC — за исполнителем.

## User capability

Потребитель получает поставку `init`/lint, совпадающую с контрактом B065 и D103: workspace с вложенными членами и
относительными путями библиотек получает верные корни, потребитель JSON видит ошибки конфигурации в JSON, условный
атрибут `unsafe` не даёт ложной находки, навык split-boolean-parameter не ведёт к ошибочному ремонту, гейт выбирает
тесты `shared::fs` при их изменении.
