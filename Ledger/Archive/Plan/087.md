# P087 — clippy-shape: `map_err_ignore`, `partial_pub_fields`, `struct_excessive_bools` в dev-гейте

## Feature

[B081](../Backlog/081.md): команда `clippy` в `.agentrig/commands.yaml` запрещает `map_err_ignore`,
`partial_pub_fields` и `struct_excessive_bools`; места AgentRig и норма `type-driven-discipline` приведены в
соответствие. Источник — карточка B081 (ревизия в Git `79be435`); выбор и авторизация — пользователь 2026-11-07.
Порядок и границы VAC — за исполнителем.

## User capability

Причина ошибки не теряется; запись и абстракция различимы по объявлению типа.

## Acceptance

Карточка **B081 (AC1–AC4, проверка каждого линта, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/clippy-shape` (база master `dbfad6c`), по одному VAC на линт и финальный пин D051. Каждый линт доказан
пробой: фрагмент, дописанный в `Project/lib.rs`, проваливает `just run clippy` с кодом 101 и ошибкой этого линта,
после удаления — код 0. Пересчёт на базе совпал с карточкой: `map_err_ignore` 3, `partial_pub_fields` 3,
`struct_excessive_bools` 0.

- AC1, VAC `d9c828e` — выполнен. Два `join` в `command_runner/jobs` сообщают «… panicked: <текст паники>» через
  `panic_text` в `streams.rs`. `Display` для `Kind` в `structural_lint/rules/kind.rs` остаётся с `map_err` в
  `fmt::Error` под `#[allow(clippy::map_err_ignore)]` и `DECISION: D129`. Проба
  `text.parse::<u8>().map_err(|_| String::from("bad"))` — «wildcard pattern discards the original error».
- AC2, VAC `56b7332` — выполнен. `Session` (`state_mut`), `Declaration` (`files`, `directories`, `kind`) и `Selector`
  (`overrides`) держат все поля закрытыми. Пункт 5 нормы `type-driven-discipline`: структура — либо запись со всеми
  полями `pub`, либо абстракция со всеми закрытыми; Enforcement называет линт. Проба
  `pub struct Probe { pub open: u8, closed: u8 }` — «mixed usage of pub and non-pub fields».
- AC3, VAC 3 — выполнен. Чинить нечего. Проба со структурой из четырёх `bool` — «more than 3 bools in a struct».
- AC4 — выполнен. Решение [D129](../../Decisions/129.md) расширяет D060 и D127, фиксирует набор и отказ от
  `mutex_atomic` и `mutex_integer` с причиной.
- Границы — соблюдены: изменён только dev-гейт этого репозитория; поставку решает B082.
- Гейты коммитов: `d9c828e` — все проверки PASS, rust-test 155 и test 395 passed; `56b7332` — все проверки PASS,
  rust-test 155 и test 342 passed.
