# P117 — option-option-owner: вложенное необязательное значение ловит только Clippy

## Feature

[B111](../Backlog/111.md): вложенное необязательное значение ловит только Clippy. Источник — карточка B111 в коммите
её сохранения на ветке `feature/rust-tests`; выбор и авторизация — пользователь 2026-11-11, сразу после P115.
Порядок и границы VAC — за исполнителем.

## User capability

Агент получает одну ошибку на одну проблему.

## Acceptance

Карточка **B111 (AC1–AC2)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/option-option-owner` от master `44c9004`. VAC 1 `8cd02d3`, решение [D162](../../Decisions/162.md):
правило `ambiguous-option` ловит только `Option<bool>`, его описание и навык `name-the-states` говорят только об этой
форме. Вложенный `Option` остаётся за линтом Clippy `option_option`, который включён в общий профиль по D137.

### AC1

Коммит в одноразовой копии рига через её хук коммита и установленный рантайм `81bbd8d`. Фрагмент один и тот же: в
`Project/shared/fs/mod.rs` добавлена открытая функция `nested_probe() -> Option<Option<u32>>`. После каждого прогона
копия возвращена к исходной ревизии и сверена с копией файла.

| Ревизия | Что остановило коммит | Ошибок |
| --- | --- | --- |
| До, master `44c9004` | `lint`: `ambiguous-option`; Clippy не запускался | 1; Clippy с тем же профилем ловит этот фрагмент, как показала строка «после», так что исправление первой ошибки вело ко второй |
| После, `8cd02d3` | `clippy`: «use of `Option<Option<T>>`»; `lint` прошёл | 1 |

AC1 выполнен: на записи `Option<Option<T>>` коммит останавливает только Clippy, ошибка одна.

### AC2

Тест `structural_lint::languages::tests::signature::type_shape::rust_flags_an_option_over_a_bool_wherever_it_stands_and_leaves_a_nested_option_to_clippy`.
В исходнике теста есть поле `Option<bool>`, поле `Option<Option<u32>>`, параметр `std::option::Option<bool>`,
возвращаемый `Option<Vec<bool>>` и `Option<bool>` с решением строкой выше. Тест требует ровно две находки, обе на
`Option<bool>`. AC2 выполнен: тест прошёл на кандидате и в гейте коммита VAC 1.

### Найдено при поставке

Проба Clippy 1.98.1 с `-D clippy::option_option` и настройками `clippy.toml` рига на отдельном маленьком крейте:

| Где стоит `Option<Option<u32>>` | Clippy ловит |
| --- | --- |
| Параметр открытой функции | да |
| Возвращаемый тип открытой функции | да |
| Открытое поле открытой структуры | да |
| Параметр закрытой функции | да |
| Открытый `type`-псевдоним | нет |
| Закрытый `type`-псевдоним и параметр этого типа | нет |
| Аннотация `let` | нет |

Правило `ambiguous-option` раньше ловило и псевдонимы, и `let`. Теперь эти три места не ловит ни одна проверка рига,
это записано в последствиях D162. Пользователь выбрал Clippy единственным владельцем формы, поэтому правило не
оставлено для этих мест: иначе у формы снова было бы два владельца.
