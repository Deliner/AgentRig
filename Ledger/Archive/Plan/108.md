# P108 — method-edges: рёбра зависимостей через вызовы методов

## Feature

[B096](../Backlog/096.md): рёбра зависимостей через вызовы методов. Источник — карточка B096 на ревизии `4518103`; выбор
и авторизация — пользователь 2026-11-10. Порядок и границы VAC — за исполнителем.

## User capability

Бюджеты и циклы считаются по реальным зависимостям.

## Acceptance

Карточка **B096 (AC1–AC3, границы)** — критерии и формулировки там; идентификаторы те же.

## Delivery

Ветка `feature/method-edges` (база master после слияния P107 `fc7c4b4`), один VAC: замер, решение и ротация без
изменения рига ([D149](../../Decisions/149.md)).

- AC1 — выполнен. Замер сделан внешним оракулом в scratchpad: вызовы `.name(` вне тестов, имя метода с `self`
  определено ровно в одном каталоге проекта и не встречается как `fn` в исходниках std и зафиксированных
  зависимостей; каталоги вызова и владельца сверены с рёбрами `lint-edges`. Потеряно рёбер: AgentRig 2 из 235,
  voxel-rust `71440d0` 1 из 105; это нижняя оценка, фильтр внешних имён снял 53 из 170 и 128 из 235 имён методов
  проекта. Верхняя оценка по одному имени без фильтра — 64 и 28 пар, почти все ложные. Все 3 ребра проверены вручную
  и настоящие: `project_setup` и `project_setup/initialization` → `project_config/settings` через
  `config.paths.service_path(...)`, при этом риг уже видит ребро к фасаду `project_config`, который реэкспортирует
  `Config`; `native/android` → `render/near` через `game.near.resident()`. Через имена, определённые в нескольких
  каталогах, новых пар нет.
- AC2 — не применяется: ни один подтверждённый случай нельзя определить без вывода типов. Все три получателя — цепочки
  полей, тип которых объявлен в другом файле. Единственный сигнал без типов, уникальное имя метода, без исходников
  зависимостей ложен: даже со списком имён std voxel-rust получает два ложных ребра от `Rect::center` из egui.
- AC3 — не применяется: потерянные рёбра подтвердились.
- Решение по остальным случаям, переданное исполнителю: D059 остаётся в силе, риг не меняется. Три ребра не меняют ни
  одной находки: зависимых у `settings` стало бы 3 вместо 1, у `render/near` 4 вместо 3, оба под бюджетом 6, циклов
  не возникает. Решение записано в D149 и может быть пересмотрено пользователем.
- Границы — соблюдены: замер на AgentRig и клоне voxel-rust без правок обоих проектов; под voxel-rust риг не
  подгонялся.
