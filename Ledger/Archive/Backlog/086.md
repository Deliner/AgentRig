# B086 — Рантайм проекта на нескольких платформах

## Context

- В voxel-rust рантайм лежит в рабочем дереве под одну платформу: на main под Linux, на ветке под macOS.
- Хуки берут его из дерева, поэтому `feature-merge` на main без обхода хуков не проходит ни на одной машине.

## Proposal

- Хуки и команды запускают рантайм текущей платформы.
- Платформу можно добавить одной командой.
- Если рантайма для платформы нет, хук отказывает и называет платформу и команду добавления.
- **AC1.** На одной ревизии коммит через хуки проходит на Linux x86_64 и на macOS arm64.
- **AC2.** `feature-merge` проходит на обеих платформах.
- **AC3.** На платформе без рантайма хук называет её и команду.

**Решение за пользователем.** Хранить двоичные файлы в Git или получать их при bootstrap. От этого зависят размер
репозитория и работа без сети.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Проект с AgentRig коммитит и сливает ветки на Linux и macOS с одной ревизии, без обхода хуков.
