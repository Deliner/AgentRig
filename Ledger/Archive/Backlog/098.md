# B098 — Очистка после слияния не помечает свой запуск

## Context

- `feature-merge` под `just scratch` дважды оставил запуск с пометкой «inspect manually»: run-peuO0r и run-wBKSww.
- В обоих выводах владелец очистки совпадает с оставленным запуском. Это обёртка, внутри которой и шло слияние.
- Обе завершились с кодом 0.

## Proposal

- Очистка узнаёт запуск, внутри которого работает, и не просит проверить его вручную.
- Другие живые запуски ветки перечисляются как сейчас.
- **AC1.** `feature-merge` внутри управляемого запуска не перечисляет этот запуск.
- **AC2.** Посторонний живой запуск ветки перечисляется.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Пометка «inspect manually» появляется только там, где действительно нужно вмешаться.
