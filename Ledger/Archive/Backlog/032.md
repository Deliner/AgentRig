# B032 — Линты тестов

## Context

Кластер 7 набора улучшений качества (мозгоштурм 2026-10-29). Дополняет норму тестовой
дисциплины ([D055](../../Decisions/055.md)/[D057](../../Decisions/057.md)). Согласовано
пользователем 2026-10-29.

## Proposal

- **7.1 Нет тихо выключенных тестов.** Rust `#[ignore]`, Python `@pytest.mark.skip`/
  `skipif` без ссылки `DECISION:` — находка. *[правило]*
- **7.2 Запрет недетерминизма в тестах.** Реальные `SystemTime::now`/`Instant::now`/`rand`/
  сеть в тестовых файлах. *[правило]*
- **7.3 Конвенции имён/размещения тестов.** Размещение уже норма (TC1); имена — проверяемо.
  *[правило/норма]*

**Границы.** Только `Project`; возможность уезжает в `init`
([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md)); что не проверяется чисто —
норма (norm-or-choice). Догфуд: наш код к зелёному.

## Expected benefit

Тесты детерминированы и явно обоснованы, а не тихо выключены; новый проект получает это из
коробки.
