# B125 — Команда понятности структуры и навык её правки в проектах через init

## Context

В P129 связка `agentrig lint-structure` и навыка v5 подняла слепую оценку Sonnet для Project с 51,6 до 66,67 %.
Пользователь 2026-11-13 выбрал поставить её в проекты как подсказку, без блокировки.

## Proposal

- **AC1.** В Rust-проекте после `init` команда `just lint-structure ПУТЬ` печатает то же, что `agentrig
  lint-structure ПУТЬ`. Защита оболочки пропускает её как команду чтения, так же как `just lint-tree`. В самом
  AgentRig этот рецепт тоже есть.
- **AC2.** `init` ставит навык `clarify-structure` рядом с остальными каноническими навыками. Единственный исходник
  навыка лежит в `Project/shared/skills`.
  - Основа: навык v5 из P129 с теми же двумя циклами, правилами сохранения и остановки.
  - Отличается только привязкой к проекту. Агент правит сам проект на ветке. После каждого круга он запускает
    настроенную проверку проекта вместо `cargo check`. Карта правок не нужна, историю хранит Git.
- **AC3.** Числа команды ничего не блокируют. Lint, шлюз коммита и хуки не падают на них и не останавливают агента.
  Навык вызывают по просьбе пользователя или по его описанию, хук его не навязывает.
- **AC4.** Пробный проект из тестов `init` получает рецепт и навык, и рецепт печатает числа. README рига описывает
  команду рядом с `lint-tree`.

**Границы.** Только Rust, потому что команда считает только код Rust. Правила команды и циклы навыка не меняются.
Блокирующие правила вынесены в B126.

## Expected benefit

Агент в любом Rust-проекте с ригом может по числам привести структуру к понятной.
