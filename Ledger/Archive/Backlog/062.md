# B062 — одноразовые ремонты нашего кода по итогам дуги (N1/N2 и прочие)

## Context

Исследовательская дуга (`coverage-map.md` порядок «VAC одноразовых ремонтов», шаг 5 итог R6,
раздел N2; `meta/register.md` «список ремонтов»). Находки в нашем коде, не закрываемые
правилами: fail-open вердикты, роспись строк вместо enum (R6 закрыт нормой N1 + ремонты),
безымянные пары в сигнатурах, два атомарных `Ordering` без записи, usage-строка без
`lint-explain`. Авторизовано 2026-11-04 (/goal).

## Proposal

Наблюдаемое поведение после ремонта (пункты независимы, каждый — отдельный VAC):

- **AC1 — fail-closed `merged_reference`.** `change_delivery/git/mod.rs:146`: нерезолвимый tip
  ветки больше не даёт `Ok(false)`; ошибка Git пробрасывается, удаление не разрешается.
  Поведенческий тест в `change_delivery/git/tests` фиксирует «ошибка проверки не разрешает
  удаление» (кандидат инварианта I021, norm-or-choice).
- **AC2 — guard-reference.** `agent_hooks/guard.rs:95`: ошибка на пути проверки даёт отказ с
  причиной, а не разрешение; `guard_reference_with(root, phase, base, prefix)` принимает
  `&Settings` вместо россыпи полей; штатное поведение guard-reference не меняется (существующие
  тесты), новый негативный тест закрепляет отказ.
- **AC3 — enum вместо строк-режимов (N1).** `Diagnostic.level: String` → `Level` (сравнения
  с `"error"`/`"warning"` исчезают из `structural_lint/mod.rs`); состояния заданий
  `observe_once`/`grouped`/`observe` → `enum JobState`; каскад команд `command_line` + `jobs::cli`
  → `enum Command`; `detail_sections(directory: &str)` → enum каталога памяти. Внешний вывод и
  форматы не меняются.
- **AC4 — именованные записи.** Семь сигнатурных пар получают имена полей: `(String, String)` в
  `project_memory/format.rs:47`, `project_config/settings/mod.rs:266`,
  `command_runner/registry/check.rs:7`, `architecture/policy.rs:198`,
  `project_setup/template.rs:387`; `(File, File)` в `jobs/streams.rs:36`, `jobs/mod.rs:166`.
- **AC5 — `Ordering`.** `jobs/streams.rs:69,146` несут строку `// DECISION: …`, объясняющую
  выбор Release/Acquire.
- **AC6 — usage.** Ошибка неизвестной команды (`command_line/main.rs:37–39`) — одна строка с
  указанием на `--help`; таблица команд живёт в `print_help`, где уже есть `lint-explain`.

**Границы и неизвестное.** Ремонт `super::super` — под B058; каст PID не меняется (cast-линты
не выбраны; B051 AC2 остаётся в Backlog). Поведение продукта не меняется, кроме AC1/AC2
(fail-closed).

## Expected benefit

Собственный код соответствует нормам N1/N2, которые проект предлагает потребителям; fail-open
вердикты закрыты тестами.
