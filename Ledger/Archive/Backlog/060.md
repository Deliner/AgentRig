# B060 — C-профиль dev-гейта: пять линтов clippy и ограждение `unsafe`

## Context

Исследовательская дуга: решение пользователя 2026-11-02 п. 3 (`clippy::exit`,
`clippy::should_panic_without_expect` — по одному VAC на линт; `wildcard_enum_match_arm`,
`map_err_ignore`, `cast_*` — **не выбраны**), шаг 6 (далее `rest_pat_in_fully_bound_structs`,
`self_named_module_files`; `debugomit` → `clippy::missing_fields_in_debug`), шаг 2
«unsafe-confinement» (`#![deny(unsafe_code)]` на крейте + `#[allow(unsafe_code)]` со строкой
DECISION на единственном поддереве; наши 13 `unsafe`-сайтов — все в `command_runner/jobs`).
`allow_attributes_without_reason` не берётся (дублирует D080); `derived_hash_with_manual_eq` и
`derive_ord_xor_partial_ord` — deny по умолчанию (проверить, не добавлять). Объём на нашем коде:
0 ремонта по всем пяти линтам (`exit` в точке входа `main` линтом не считается; `should_panic`,
ручных `Debug`, полностью связанных `..`-образцов и пар `foo.rs`+`foo/` нет). Авторизовано
2026-11-04 (/goal).

## Proposal

- **AC1–AC5 — по одному VAC на линт.** В профиле clippy `.agentrig/commands.yaml` появляются
  `-D clippy::exit`, `-D clippy::should_panic_without_expect`, `-D clippy::missing_fields_in_debug`,
  `-D clippy::rest_pat_in_fully_bound_structs`, `-D clippy::self_named_module_files`; гейт
  зелёный. Признак работы каждого: пробный фрагмент с нарушением проваливает проверку clippy
  кандидата, удаление фрагмента возвращает зелёный.
- **AC6 — ограждение `unsafe`.** `Project/lib.rs` несёт `#![deny(unsafe_code)]`; единственное
  `#[allow(unsafe_code)]` стоит на объявлении поддерева `command_runner::jobs` со строкой
  `// DECISION: …` над ним (правило `allow-justification` удовлетворено); `unsafe` вне поддерева
  не компилируется.
- **AC7 — запись.** Decision, расширяющий D060, фиксирует набор, невыбранные линты и проверку
  линтов deny-по-умолчанию.

**Границы и неизвестное.** Только dev-гейт этого репозитория (D060), потребителям не
поставляется. Escape для законного сайта — `#[allow(clippy::…)]` со строкой DECISION (D080).

## Expected benefit

Dev-гейт ловит скрытый выход из процесса, паникующие тесты без ожидания, забытые поля в ручном
`Debug`, маскирующие `..`-образцы и смешение стилей модулей; `unsafe` не может появиться вне
объявленного поддерева.
