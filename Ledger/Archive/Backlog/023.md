# B023 — Статическая проверка публичной поверхности тестов

## Context

[D054](../../Decisions/054.md)/[D055](../../Decisions/055.md) оставили TC2 («элемент
сделан публичным лишь ради теста») и TC4 («чёрные ходы в приватные внутренности») из
[B022](022.md) нормами навыка `testing-discipline`: синтаксический движок линтера видит
объявления и ссылки, но не извлекает видимость символов и не строит обратный индекс «кто
ссылается», поэтому отличить `pub`, нужный только тестам, от настоящей публичной
поверхности нельзя. Источник: набор идей улучшений, согласовано пользователем 2026-10-28.

## Proposal

Дать движку извлечение видимости объявленных символов и обратный индекс ссылок, и на
их основе — правило линтера, выявляющее TC2/TC4 статически. Правило уезжает в поставку
`init` как universal-возможность ([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md))
и действует в этом репозитории.

**K1 — видимость символов.** Для поддерживаемых языков движок определяет видимость
объявленного символа: Rust — `pub` / `pub(crate)` / приватный (включая `pub(super)` и
пути); Python — соглашение об именах (`_name` приватно) и `__all__`.

**K2 — обратный индекс ссылок.** Для символа движок знает множество файлов, которые на
него ссылаются, с разделением тестовых (`tests`/`testing`) и продуктовых.

**K3 — правило «публично только ради теста».** Символ с видимостью шире
приватной/крейт-локальной, на который ссылаются только тестовые файлы, — нарушение с
ремонтным навыком: сузить видимость либо дойти до него публичным путём. Возможность
объявлена в `lint-rules`, поведенчески проверена, ремонт описан.

**Границы и неизвестное.** Осуществимость и отсутствие ложных срабатываний на реальном
репозитории подтверждаются на этапе реализации: если чисто проверить нельзя, пункт
остаётся нормой с записью причины (norm-or-choice), без «притворного» инварианта — как
в [P031](../Plan/031.md). Проверяются только символы внутри `Project`; внешние
модули классифицируются вне графа, как сейчас. Для Python язык не форсирует приватность,
поэтому там правило опирается на соглашение об именах и может остаться нормой, если даёт
шум.

## Expected benefit

«`pub` ради теста» и чёрный ход в приватные внутренности выявляются из коробки, а не
держатся в голове ревьюера; давление тестов перестаёт незаметно расширять публичную
поверхность продукта.
