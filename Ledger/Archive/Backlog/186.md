# B186 — Код, который никто не вызывает, удалён

## Context

- 2026-11-21 пользователь, уходя: «Как закончишь, то продолжай автономно улучшать проект без изменения поведения с
  точки зрения бизнес правил. Можешь оптимизировать и ускорять, упрощать и рефачить. Все в рамках текущих правил. Сам
  заведи карточку и аппрувни ее, мне показывать не надо». Карточки B181–B185 этого поручения выполнены.
- Крейт рига открыт как библиотека, поэтому компилятор молчит о неиспользуемых открытых функциях. Пробная сборка на
  master `b03c5fd`, где модули закрыты внутри крейта, а вызовы бинарников оставлены, назвала функции без вызовов в
  продукте:

  | Функция | Кто вызывает |
  | --- | --- |
  | `FileKind::mode` | никто |
  | `Repository::diff` | одна проверка одного теста |
  | `atomic_files::read_regular` | только её собственные тесты |

## Proposal

- **AC1. Поведение то же.** Команды рига, их вывод, тексты ошибок, коды выхода, форматы файлов и конфигурации не
  меняются.

  Проверка: все тесты проходят. Удаляются только тесты удаляемой функции и проверка, которая вызывает удаляемый метод;
  проверка общего владельца из такого теста остаётся в тесте этого владельца. Число тестов уменьшается ровно на
  удалённые тесты.
- **AC2. Неиспользуемого кода нет.** Функции без вызовов в продукте удалены вместе с тем, что служило только им.

  Проверка: Delivery называет каждое удалённое место; та же пробная сборка на голове ветки не находит функций без
  вызовов. Открытые типы, которые вызывающий получает из сигнатуры, но не называет, остаются, и Delivery их перечисляет.
- **AC3. Удаление не добавляет находок lint.**

  Проверка: `just lint` на голове ветки без находок.

**Границы.** Новые правила, виды проверок, зависимости и решения о поведении не вводятся. Видимость модулей крейта не
меняется. Пороги, селекторы, исключения и бюджеты lint не ослабляются. Защищённые файлы не меняются. Пин ветки ставит
пользователь командой `! just approve`.

## Expected benefit

Читатель не тратит время на код, который ничего не делает, а правки рядом не тянут за собой его поддержку.
