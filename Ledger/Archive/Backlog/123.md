# B123 — Слепой тест понятности структуры Project

## Context

Пользователь 2026-11-12 поставил задачу: каталоги и файлы Project должны объяснять проект без чтения кода. Проверка —
слепой тест. Отдельный агент видит только дерево Project, без описаний, и рассказывает, что это за проект, какой у
него основной функционал и что он выполняет. Исполнитель меняет дерево так, как мог бы выглядеть отрефакторенный
проект, и снова отдаёт агенту, пока описание не станет лучшим.

## Proposal

- **AC1.** Команда `lint-tree PATH` печатает каталоги и файлы под PATH деревом из символов псевдографики `├──`, `└──`
  и `│`: только имена, без описаний, в постоянном порядке. Для Project это то дерево, которое получает агент.
- **AC2.** Слепой прогон: Sonnet 5.5 на уровне рассуждений high получает только дерево и один и тот же вопрос. Ему
  недоступны репозиторий, инструкции и название проекта.
- **AC3.** Вариант структуры — возможный рефакторинг Project: переименования, переносы, разбиения и слияния
  каталогов и файлов, записанные как изменённое дерево. Файлы кода не меняются.
- **AC4.** Исполнитель прогоняет варианты около 12 часов или до остановки пользователем и подбирает структуру, по
  которой Sonnet лучше всего описывает проект.
- **AC5.** Итог: лучшая структура, оценки исходной и лучших вариантов и изменения, которые помогли. Правка самого
  Project по итогу — отдельная карточка по согласию пользователя.

**Неизвестное.** Насколько оценка одного описания устойчива между прогонами. Протокол оценки исполнитель записывает
в Delivery до первого прогона.

## Expected benefit

Агент и человек понимают назначение и части проекта по одной структуре каталогов, не читая кода.
