# B093 — Гейт и переключение веток без промежуточного состояния

## Context

- `check --revision` упал в `tools` с «not a git repository»: выгрузка ревизии идёт без .git.
- Раньше отказ хука в обновлении HEAD оставил файлы другой ветки при прежнем HEAD.
- Второй случай нужно воспроизвести.

## Proposal

- `check --revision` выполняет `tools` или пропускает её и называет причину.
- Если переключение ветки отказано, рабочее дерево и HEAD остаются как до команды.
- **AC1.** `check --revision HEAD` проходит без ошибки git на проекте с проверкой `tools`.
- **AC2.** После отказанного переключения `git status` не меняется.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Проверка ревизии не падает на ложной ошибке git, а отказанное переключение ветки не оставляет смешанное рабочее
дерево.
