# B028 — Дисциплина ошибок и ресурсов

## Context

Кластер 3 набора улучшений качества (мозгоштурм 2026-10-29). Согласовано пользователем
2026-10-29.

## Proposal

- **3.1 Запрет тихого глотания ошибок.** Python `except: pass`, Rust `let _ = <Result>` —
  находка (или явное обоснование `DECISION:`). *[правило]*
- **3.2 Результат нельзя игнорировать** — `#[must_use]`/`Result` (clippy `unused_must_use`,
  `let_underscore_must_use`). *[конфиг]*
- **3.3 Ресурсы через контекст-менеджер/RAII** — файлы/сокеты (ruff `SIM115` и
  родственные). *[конфиг]*

**Границы.** Правила — внутри `Project`; возможность уезжает в `init`
([D053](../../Decisions/053.md)/[I020](../../Invariants/020.md)). Догфуд: наш код к зелёному.

## Expected benefit

Ошибки обрабатываются, а не глушатся; ресурсы закрываются — новый проект получает это из
коробки.
