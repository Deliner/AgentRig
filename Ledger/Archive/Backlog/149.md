# B149 — Подсказки хука для `just write` только по делу

## Context

- Проба 2026-11-19: Claude Code в проекте после `init` выполнил `just run write -- mkdir -p Project/data`. Хук
  пропустил команду и выдал подсказки про пять навыков памяти: edit-plan, edit-backlog, edit-decisions,
  edit-invariants и edit-state, потому что не видит, что меняет команда оболочки. Команда их не касалась, и агент
  правильно их пропустил. Такой шум приучает агента пропускать подсказки хука.
- Программы `just write` получают пути явными аргументами, поэтому хук может их увидеть.

## Proposal

- **AC1.** Для `just write` с программами mkdir, cp, mv, rm, touch и chmod хук называет только навыки тех маршрутов,
  под которые попадают пути из аргументов. Для `git` и `just scratch` всё остаётся как сейчас.

  Проверка: тест хука.

## Expected benefit

Подсказка хука появляется, только когда команда касается файлов её навыка, и агент не привыкает их пропускать.
