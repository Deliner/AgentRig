# B082 — `init` поставляет новым Rust-проектам профиль clippy dev-гейта

## Context

Пользователь 2026-11-07: «заведи отдельную карточку на клипе». Линтер AgentRig предназначен для новых проектов:
быстрое AI-first, agent-native, кроссплатформенное написание Rust-кода, большие сложные проекты со сроком поддержки 20
лет, и всё проверяется догфудингом. Сейчас набор `-D clippy::…` из D060, D068, D107, D109, D127 и B081 записан только в
`.agentrig/commands.yaml` этого репозитория; D060 оставил его dev-гейту. `init --language rust` создаёт команды
`read`, `write`, `test` и проверки `lint`, `memory`, `tests`, `tools`, а clippy в новом проекте не запускается вовсе.

## Proposal

- **AC1.** `init --language rust` записывает команду `clippy`: `cargo clippy --manifest-path <манифест, который init
  уже находит для команды test> -- -D warnings` и `-D clippy::<линт>` для каждого линта профиля. Проверка `clippy` с
  навыком `repair` запускает её в `check` и в гейте коммита. Признак: в новом проекте функция с `Some(1).unwrap()`
  проваливает `check` ошибкой `[clippy]`, после исправления `check` проходит.
- **AC2.** Поставляемый набор совпадает с набором dev-гейта AgentRig, включая линты B081. Тест AgentRig падает, если
  линт есть только в одном из двух списков.
- **AC3.** `init --language python` не создаёт ни команды, ни проверки clippy.
- **AC4.** Новое решение фиксирует поставку профиля и заменяет ту часть D060, по которой профиль только для
  dev-гейта.

**Границы и неизвестное.** Версия toolchain не закрепляется, команда работает на toolchain проекта. Имена линтов
заданы по clippy 1.98.1, версии dev-гейта; более старый clippy может не знать имя и провалить проверку ошибкой о
неизвестном линте. `--locked` и `--all-targets` не ставятся, как у `test` и у dev-гейта, поэтому тесты clippy не
проверяет. В набор входят `print_stdout`, `print_stderr` и `exit`: новый проект печатает и завершается через одного
владельца с обоснованным `#[allow]`, как `shared/console` в AgentRig. Уже созданные конфигурации не меняются.

## Expected benefit

Новый Rust-проект с первого коммита проходит тот же clippy, что и AgentRig: паники, отладочный вывод и классы дефектов,
которым нужны типы, ловит гейт без ручной настройки.
