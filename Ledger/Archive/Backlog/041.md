# B041 — Анти-дублирование: один владелец поведения вместо копий (переносимая норма)

## Context

Набор II улучшений качества (переносимо на любое приложение, agent-native), согласован
пользователем 2026-10-31 на автономное исполнение по моей рекомендации. Следующий по плану кластер
после C10 — C7 «анти-дублирование». Под давлением агент (и человек) копипастит логику вместо выноса
общего владельца — расходящиеся копии, правка в одной и забытая в другой. Но статическое near-zero-FP
обнаружение клонов упирается в движок: он синтаксический (tree-sitter), меряет пофайловые скаляры и
граф зависимостей каталога, тел функций в корпус не собирает ([D059](../../Decisions/059.md)).

## Proposal

C7 доставляется **нормой** — переносимым принципом анти-дублирования в поставляемом навыке
`complexity-discipline` (у него уже есть клаузула консолидации), — **без нового правила**. Решение
[D086](../../Decisions/086.md) фиксирует, почему статическое правило отвергнуто, и текущее покрытие.

- AC1: переносимый принцип «не вводи вторую репрезентацию поведения, у которого уже есть владелец;
  переиспользуй или расширь существующее определение вместо копии» закреплён в поставляемом навыке
  `complexity-discipline`, доступен потребителю из коробки (`init` отдаёт тот же навык). *[норма]*
- AC2: решение [D086](../../Decisions/086.md) фиксирует: широкое/нечёткое (Type-2/3) и кросс-файловое
  клон-детектирование требует тюнингуемой корпус/оконной подсистемы с присущими FP (конфликт с
  near-zero-FP [D035](../../Decisions/035.md) и быстрым гейтом/портативной установкой — семейство
  [D059](../../Decisions/059.md)); единственный вариант ниже ранга «новая подсистема» — внутрифайловое
  ТОЧНОЕ дублирование целых тел — срабатывает слишком редко и не окупает свою машинерию. *[норма]*
- AC3: нового вида правила нет → набор видов правил не меняется; наш код не меняется в поведении.
  Существующие поставляемые правила уже давят на условия, где заводится дублирование: бюджеты размера
  (`file-size`/`function-lines`/`directory-entries`), запрет свалок (`dump-name`), качество `purpose` +
  отсутствие циклов + fan-in (`directory-architecture` [D070](../../Decisions/070.md)/[D079](../../Decisions/079.md)). *[норма]*

**Границы.** Только норма + решение. Статическое клон-правило (широкое/нечёткое/кросс-файловое —
подсистема; внутрифайловое точное — редкое, непропорциональная машинерия) отвергнуто. Притворный
инвариант не вводится ([I020](../../Invariants/020.md) по видам правил без изменений).

## Expected benefit

Потребитель получает из коробки переносимую, agent-native норму против дублирования — выносить общего
владельца, а не копировать, — честно, без ложного gate-enforcement там, где движок не даёт near-zero-FP
обнаружения клонов. Свойство переносимо на любое приложение.
