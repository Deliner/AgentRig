# B136 — Флаги, понижающие уровень lint-ов, в команде clippy требуют ссылку на решение

## Context

Пользователь 2026-11-13 после P139 попросил карточку про флаги в `.agentrig/commands.yaml`. В границах B135 они
остались без проверки.

Гейт запускает команду `clippy` из `.agentrig/commands.yaml`. Всё, что стоит в ней после `--`, Clippy получает как свои
флаги. `init` записывает такую команду в каждый проект на Rust. Lint рига читает флаги только в списке `rustflags` из
`.agentrig/rust.yaml`, а команды не читает.

Проба 2026-11-13 на Clippy 1.100. Команда как в гейте: `cargo clippy -- -D warnings -D clippy::panic -D
clippy::unwrap_used`. В коде есть неиспользуемая переменная, `panic!` и `unwrap`. Флаг дописывался в команду после `--`.

| Флаг в команде | Где стоит | Код выхода | Ошибок | Предупреждений |
| --- | --- | --- | --- | --- |
| нет | - | 101 | 3 | 0 |
| `-A` на эти три lint-а | после `-D` | 0 | 0 | 0 |
| `-A` на эти три lint-а | перед `-D` | 101 | 2 | 0 |
| `--allow=` на эти три lint-а | после `-D` | 0 | 0 | 0 |
| `-A warnings` | после `-D` | 101 | 2 | 0 |
| `--cap-lints allow` | перед `-D` или после | 0 | 0 | 0 |
| `--cap-lints warn` | после `-D` | 0 | 0 | 3 |
| `--force-warn` на эти три lint-а | перед `-D` или после | 0 | 0 | 3 |
| `-W` на эти три lint-а | после `-D` | 101 | 3 | 0 |

- `-A` перед `-D` и `-A warnings` всё равно спрятали неиспользуемую переменную: её делал ошибкой только `-D warnings`.
  Значит, `-A` прячет что-то и перед списком `-D`, и после него.
- `-W` гейт не ослабил.

## Proposal

`-A`, `--allow`, `--cap-lints` и `--force-warn` в команде clippy проверяются так же, как в списке рига.

- **AC1. Проверка флага.** Команда в `.agentrig/commands.yaml` запускает `cargo clippy` или `cargo rustc`. Если в её
  `argv` после `--` есть элемент, который начинается с `-A`, `--allow`, `--cap-lints` или `--force-warn`, и строкой
  выше нет ссылки `DECISION:` или `INVARIANT:`, lint выдаёт ошибку `allow-justification` с навыком `justify-allow`.
  Навык описывает и этот случай. Со ссылкой ошибки нет. Флаг ловится в любом написании и в любом месте после `--`.
  Проверка:
  - каждый из четырёх флагов, отдельно и через `=`, перед списком `-D` и после него, даёт находку;
  - со ссылкой находок нет;
  - `-A` у `grep` и `--allow-dirty` у `cargo package` находок не дают.
- **AC2. Проекты после `init`.** Проект, которому `init` записал команду clippy, получает ту же проверку: если дописать
  в конец этой команды `--cap-lints allow`, lint выдаёт ошибку.

**Границы.**

- `-W` и `--warn` не проверяются: в пробе под `-D warnings` они гейт не ослабили.
- Команда может звать cargo через обёртку: `env`, `sh -c` или свой скрипт. Флаги внутри обёртки карточка не разбирает.
- Если из команды clippy удалить `-D`, например `-D warnings`, гейт тоже ослабнет. Карточка этого не ловит.

## Expected benefit

Ни список флагов рига, ни команда clippy не ослабляют гейт молча. Флаг, понижающий уровень lint-ов, в любом из этих
мест либо опирается на решение, либо даёт ошибку lint.
