# B083 — анализатор зависимостей Rust разбирает include!, macro_rules! и атрибуты без кодогенерации

## Context

Пользователь 2026-11-07 поручил довести voxel-rust до готовности в AgentRig и выбрал исправление анализатора. Версия
95ee9dc с конфигурацией init даёт в voxel-rust 5212 ошибок, из них около 4700 — пределы анализатора:

- 4667 + 4: корень src/core/lib.rs не разобран, ошибку получает каждый файл крейта;
- 19: include!("core.rs") в src/schema/abi и include!(concat!(env!("OUT_DIR"), "/…rs")) для кода prost;
- 5: macro_rules! exports и records;
- 4: #[wasm_bindgen] и #[unsafe(no_mangle)].

Без поломки voxel эти конструкции не убрать.

## Proposal

- **AC1.** include!("путь") со строковым литералом: зависимости подключённого файла учитываются так, будто его текст
  стоит на месте вызова. Файл считается частью крейта вызывающего модуля. Файл вне инвентаря исходников остаётся
  ошибкой.
- **AC2.** include!(concat!(env!("OUT_DIR"), "/имя.rs")) — код build.rs: локальных зависимостей не даёт, находки нет.
  Другие вычисляемые пути остаются ошибкой.
- **AC3.** macro_rules!: пути в теле макроса — зависимости модуля, где он определён, как сейчас пути в аргументах
  вызова. $crate — корень крейта, метапеременные пропускаются. Находки нет.
- **AC4.** no_mangle и export_name, в том числе в unsafe(...), находки не дают. Атрибут-макрос внешнего крейта,
  например wasm_bindgen, — зависимость от этого крейта без находки. Атрибут-макрос своего крейта остаётся ошибкой.
- **AC5.** На voxel-rust с конфигурацией init нет ни одной находки «dependency analysis incomplete» для Rust. В
  AgentRig lint остаётся без находок.

**Границы и неизвестное.** Макросы не раскрываются: путь, собранный из метапеременных, не виден. Код из OUT_DIR не
читается: ссылки prost extern_path на типы проекта не видны, в voxel-rust их нет. Сколько новых находок, например
циклов, покажет разобранный крейт, заранее неизвестно.

## Expected benefit

Rust-проект с генерацией кода, FFI-экспортом и wasm проходит проверку архитектуры по реальным зависимостям, а не
тысячами ошибок анализатора.
