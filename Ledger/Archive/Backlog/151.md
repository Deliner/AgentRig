# B151 — Разрешённые языки программирования в проекте

## Context

- 2026-11-19 пользователь: «проверь, есть ли у нас правила на запрет языков программирования определенных в проектах
  под ригом. Если такого правила нет, надо будет добавить потом на будущее». О показанном черновике: «Карточка 151 в
  целом окей».
- Правила, запрещающего языки, нет. `init --language python|rust` выбирает только шаблоны и проверки
  (`Project/project_setup/template.rs:50-52`).
- Языковые правила lint видят `.rs`, `.py` и `.pyi`. Файл на другом языке получает лишь общие правила вроде размера
  и ширины, поэтому логика на `.js`, `.sh` или `.go` почти не проверяется.
- Вид правила `forbidden-file` есть, но его навык про Markdown (`Project/project_setup/lint.rs:119`).

## Proposal

- **AC1.** Настройка проекта перечисляет разрешённые языки программ. `init` заполняет её по `--language`, в риге
  список отражает его нынешние языки.

  Проверка: тест `init` и config-check.
- **AC2.** Файл программы на языке вне списка даёт ошибку lint, и коммит не проходит. Ошибка называет файл, его язык,
  разрешённый список и абсолютный путь к навыку, который объясняет, как переписать код на разрешённом языке.

  Проверка: тест lint, например `.js` в Rust-проекте.

**Границы.**

- Данные и настройки вроде YAML, JSON, TOML и Markdown программами не считаются.
- Чужой вендорный код исключён, как сейчас по D112.

**Неизвестное.**

1. Язык определяется по расширению, а у файлов без расширения по строке `#!`.
2. Какие языки разрешены самому ригу кроме Rust, например shell для адаптеров.

## Expected benefit

В проекте под ригом код пишется только на выбранных языках, и вся логика проходит языковые правила lint.
