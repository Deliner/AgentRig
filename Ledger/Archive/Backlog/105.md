# B105 — Свои структурные правила, первая партия

## Context

- Для этих 12 форм в Clippy нет lint-а, а проверить их можно по синтаксису без типов.
- Формы из списков запретов пользователя от 2026-11-10, файлы list-2-bans.md и list-3-bans.md:
  - II-13 `..rest` в литерале структуры;
  - II-20 `String` как тип ошибки;
  - II-29 `static mut`;
  - II-30 `Deserialize` без `deny_unknown_fields`;
  - III-10 `#[cfg]` на инструкции внутри функции;
  - III-11 `derive(PartialOrd, Ord)` у enum без явных дискриминантов;
  - III-15 `break` и `continue` во вложенном цикле без метки;
  - III-16 вычитание из `len()`;
  - III-18 значение-сторож в целочисленном результате;
  - III-19 значение по умолчанию вместо ошибки разбора;
  - III-23 `Mutex<()>`;
  - III-28 `spawn` как инструкция.

## Proposal

- Для каждой формы есть свой вид правила и навык исправления.
- **AC1.** Точность каждого правила на риге и voxel-rust не ниже 90%. Правило ниже этой планки не поставляется, и это
  записывается.
- **AC2.** Находки в коде рига исправлены.
- **AC3.** `init` ставит эти правила в проекты.

**Границы.**

- У каждой формы один владелец. Пересечение II-30 с `unchecked-deserialize` разбирается при поставке.
- Неизвестно, сколько находок дадут правила и насколько они точны.

## Expected benefit

Формы ошибок, которые Clippy не видит, запрещены и в риге, и у потребителей.
