# B175 — Файлы одной директории не образуют цикл

## Context

- 2026-11-20 пользователь: цикл между файлами это дефект, его надо рефакторить. Сегодняшняя проверка циклов
  директорий остаётся, к ней добавляется проверка файлов внутри директории.
- Сейчас файлы одной директории считаются одним узлом. Решение D093 отклоняло такое правило, пользователь это
  пересмотрел.
- Замер рига: 8 директорий с циклом, самый длинный из 4 файлов.

## Proposal

- **AC1. Находка.** Правило `file-cycle` даёт ошибку, когда файлы одной директории используют друг друга по кругу,
  напрямую или цепочкой. Входной файл директории не учитывается: `mod.rs`, `lib.rs`, `main.rs`, `__init__.py`.
  Объявление `mod child;` связью не считается.

  Проверка: `a.rs` и `b.rs` используют друг друга: находка. Цепочка `a → b → c → d → a`: одна находка. `a.rs` и
  `mod.rs` используют друг друга: находки нет.
- **AC2. Текст находки.** Вся цепочка и для каждого звена `файл:строка uses файл`.
- **AC3. Навык `break-file-cycle`.** Шаги: найти лишнее звено; перенести общий тип или функцию в файл, от которого
  зависят оба; соединить файлы, если ответственность одна. Запрещает сливать файлы или прятать связь за реэкспортом
  ради прохождения.
- **AC4. Риг и проекты.** Правило включено в риге и после `init`, для Rust и Python. Код рига приведён к правилу.

**Границы.** Проверка циклов директорий не меняется. Правило читает те же связи, включая тестовые; корни в
конфигурации повторять не нужно.

## Expected benefit

Каждый файл можно понять и изменить, прочитав только то, от чего он зависит.
