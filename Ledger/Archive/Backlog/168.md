# B168 — Индекс из одного массива не читает другой массив

## Context

- 2026-11-19 пользователь прислал ревью voxel-rust на ревизии `2304625` и попросил: «Посмотри, возможно на основе
  этого можно новых карточек наделать … для AST линтеров и в целом для процесса». О показанных черновиках:
  «Остальные можешь сохранить».
- Ревью, «Приоритет зон касания закодирован двумя массивами»: в `src/ui/touch/mod.rs:8, 64` позиция ищется в списке
  прямоугольников, затем служит индексом в отдельном списке ролей. Сейчас сопоставление верно, но порядок задан в
  двух местах.

## Proposal

- **AC1.** Результат `.position(…)` по одной коллекции, использованный как индекс другой коллекции, даёт ошибку lint.
  Навык велит хранить пары вместе, например прямоугольник и роль в одном списке.

  Проверка: тест lint на пример из ревью.

## Expected benefit

Связанные значения меняются в одном месте и не расходятся по позициям.
