# B153 — Хук понимает команду так же, как оболочка агента и just

## Context

- 2026-11-19 пользователь об отчёте аудита обходов: «не хочется все твои находки терять… давай их все исправим».
  Затем: «Пока только карточки заведи». Текст сохранён без показа в чате, затем пользователь его согласовал: «Да,
  тексты согласованы будем считать».
- Аудит 2026-11-19, пункт A2. zsh исполняет код внутри разрешённой команды: `just read -- cat =(touch x)` и
  `just read -- ls *(e:'cmd':)`. Хук ищет только `;|&<>`, перевод строки, обратную кавычку и `$(`
  (`Project/agent_hooks/shell_guard.rs:31`). Проба: zsh исполнил, хук разрешил.
- Пункт A3. Первым словом подходит любой файл с именем `just`, например `.cache/x/just lint` после
  `just write -- chmod +x` (`shell_guard.rs:93-96`). Проба: хук разрешил.
- Пункт A4. Рецепты `lint*`, `jobs` и `job-*` хук не проверяет, а just читает лишнее слово после рецепта без
  параметров как второй рецепт: `just jobs bootstrap` запускает и `bootstrap` (`shell_guard.rs:146-148`). Проба: хук
  разрешил, just запустил оба рецепта.
- Пункт A5. `--root` в аргументах подменяет каталог команд: `just read cat --root /tmp/e x`
  (`Project/cli_dispatch/main.rs:56-60`, `Project/shared/shared_options/take_option.rs`). Проба: хук разрешил;
  подмена каталога прослежена по коду.

## Proposal

- **AC1.** Хук отказывает команде, в которой оболочка агента исполнит код до запуска just, в том числе через
  `=(…)`, `<(…)` и квалификаторы glob в zsh. Та же запись в кавычках остаётся текстом и проходит.

  Проверка: тест хука на примеры A2 и проба в zsh.
- **AC2.** Первым словом принимается только `just`, который оболочка находит по имени; путь к файлу `just` получает
  отказ.

  Проверка: тест хука на `./x/just lint` и на абсолютный путь.
- **AC3.** Хук проверяет аргументы каждого рецепта. Лишнее слово после рецепта без параметров получает отказ, а не
  запуск второго рецепта.

  Проверка: тест хука на `just jobs bootstrap`.
- **AC4.** Каталог команд и корень проекта берутся из репозитория, где работает агент; аргументы агента их не
  меняют.

  Проверка: `just read cat --root /tmp/e x` не читает каталог из `/tmp/e`.

## Expected benefit

Хук разрешает ровно ту команду, которая потом выполнится.
