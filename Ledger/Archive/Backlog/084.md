# B084 — профиль Clippy: `option_option`

## Context

Пользователь 2026-11-07 увидел в анализаторе тип `Option<Option<String>>` и спросил, не антипаттерн ли это и не должны
ли мы такое блокировать: архитектурного смысла в нём нет. Внешний и внутренний `None` различают два состояния, но их
смысл виден только из кода вокруг. В ветке `feature/rust-expansion` это место уже заменено перечислением `Binding` с
вариантами `Path` и `Opaque`. На master `ef216b2` и в voxel-rust таких типов нет.

Проба clippy 1.98.1 с `-D clippy::option_option`:

| Место | Срабатывает |
| --- | --- |
| закрытые поле структуры, вариант перечисления, параметр, возвращаемый тип | да |
| вложенный тип, например `Vec<Option<Option<u8>>>` | да |
| открытый API библиотеки | только при `avoid-breaking-exported-api = false` в `clippy.toml` |
| псевдоним `type`, аннотация `let`, выведенный тип | нет |

## Proposal

- **AC1.** Общий профиль Clippy запрещает `clippy::option_option`: и dev-гейт AgentRig, и команда `clippy`, которую
  `init --language rust` ставит новым проектам. Проверка: пробный фрагмент с `Option<Option<_>>` проваливает
  `just run clippy`, его удаление возвращает гейт в зелёный; тест профиля подтверждает, что списки dev-гейта и `init`
  совпадают.
- **AC2.** В AgentRig нет мест, которые находит линт. Проверка: гейт проходит без исключений для этого линта.
- **AC3.** Новое решение расширяет D132 и фиксирует границы ниже.

**Границы и неизвестное.**

- Законный случай, например поле PATCH-запроса с тремя состояниями через serde, остаётся возможным через обоснованный
  `#[allow(clippy::option_option)]` по D080.
- Открытый API библиотек линт по умолчанию не проверяет. Настройка `avoid-breaking-exported-api = false`
  распространила бы на открытый API и другие линты профиля и потребовала бы от `init` нового файла `clippy.toml`; в
  карточку она не входит.
- Псевдонимы типов и локальные переменные Clippy не проверяет.

## Expected benefit

Два разных «нет значения» не прячутся в одном типе: состояние получает имя через перечисление, и его смысл виден в
объявлении, а не в коде вокруг.
