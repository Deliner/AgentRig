# B087 — Граф зависимостей Rust без ложных рёбер

## Context

- `pub(in crate::native)` дало ребро host → native и ложный цикл, пришлось писать `pub(crate)`.
- На прежних версиях `#[expect]` выключал анализ всего крейта, а импорт `wasm_bindgen` давал цикл.
- Эти два случая нужно перепроверить.

## Proposal

- Путь в ограничении видимости не считается использованием.
- Крейт с `#[expect]` анализируется полностью.
- Внешний крейт не даёт рёбер внутри проекта.
- **AC1.** На фикстуре `pub(in crate::a)` внутри `a::b` не даёт ребра b → a.
- **AC2.** Крейт с `#[expect]` анализируется полностью.
- **AC3.** В voxel-rust можно вернуть `pub(in crate::native)` без новых находок.

**Границы.**

- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Проверка архитектуры Rust видит только настоящие зависимости, и проекту не нужно менять видимость или атрибуты ради
анализатора.
