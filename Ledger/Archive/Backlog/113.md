# B113 — Вложенный Option ловится и там, где Clippy его не видит

## Context

- После P117 запись `Option<Option<T>>` ловит только Clippy. Проба Clippy 1.98.1 с настройками рига нашла места, где
  Clippy её не видит. Там её сейчас не ловит ни одна проверка рига.
- Через эти места проверку можно обойти. Например, можно объявить `type X = Option<Option<u32>>` и дальше писать `X` в
  параметрах и полях: Clippy молчит и там.
- Решение D162 этот вариант отклонило. Пользователь 2026-11-11 выбрал его: правило рига ловит вложенный Option только
  там, где Clippy молчит, и на каждом месте остаётся одна ошибка.

| Где записан `Option<Option<..>>` | Clippy ловит |
| --- | --- |
| Параметр и возвращаемый тип функции или метода, в том числе в трейте | да |
| Поле структуры, вариант перечисления, кортеж или `Vec` внутри поля | да |
| `const` и `static` | да |
| Псевдоним `type`, в том числе связанный тип в `impl` | нет |
| Аннотация `let` | нет |
| Параметр замыкания | нет |
| Параметр в типе `fn(..)` или `dyn Fn(..)` | нет |
| Ограничение обобщённого параметра, например `T: Into<..>` | нет |

## Proposal

Правило рига ловит `Option<Option<T>>` в каждом месте, где Clippy молчит, и только там. Ошибка правила называет место
и подсказывает исправление: дать каждому состоянию имя через перечисление или обосновать запись ссылкой на решение.

- **AC1.** Коммит с `Option<Option<T>>` в любом месте таблицы с «нет» останавливает правило рига, ошибка одна.
- **AC2.** Коммит с `Option<Option<T>>` в любом месте таблицы с «да» по-прежнему останавливает только Clippy, ошибка
  одна.
- **AC3.** Ссылка `DECISION:` или `INVARIANT:` на строке прямо над записью снимает находку правила рига, так же как у
  `Option<bool>`.

Границы:

- Правило для `Option<bool>` не меняется.
- Тестовый код, как и раньше, вне области: Clippy рига его не проверяет, а правила рига пропускают.
- Новые Rust-проекты получают правило вместе с остальными правилами рига и с тем же профилем Clippy.
- Список мест верен для Clippy 1.98.1, версии, закреплённой в риге. Если новая версия Clippy начнёт ловить ещё какое-то
  место, там снова будут две ошибки, пока список правила не поправят.
- Сделать это частью правила `ambiguous-option` или отдельным правилом, решает исполнитель.

Неизвестное: таблица перечисляет проверенные места. Остальные, например возвращаемый тип внутри `fn(..)`, исполнитель
проверит пробой Clippy и отнесёт к «да» или «нет».

## Expected benefit

Вложенный Option нельзя провести мимо проверок через псевдоним или замыкание, а агент по-прежнему получает одну ошибку
на одну проблему.
