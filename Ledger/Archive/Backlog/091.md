# B091 — Тестовые файлы Rust по соглашению AgentRig

## Context

- В voxel-rust 13 тестовых файлов `*_tests.rs` подключены через `#[cfg(test)]`.
- Риг молча считает их рабочим кодом, и правила дают по ним непонятные находки. Шаблон пришлось дописать в 16 правил.
- Соглашение AgentRig опирается на Rust Book, где тесты встроены в модуль `tests`, и на проверку tidy в
  rust-lang/rust, где они лежат в `tests.rs` или в каталоге `tests/`. Сам AgentRig этому соглашению уже следует.
- Пользователь 2026-11-10 выбрал этот путь: проекты приводятся к соглашению AgentRig, риг не подстраивается под их
  имена файлов.

## Proposal

- Файл, подключённый под `#[cfg(test)]` вне `tests.rs` и `tests/`, даёт одну находку размещения.
- В ней названы файл, строка объявления и навык, который переносит тесты так, что они видят тот же код, что и раньше.
- Остальные правила оценивают такой файл как сейчас.
- Выбор записывается решением. Отвергнутый вариант: риг сам узнаёт тестовые файлы по `#[cfg(test)]`.
- **AC1.** `#[cfg(test)] mod x_tests;` даёт одну находку размещения.
- **AC2.** `#[path = "x_tests.rs"] mod tests;` даёт такую же находку.
- **AC3.** `tests.rs`, `tests/` и встроенный `mod tests {}` находок не дают.
- **AC4.** В voxel-rust после переноса 13 файлов шаблон `**/*_tests.rs` убран без новых находок.

**Границы.**

- Прежние находки по такому файлу остаются, к ним добавляется одна с причиной. Уходят они после переноса файла.
- Поведение проверяется тестами AgentRig на переносимых фикстурах, затем на voxel-rust, где снимается названный обход.
- Под voxel-rust риг не подгоняется.

## Expected benefit

Неправильно размещённый тестовый файл сразу получает находку с причиной и способом исправления.
