# Decisions

Current precedence: [D044](Decisions/044.md) adds an architecture type to contracts of features without nested features, superseding D043's three-field limit. [D043](Decisions/043.md) limits directory contracts to purpose, files and directories, superseding D028's permission and public-boundary checks. [D042](Decisions/042.md) places first-level features with two-word names directly in Project and adds Python verification configuration to tooling, superseding D041's tooling scope. [D041](Decisions/041.md) develops the worker under Project, superseding D025's placement under tooling/worker. [D035](Decisions/035.md) makes feature-merge select tests affected by the whole branch, superseding D022's complete integration gate for test commands. [D034](Decisions/034.md) replaces systemd scopes with process groups and adds a macOS read-only sandbox. [D033](Decisions/033.md) retires review, delegation, upgrade and its receipt, declarative setup, Mercurial and external VCS, and JavaScript/TypeScript analysis; D023 and D024 remain history and D025 keeps only lint ownership. [D032](Decisions/032.md) requires chat agreement before saving new or revised feature requirements, Backlog-origin Plan contracts and autonomous execution of selected sets; it supersedes immediate idea capture under D031 and new-outcome prerequisite bypasses under D012. [D031](Decisions/031.md) limits Plan to current execution and sends future ideas to unordered Backlog, superseding D012's future queue semantics. [D022](Decisions/022.md) adds actionable verification evidence and recovery facts without new checkpoints. [D021](Decisions/021.md) supersedes D017's warning-only language rollout. [D020](Decisions/020.md) consolidates the runtime and current guidance. D011 retires D003 edit checkpoints; D012 supersedes D009 delivery sequencing. Rows and details D001–D019 record historical choices, not additional active runtimes. Their statements and details are preserved; Applies in points to current owners.
