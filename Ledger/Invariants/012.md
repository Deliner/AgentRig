# I012 — Ledger edit guidance routing

## Predicate

The shared pre-tool dispatcher selects the matching short skill for each affected Plan, Decisions, Invariants, or State path, including detail files and patch moves. Direct unrelated edits receive no Ledger guidance. Guidance alone does not deny edits; existing shell guard and complexity decisions remain in effect.
