# I012

## Predicate

Ledger edits receive matching skill guidance without a new edit denial, except that the first edit of a decision record in each area of a context window is denied until norm-or-choice is delivered (D186), preserving existing guard and complexity decisions.

## Oracle

Configured cargo target `agent_hooks::tests::memory::ledger_edit_guidance` verifies this behavior through the native runtime. D020 updates the implementation and current ownership while preserving the predicate except its explicit revisions to I001 and I003. D186 revises the predicate with the decision-record denial, which the same target checks.
