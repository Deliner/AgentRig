# I014 — Actionable lint configuration failures

## Predicate

Unsupported rule kinds or targets, malformed selectors, missing repair skills, and invalid thresholds fail lint configuration with exit 2 and a configuration-repair skill, rather than silently passing.

## Oracle

[test_invalid_config_is_actionable](../../tooling/worker/src/lint/tests/test_lint.py) invokes the native binary against invalid configurations under D016. Companion tests verify selector overrides, file languages, directory measurements, and external gate hints.
