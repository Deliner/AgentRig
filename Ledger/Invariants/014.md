# I014 — Actionable lint configuration failures

## Predicate

Unsupported rule kinds or targets, malformed selectors, missing repair skills, and invalid thresholds fail lint configuration with exit 2 and a configuration-repair skill, rather than silently passing.

## Oracle

[invalid_config_is_actionable](../../Project/structural_lint/tests/diagnostics.rs) runs the native worker as a process against invalid configurations under D016. Companion tests verify selector overrides, file languages, directory measurements, and external gate hints. The exact target is configured under oracles.I014.
