# I016 — Reject unsupported language selection

## Predicate

Both lint-config-check and lint reject syntax rules explicitly selecting unsupported suffixes or selecting existing unsupported files without an extension filter. The error names supported languages and a configuration repair skill, rather than silently passing.

## Oracle

[test_config_rejects_unsupported_language](../../tooling/tests/native/test_config_check.py) checks extension selection, literal-suffix globs and broad directory selection against both CLI entrypoints under D018.
