# I022 — init keeps sources in Project and memory in Ledger

## Predicate

`agentrig init` writes `paths.sources` as `[Project/**]` and `paths.memory` as `Ledger` and creates `Ledger/State.md`; `--source` or `--memory` with any value is refused before anything is written.

## Oracle

Configured cargo target `project_setup::initialization::tests::layout::init_always_keeps_memory_in_ledger_and_sources_in_project` runs init with `--source Other` and with `--memory Other` in an empty directory and compares its snapshot before and after, then runs a plain init and reads `.agentrig/project.yaml` through the native runtime. D187 fixed the names; D040 chose them.
