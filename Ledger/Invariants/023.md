# I023 — init reproduces the rig's setup except listed differences

## Predicate

For a Rust project with an `origin` remote and this repository's Cargo manifest, the files under `.agentrig`,
`justfile`, `just`, `.codex` and `.claude` after `agentrig init`, except Claude Code's personal `settings.local.json`,
equal this repository's, with configuration modules compared after normalization, except at the paths
`rig_differences.yaml` lists; every listed path still differs and every entry has a reason.

## Oracle

Configured cargo target
`project_setup::initialization::tests::rig::init_matches_the_rig_setup_except_listed_differences` runs init in a
temporary repository with `origin` and the rig's manifest, reads both setups without following links, compares them
key by key, records of a list by `id` and other list items as sets, and fails on an unlisted difference, an unused
listed path or an empty reason. D189 chose this norm.
