# I021 — Reference guard errors never permit a deletion

## Predicate

When the reference-transaction guard (`guard-reference`, prepared phase) checks the deletion of a feature branch and cannot resolve the branch tip or complete the ancestry check, the transaction fails with the Git error; it never answers "not merged" and permits the deletion. A resolvable merged tip is still rejected as retained.

## Oracle

Configured target `Project/change_delivery/git/tests/test_git.py::test_reference_guard_rejects_deletion_when_the_tip_cannot_be_resolved` feeds the guard an unknown old value for a merged feature branch (exit 1, retained) and for a reference that does not exist (exit 2, the error, without the retained verdict) through the native runtime. D097's dogfooding (B062 AC1) made `merged_reference` propagate the error instead of answering `Ok(false)`.
