# I018

## Predicate

Changed source or executable mode invalidates current check evidence, and a selected passing check never claims a full passing gate.

## Oracle

[evidence_tracks_content_and_partial_checks](../../Project/project_memory/evidence/tests/mod.rs) runs checks through the native worker in an independent Git repository and reads the evidence through `resume` in process. The exact target is configured under oracles.I018. D022 defines the recovery contract.
