# I011 — Recovery snapshot structure

## Predicate

The repository gate rejects missing State or missing, empty, reordered, or duplicate recovery sections. A structurally complete snapshot is accepted even when its recorded branch or revision differs from the current checkout, because resume reconciles observed facts instead of treating State as live Git metadata.

## Oracle

[test_state_recovery_contract](../../tooling/tests/test_state_policy.py) exercises absent and malformed snapshots and valid recovery notes. State is introduced by [D013](../Decisions/013.md).
