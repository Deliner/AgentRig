# I015 — Language-specific named branch checks

## Predicate

For supported Rust/Python source, named-if-condition accepts named values, reports inline boolean expressions at their source lines, ignores text in comments/strings, and selects the configured warning or blocking severity and repair skill. A simple Rust if let remains a binding construct under D017.

## Oracle

[test_language_conditions](../../tooling/worker/src/lint/languages/tests/test_language.py) executes the native linter on both grammars and verifies accepted forms, rejected expressions, coordinates, skills and exit behavior. Companion tests exercise functions, receivers, parameter defaults, syntax errors and selectors.
