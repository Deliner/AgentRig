# I017 — Blocking language defaults

## Predicate

New Python and Rust consumers reject unnamed if conditions, functions longer than 40 nonblank lines and declarations with more than 4 counted inputs. Findings have error severity and a repair skill; the delivery gate stops. Named conditions and exactly 40 lines or 4 inputs pass lint.

## Oracle

[test_strict_defaults_block_delivery](../../tooling/tests/native/scaffold/test_strict.py) installs the actual runtime and checks each violating source and repaired boundary through lint, plus delivery gate rejection. The exact target is configured under oracles.I017. D021 authorizes this policy.
