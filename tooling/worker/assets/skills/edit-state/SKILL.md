Use Focus, Workspace, Progress, Verification, Blockers and Next action in order. Read current Plan and Git before editing. Record the authorized task, observed branch/revision, coherent change, verified results, pending work, blockers and next action. Branch: `name` and Revision: `hash` lines can be compared by resume. Refresh at meaningful boundaries and interruptions; reconcile after branch switches. State is a snapshot, not authorization or a second task/history database. Preserve user work and never include secrets or transcripts.
