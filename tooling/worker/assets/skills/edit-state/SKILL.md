description: Record compact factual recovery context after progress, failure or handoff.

Use Focus, Workspace, Progress, Verification, Blockers and Next action in order. Read current Plan and Git before editing. Record the authorized task, observed branch/revision, coherent change, verified results, pending work, blockers and next action. Branch: `name` and Revision: `hash` lines can be compared by resume; use the observed commit ID (full or unambiguous abbreviation), not a moving branch name. Read resume for merge/rebase facts and check freshness; a passing result for different content or HEAD is not current verification. Refresh at meaningful boundaries and interruptions; reconcile after branch switches. State is a snapshot, not authorization or a second task/history database. Preserve user work and never include secrets or transcripts.
