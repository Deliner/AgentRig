# Edit decisions

- Apply norm-or-choice: a decision selects among admissible alternatives; a must-hold observable predicate belongs in Invariants with a test.
- Read relevant records and explicit successors. Give a new choice a stable DNNN ID, indexed detail, and Context, Chosen, Rejected, Rationale, Consequences sections in that order.
- Preserve committed IDs, statements, details, and prior application links. Supersede through a new decision naming the displaced choice and changed context; identify precedence in the index.
- Link actual governed files in Applies in. Each linked Python/shell implementation must carry the exact comment # DECISION: DNNN. Additional application links are allowed.
- Record only genuine durable choices. Routine Plan or State updates do not create decisions. Update affected instructions, implementation, and tests together; the staged gate checks the records.

D019 permits only its five deleted Python application links to migrate to the named Rust owners. Decision IDs, statements and detail files remain immutable; this exception does not authorize other link removal.
